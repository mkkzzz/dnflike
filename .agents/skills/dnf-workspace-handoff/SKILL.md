# DNF 工作区接续与交接

从当前仓库根目录执行，身份从 `.workspace` 读取；迁移 AI 工具不改变工作区 ID。入口是 [AGENTS.md](../../../AGENTS.md)，协作规则只在 [协作总纲](../../../docs/project/00_协作总纲.md) 维护，本技能不另建规则副本。

## 开工、收工与切换

- 使用者说“开工”时，严格按协作总纲第二节顺序执行，首个操作为 `python tools/sync_status.py`，主动告诉用户“等待本区”的事项。首次初始化只有在身份可确定时执行，不猜 ws 编号。
- 使用者说“收工”时，读协作总纲第二节的当前流程并执行。普通授权任务也按该文规定的产出同步节点交付，不把“配置建议”自动解释成已安装。
- 迁移或切换任务时，将 [工作区登记](../../../docs/project/03_工作区登记.md)、本区状态、[待办](../../../docs/project/02_待办.md)、`git status`、最新 commit 和必要 diff 对照。状态所称“未提交”需和当前历史核实；提交、回归、用户认可分别登记，保留尚未验证的事项。
- 动态职责从 [28 分工](../../../docs/design/28_工作区分工与原版资料共享.md) 获取。识别本区修改、其它区修改、未跟踪素材与引擎缓存；无法安全分离的改动保留并解释。

## 环境迁移

检查实际 `CODEX_HOME`、生效配置、技能发现位置和工具可用性，只输出相关字段，不打印凭证或整份配置。机器路径/凭据留本地，项目技能可随仓库共享。改 MCP 配置前备份，验证 TOML 和实际工具握手，保留其它项目连接。

Godot 使用仓库固定引擎和现有启动脚本，临时桥接/截图按 `.mcp` 缓存规则处理。从 CodeBuddy 接续时核对仍引用旧安装目录的工具；只迁移当前授权范围内实际需要的能力，不顺手重写历史工具。

## 状态与证据

只更新本区状态；公共文件占位、追加交接、等待项关闭、提交与推送遵循协作总纲。写文档前读 [文档规范](../../../docs/project/06_文档规范.md)，新增报告登记 [文档索引](../../../docs/project/07_文档索引.md)。交付说明已完成的配置/检查、实际可用的能力、重启加载需求以及未完成验证；不要以重启前的配置文件存在宣称当前会话已加载新工具。
