# effort_voice —— 出招人声（真实录音，CC0）

招式起手那一声"用力"。**原始素材不入库**，本目录记录来源、许可与加工参数，
派生结果在 `game/assets/audio_v3/voice_{light,mid,heavy,rage}_<1..3>.wav`。

## 来源

| 包 | 作者 | 许可 | 素材 | 链接 |
|---|---|---|---|---|
| Male Grunt/Yelling sounds | HaelDB | **CC0**（同时提供 OGA-BY 3.0，本工程取 CC0） | 4 位男声、每人 10~12 段嘶吼/发力声，WAV，共 62 段 | https://opengameart.org/content/male-gruntyelling-sounds |

## 为什么用真实录音

先做过一版**共振峰合成**的"用力"人声（四档、0.11~0.30 s），负责人实机反馈
"不像人"。人声属于"有大量 CC0 素材、合成很难达到手感"的类别，
判断表见 `docs/design/19_音效生产工作流.md` 3.8 节。

## 加工（`tools/bake_effort_voices.py`）

1. 逐段量"有声段长度"（3% 峰值门限），只保留 0.10~0.85 s 的段
2. 按长度排序后**分段取样**成四档（不靠听也能分档）：
   - 最短 → `voice_light`（轻击，上限 0.26 s）
   - 次短 → `voice_mid`（中击，0.34 s）
   - 再次 → `voice_heavy`（重击，0.44 s）
   - 最长 → `voice_rage`（血怒火吼，0.60 s）
3. 裁剪有声段、重采样到 48 kHz 单声道、按上限截断并补收尾、归一化峰值 0.72

**为什么加时长上限**：素材里混着整句长啸，直接用会盖住招式音。
起手声必须"短促"，所以每档都有硬上限。

## 验收

`validation.json` 记录每个文件的时长、峰值、RMS、质心、首尾采样、削波数与哈希；
交付规范同工程：48 kHz / 单声道 / 16 bit、峰值 < 0.76、首尾为 0、无削波、3 变体。
