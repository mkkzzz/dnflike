# Combat foley v3

本目录记录的 27 类声音（81 个 WAV）全部为本工程原创的离线程序化拟音，没有下载素材、第三方录音或音频模型输出。可入库的游戏 WAV 位于 `game/assets/audio_v3/`，生成程序是 `tools/bake_combat_audio.py`。

> **例外（2026-10-15 追加）**：`game/assets/audio_v3/` 下另有 `goblin_hurt_1~3.wav`（怪物受击生物叫声），**使用了外部素材**（Wikimedia Commons 公有领域录音）。因此本节开头的声明对**本目录的 27 类**成立，对 `goblin_hurt` 不成立。该类的来源、许可与派生链单独记录在 [../goblin_hurt/README.md](../goblin_hurt/README.md)。运行时合计 28 类 / 84 个 WAV。

27 类声音各有 3 个独立随机种子演奏版本，共 81 个 48 kHz / 单声道 / 16 bit PCM 文件。运行时轻微音高变化和不连续重复的变体选择进一步减轻机械重复感。单声道资产通过 Godot `AudioStreamPlayer2D` 做相对听者的位置声像和距离衰减。

## 材质与层次

- 剑挥：低频空气位移、中频湍流和高频刃口空气剪切分层，叠加手套/皮革握柄声。三连、上挑、空斩、冲斩、连突分别使用不同宽度、频带和速度包络。
- 命中：瞬时接触声、中低频肉体/压力振动、皮革拍击、刃缘擦过和微量衰减钢铁模态。重击加低频瞬态和破裂颗粒，上挑加空气释放。
- 格挡/金属：以不整数频率比和不同阻尼的弹性板/梁模态模拟钢刃接触，叠加短宽带撞击和握柄受力，避免旧版的单频滑音。
- 移动：石板与靴底接触、鞋跟第二触点、鞋底压缩和皮革褶皱声。跑步、急停、起跳、双脚落地分别有独立模型。
- 拔刀：反向收束空气与弱钢铁局部共振，接瞬间高频刃口释放、空气斩和低压力脉冲。怒气使用粗糙空气与稀疏火星瞬态，两次怒斩各叠双层空气剪切。
- 死亡：怪物呼气衰减、躯体落地和皮革/石板碰撞；提示音使用衰减敲击音，保持可辨识。

所有声音最后有低音量石室早期反射、轻软饱和、3 ms 首尾渐变和零边界 DC 校正。模型旨在比单频 chirp 更有材质和重量；拟音品质仍应通过耳机/扬声器的主观试听继续打磨。

## 复现与验证

```powershell
python tools/bake_combat_audio.py
```

需要 NumPy；不需要 SciPy、外部网络或 Godot。SHA256 为每个类别/变体固定种子，因此相同 NumPy 环境内可复现。`source_spec.json` 记录配方与种子协议，`validation.json` 记录每个 PCM 的时长、峰值、RMS、DC、文件哈希、削波数量和首尾采样。

本轮验证：81 文件 / 27 类 / 每类 3 版本，最大峰值低于 0.76 FS，无削波采样，首尾采样全为 0。运行时 10 个优先级声音池，常规脚步优先让位于击打；同类命中的最短间隔限制同时群怪堆音。根据所有活跃声道的保守峰值上界即时降低混音增益并缓慢释放，保持总输出余量。

`audition_combat_v3.wav` 是带轻微左右声像的试听合集，顺序为三种剑挥、轻/重/金属命中、走/跑/跳/落/急停、格挡、蓄力/拔刀、血怒/怒斩、三次连突、死亡、波次、胜利。真实游戏里的声音按 `combat_audio.gd` 的强弱参数混音，合集只用于检查单个音色。

Headless 会加载资源并创建池以供验收，但不播放。重玩 `stop_all()` 停止并卸载声道引用、清空变体历史/节流和混音余量。
