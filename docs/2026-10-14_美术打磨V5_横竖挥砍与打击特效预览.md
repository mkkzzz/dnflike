## 二、三个问题与对策

### 1. 挥砍全是竖向 → 横竖分配

V4 的武器只在屏幕平面内旋转，所以所有招式都只能画成竖向月牙。V5 改成**在 3D 挥砍平面里定义刀身方向，再按 20° 相机俯角投影**：横斩时刀身会因透视缩短，刀光就是该平面圆弧的投影（扁椭圆）。刀光经过身前近侧的部分画在身体前，经过远侧的部分画在身体后并压暗 38%。

| 招式 | 方向 | 挥砍平面（β 近侧下倾 / γ 前端下倾） | 轨迹 |
|---|---|---|---|
| 一段·右横斩 | 正手横斩 | β −8°，γ +5° | 身后 → 身前近侧 → 正前（命中）→ 远侧 |
| 二段·反手横斩 | 反手横斩 | β −6°，γ −10°（倾斜与一段相反） | 远侧 → 正前（命中）→ 近侧 |
| 三段·竖劈 | 竖向重劈 | β 82°（接近屏幕平面） | 头顶 → 前下 → 刀尖砸地后停住 |
| 拔刀斩 | 居合横扫 | β −3°，γ +2°（接近水平） | 蓄力 16 帧 → 4 帧拔刀横扫并前冲 104 px → 9 帧停帧 → 三道延迟斩痕 |

身体姿势：本轮**没有新画身体帧**，而是从 V3 已审核的 88 个无武器源姿势里重新编排（每个招式的序列见 `tools/art_v5/moves.py`），例如一段用 `base:8` 后拉蓄势 → `combo12:14` 胸前横带 → `airdash:11` 弓步全伸。帧预算沿用 V4 的 `moves.json` / `skills.json`。

### 2. 刀光迭代

- **刀光头部永远等于画面里的刀尖**：刀光以握点为圆心、刀尖为外缘；进入收招后圆心锁定在最后一个出刀姿势，避免收招姿势把刀光拖走。
- 分层：白热刃缘线（屏幕空间恒定宽度，不随透视变粗）+ 刃缘热带 + 沿弧向的拉丝流光 + 碎散的内缘 + 外辉光 + 内外两条副弧线。
- 形状：刀头尖锐、紧随其后最厚、尾部拉长变细。
- 消散：从尾部被噪声逐步吃掉并变薄，不是整体淡出。
- 色板 3 选 1，见 `slash_palette_options.png`：银白（当前默认）/ 血红（狂战士）/ 青蓝（剑魂，拔刀斩已用）。

### 3. 受击特效：精致化，并与打击点对齐

**打击点**：每个物理帧做 4 次子采样，取刀身 24 个采样点与目标**真实像素 alpha** 的首个交集，交集点的重心就是打击点。命中后整个停帧期间，身体、刀身、刀光都锁在该子帧，所以刀、刀光和火花三者同位。`hit_alignment_debug.png` 中，黄点是刀身采样，品红十字是打击点，绿圈是挥砍圆。

| 层 | 时长 | 说明 |
|---|---|---|
| 核心闪光 | 4 帧 | 小白热核心 + 暖色光晕，不再整片糊白 |
| 星芒 | 6 帧 | 沿刀身方向两条长芒 + 随机短芒 |
| 斩痕 | 13 帧 | 沿挥砍圆弧、穿过打击点的短亮弧；横斩是横向斩痕，竖劈是纵向斩痕 |
| 冲击环 | 9 帧 | 垂直于刀向压扁 |
| 火花 | 9–22 帧 | 沿刃口行进方向和击退方向喷射，带阻尼、重力，颜色从白热冷却到暗红 |
| 血滴 / 血雾 | 16–32 帧 | 暗红血滴落地后小幅弹跳，血雾缓慢扩散 |

目标反应：不再整体变成白剪影。命中首帧闪白 26%，随后用红色乘色保留原画细节；只在朝向刀口、且靠近打击点的边缘打轮廓光。停帧中目标左右抖动，之后挤压回弹并沿刀向击退。三段竖劈和拔刀斩会击倒目标。

重击追加：刀尖砸地时生成地裂纹（裂缝热光会冷却）、向两侧扩散的尘烟、碎石，以及压扁在地面上的冲击环，并加入镜头竖向震动。拔刀斩停帧时世界压暗，出现横贯画面的“一闪”光线；停帧结束后，目标身上依次爆出三道延迟斩痕。

## 四、实现与复现

```powershell
python tools/preview_v5.py               # 渲染全部片段到 temp/v5_preview/
python tools/preview_v5.py --publish     # 并复制评审文件到 docs/previews/v5_art/
python tools/preview_v5.py --compare     # V4/V5 对比图
python tools/preview_v5.py --palettes    # 色板对比
python tools/preview_v5.py --align       # 打击点调试叠层
python tools/preview_v5.py --clip combo --strip 18:66:3   # 任意帧区间的放大联系表
```

- `tools/art_v5/poses.py`：直接从 V3 / V4 源图按渲染倍率重采样身体姿势，复用已审核的根点与握点。
- `tools/art_v5/weapon.py`：按 3D 刀身方向投影绘制墨钢长刀（刀身、刃线、护手、缠柄）。
- `tools/art_v5/fx.py`：解析式刀光（平面圆环带投影）、纺锤光、星芒、光晕、冲击环、烟尘等绘制原语，以及泛光。
- `tools/art_v5/scene.py`：60 Hz 模拟，包括子帧命中检测、停帧冻结、目标受击反应、粒子与镜头震动。
- `tools/art_v5/moves.py`：四个招式的姿势序列、挥砍平面、刀身角度时间线、刀光与命中参数。
- 依赖沿用 `requirements.txt`（Pillow / NumPy / SciPy / imageio-ffmpeg），GIF 由 ffmpeg 生成调色板并编码。

## 五、已知限制

1. **身体帧是复用的**：躯干没有横斩应有的扭转，跨源图衔接时腿部站姿会有轻微跳变。专用横斩关键帧需要“带参考图”的生图；本机 `image_gen` 只能文生图、不能传参考图，试生成的一张造型细节与定稿不一致（只留在 `temp/`，未入库）。另外两次生图授权请求都超时了。
2. **这是离线渲染，不是 Godot 实机**：实装时需要移植 WeaponRig 的 3D 投影、刀光 shader（或预烘焙序列帧）、子帧冻结和受击分层。
3. 怪物仍使用 V2 哥布林；音效未接入预览。

## 六、待确认决策点

1. 方向是否认可：一 / 二段左右横斩、三段竖劈、拔刀斩用“一闪 + 延迟斩”。
2. 刀光色板：统一银白，还是按职业区分（狂战士血红、剑魂青蓝）。
3. 是否补专用横斩身体关键帧：在另一台机器上用带参考图的生图管线，或在本机做文生图（造型一致性有风险）。
4. 认可后的实装方式：Godot 内实时绘制（shader，可随刀身动态变化），或像 DNF 一样预烘焙特效序列帧（品质可控、改动成本高）。
