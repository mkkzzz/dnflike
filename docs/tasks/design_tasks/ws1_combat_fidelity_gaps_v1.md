## 一、规则

1. 游戏画面里出现的每个元素（图像、字形、数字、条、框、图标、特效、闪烁、阴影、声音）都必须来自原版资源并按原版规则表现。
2. 程序绘制的矩形/圆弧、系统字体、自制颜色/渐变都算占位，只允许出现在调试叠加（F2 碰撞、盒体、时间轴）和资源缺失报错页。
3. 找不到原版资源时登记到本表"原版候选"列为待查，或在[28](../../design/28_工作区分工与原版资料共享.md)流程下请 ws2 补资料；不得先画一个替代上线。
4. 框架迁移（F0~F2）不新增任何占位；替换某项时同时交原版来源路径、SHA256 与同屏截图。
5. 游戏内全部中文，不出现韩文（用户2026-10-22，经ws2转达）：原图像素内文字也要实际查看；优先找国服中文版同名资源，没有时按ws2[中文清理记录](../../reports/ws2/2026-10/2026-10-22_游戏中文与原图文字清理.md)的方法处理，不只扫代码字符串。
