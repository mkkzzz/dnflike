# 10001 首副本（森林）设计单

状态：设计已确认（2026-10-16 用户逐条确认）；美术未开工。编号约定：**10001 = 整个副本**，房间编号 10001-01 ~ 10001-05。
流程依据：[23 副本设计工作流](../../design/23_副本设计工作流.md)（步骤 1~4 的产物）；规格依据：[22 资产画面规格](../../design/22_资产画面规格.md)；结构参考：[05 地下城系统](../../design/05_地下城系统.md)。

## 一、定位与边界

| 字段 | 内容 |
|---|---|
| dungeon_id | **10001**（整个副本） |
| 名称 / 代号 | 首副本·森林（暂名，上线前可改） |
| 所属地区 | 首个地区：森林（明亮白天）。编号建议：副本 5 位、按地区分段（地区 1 = 10000 段），后续地区 20000、30000……，规则待更多副本时细化 |
| 战斗定位 | 游戏首个可进入副本、入门难度；BOSS = 哥布林头目（背石筐、投石 + 木棒敲击） |
| 房间结构 | 5 间；顺序可自由配置，唯一硬约束：**最后一间必为 BOSS** |
| 场景基调 | 明亮白天森林；韩式横版手绘、DNF 方向（`handpainted_action_v1`），只用原创素材 |
| 资产规格 | 全部新资产按 [22](../../design/22_资产画面规格.md)：2K 原生 2560×1440/屏，1080p 仅做 0.75 缩放 |
| 明确边界 | 不做高低差（除非后续特殊设计）；背景图不含任何可碰撞物；实体、门按关卡配置摆放；本单只记录设计，不代替出图/实装任务包 |

## 二、房间清单（关卡配置表）

默认连接顺序（可配置调整，BOSS 收尾）：

| 房间 ID | 角色 | 图型（按 [22](../../design/22_资产画面规格.md)） | 出场内容 | 出口 |
|---|---|---|---|---|
| 10001-01 | 入口 | 横幅长图 | 无战斗；氛围与走向引导 | 门 → 10001-02 |
| 10001-02 | 小怪 | 横幅长图 | 普通哥布林若干（数量由战斗配置定） | 门 → 10001-03 |
| 10001-03 | 小怪 | 竖幅图 | 普通哥布林若干 | 门 → 10001-04 |
| 10001-04 | 精英 | 横幅短图 | 精英遭遇（身份待定，见开放项） | 门 → 10001-05 |
| 10001-05 | BOSS | 横幅图（约 2 屏宽） | 哥布林头目 | 通关；无出口门 |

- 图型尺寸默认：横幅短图 ≥3840×1600、长图 5120~7680×1600、竖幅约 2816×2880~4320；具体像素在出图任务包登记。
- 场景统一分层：远景 / 中景 / 可行走路面 / 前景遮挡；**路面必须醒目可读**（踩实路带、边界清晰），避免角色踏空感。
- 竖幅房间默认：行走面仍为横向一条地面线、门开在横向一端；纵向空间用于高耸景物与镜头余量。
- 每间房清理开门；门的连接由关卡配置决定。

## 五、产出顺序

1. **风格确认图**（评审媒体，不产出正式资源）：入口场景 1 屏 + 实体/门样式样板，一次确认画风、色调、路面与实体风格。
2. 认可后批量：5 张背景（分层、2K 原生）→ 实体全套状态 → 门两状态与动效说明。
3. 组合验收：背景 + 实体 + 门 + 怪物按配置摆好；2K/1080p 抽查。
4. 音频清单与制作（按 19/20）。
5. 实装（另立任务）：关卡配置、碰撞、门与破坏物事件；本单不含实现。
