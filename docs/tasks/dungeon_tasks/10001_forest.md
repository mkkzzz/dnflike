## 二、房间模块池

房间模块 = 可复用单元：一张背景图 + 图型 + 统一门位；不属于某个布局，可被同副本任意布局引用（跨副本复用另按 23 登记）。

| 模块 ID | 名称 / 角色 | 图型（按 [22](../../design/22_资产画面规格.md)） | 说明 |
|---|---|---|---|
| 10001-R01 | 入口（长） | 横幅长图 | 无战斗；氛围与走向引导 |
| 10001-R02 | 小怪（长） | 横幅长图 | 普通哥布林若干（数量按实例配置） |
| 10001-R03 | 精英（短） | 横幅短图 | 精英遭遇（身份待定，见开放项） |
| 10001-R04 | 小怪（竖） | 竖幅图 | 普通哥布林若干（数量按实例配置） |
| 10001-R05 | BOSS 房 | 横幅图（约 2 屏宽） | 哥布林头目；布局收尾，无出口门 |

- 图型尺寸默认：横幅短图 ≥3840×1600、长图 5120~7680×1600、竖幅约 2816×2880~4320；具体像素在出图任务包登记。
- 原设计分层：远景 / 中景 / 可行走路面 / 前景遮挡；**路面必须醒目可读**（踩实路带、边界清晰），避免角色踏空感。
- 当前低清环境批采用远景树林与地面一次生成、不分层，实体与门仍独立；木桩采用棕色木材并配独立接地阴影。2026-10-16 用户认可 v3 并锁定该画风/模式，授权继续低清一版；不代表剩余批次已生成或实机已验收，原生 2K 目标暂不变。

## 三、布局与拼装规则

布局 = 有序的房间序列 + 每间实例配置（怪物投放、实体/门摆放）。同一副本可有 1~N 套布局；**布局是配置层，新增/调整布局不产出新美术**，除非引入新房间模块。

现行布局 **10001-A（基础）**：

| 位置 | 房间模块 | 出口 |
|---|---|---|
| 1 | 10001-R01 入口长 | 门 → R02 |
| 2 | 10001-R02 小怪长 | 门 → R03 |
| 3 | 10001-R03 精英短 | 门 → R04 |
| 4 | 10001-R04 小怪竖 | 门 → R05 |
| 5 | 10001-R05 BOSS 房 | 通关；无出口门 |

拼装规则：

- 房间之间可从 **上 / 下 / 左 / 右** 四个方位连接（2026-10-16 用户确认）；门位由布局配置决定，每间房清理开门；门与所在边缘对齐，该边留出入画面。
- 首间必须是入口房；末间必须是 BOSS 房；中间可用 小怪 / 精英 / 竖幅 任意组合。
- **同一模块可在同一布局重复出现**（如两个 R02）；重复实例的怪物数量、实体与门摆放按“位置实例”分别配置，不按模块。
- 布局长度自由（最少 2 间：入口 + BOSS）。
- 竖幅房间默认：行走面仍是一整块平地（不做高低差），门可开在任一方位；纵向空间用于高耸景物与镜头余量。
- 新布局 = 房间序列 + 实例配置；门由布局配置自动接下一间，连接关系改配置即可调整。

## 五、非生物实体与关卡门（供布局配置使用）

| 实体 | 状态 | 碰撞 | 说明 |
|---|---|---|---|
| 木桩 | 单态 | 有 | 纯碰撞装饰 |
| 火把 | 火焰循环动画 | 有（细） | 后续可接动态光源 |
| 果树 | 有果 / 无果 | 有 | 可打击掉果，果子为拾取物 |
| 木栅栏 | 完好 / 半破坏 / 破坏残骸 | 有 | 可打击；打击配合特效 |
| 骨堆 | 完好 / 半破坏 / 破坏残骸 | 有 | 可打击；打击配合特效 |
| 灌木、石块 | 单态 | 小 | 小装饰与小碰撞 |

- 关卡门：木质栅栏 + 藤蔓门框 + 门框灯；未开启 / 开启两状态，开启态灯闪烁动效。
- 门需 **四方位变体**（同款式）：上（地面远边，正面朝镜头）、下（画面底边，背面只露上半截）、左 / 右（侧向，互为镜像可复用）。
- 每项登记脚底锚点、碰撞框、破坏阈值与状态切换时机（由布局/战斗配置定义）；图片只交付各状态。

## 六、产出顺序

1. **风格确认图**（评审媒体，不产出正式资源）：入口场景 1 屏 + 实体/门样式样板，一次确认画风、色调、路面与实体风格。
2. 认可后批量：5 个房间模块背景（R01~R05，分层、2K 原生）→ 实体全套状态 → 门两状态与动效说明。
3. 组合验收：按布局 10001-A 摆好背景 + 实体 + 门 + 怪物；2K/1080p 抽查。
4. 音频清单与制作（按 19/20）。
5. 实装（另立任务）：布局配置、碰撞、门与破坏物事件；本单不含实现。
6. 新增布局（10001-B…）：只做配置拼装、复用现有模块；引入新模块时才追加出图任务。
