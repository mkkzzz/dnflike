## 2. 本批清单与排除项

下表是本轮制作边界；不改 [D031](../../design/决策清单.md) 的长期总目标，也不改玩法、技能或音效分类。

| 组 | 动作/状态 | 完成标准 |
|---|---|---|
| 移动 | 待机、行走、奔跑、起停、转向/接续 | 呼吸自然，左右腿完整交换，接地不滑；上下纵深移动复用合格步态 |
| 空中与回避 | 起跳、上升、顶点、下落、落地缓冲/恢复、后跳 | 不把屈膝拉等高；动作与外部高度分离；短长跳复用真实物理时钟 |
| 普通攻击 | 地面三连 attack1/2/3、跑动 X 攻击、空中 X 攻击 | 起手/释放/接触/余势/恢复及连段转换明确；跑动/空中 X 按当前操作链纳入 |
| 防御 | 格挡启动/保持/结束、精准格挡成功反应及接续 | 手、身体、武器同步；成功反馈不靠特效掩盖缺姿势 |
| 受击与结束 | 地面受击、空中受击/浮空、倒地、起身、死亡/复活所需表现 | 先核对实际状态映射，专用姿态/共享姿态逐项登记，不以 down 复用宣称全套完成 |

本批排除：Z 上挑、拔刀斩、血怒、怒斩、连突刺及其他职业/通用技能与 buff 专属动作。旧 D031 把上挑、拔刀斩列入长期重做目标，此次因用户“不含技能”后置。当前 X 的跑动/空中攻击纳入本批仅是制作范围，不替未决音效分类作决定。

## 4. 铺量前必须跑通的换武器小样

1. 用 c3 比例重做一组 attack1 代表姿势，覆盖蓄势、挥出、接触、余势、恢复和必要前后遮挡；同图保留直立标尺。先看裸动作与 V6 对比，按18现有 G2 规则判去留，不重置迭代次数。
2. 带标准太刀的设计原画只用于锁住握法与身体发力。成品须去掉整把固定武器，包括刀身、镡、刀柄；补出握持通道和被武器遮住的身体，拆出压在刀柄前的手指层。画上去的备用刀柄/入鞘武器也不能留成第二把固定刀。
3. 交付身体、独立武器、手指遮挡，以及握点、角度、护手/刀尖、前后遮挡数据；刀鞘/入鞘外观随武器配置独立处理，无对应鞘时可隐藏，不固定烘进可换武器身体。
4. 用**完全相同的身体帧和时钟**挂回标准太刀，核对是否还原原持刀设计；再挂巨剑、短剑。依 D026 全部单手持，不因换武器重画身体、不改动作节奏、不靠临时空手姿势随便挂刀。
5. 回放全招、左右朝向、身前/身后切换和握手近景，检查双刀、残留固定刀、漂浮握柄、穿衣穿手、刀尖/刀光错位。三种武器均通过 G3，且 G1/G2/G4 合格后再铺量；所有预览使用同一真实分层包。

当前已完成[代表 attack1 三武器结构试验](../../reports/ws2/2026-10/2026-10-17_V7普攻三武器分层验证小样.md)：新无武器身体/手部帧共用、可实际回放。已补原骨架刀向/刃向的正交投影；**完整G3仍待人工评审**，遮挡/原设计还原与动作画质未获认可，不铺量。原c3比例原画含刀与入鞘刀柄，继续只作设计参考，不作为可换武器身体成品。

## 5. 规格、来源与加工

| 项 | 约定 |
|---|---|
| 尺寸 | 按2K视口角色站高约380px；当前单层画布1024×800、root锚点(448,720)为起点，越界动作只扩透明画布并登记，不缩人物凑框；1080p只做0.75缩小 |
| 比例 | 同源直立身高标定，逐姿态头部尺度检查；不按下蹲外接框归一化，不放大源像素 |
| 像素/混合 | RGBA、straight alpha、normal；武器/身体/手指共用色彩和照明，禁止重复预乘与未知后处理 |
| 坐标/时钟 | 默认朝右、y向下、60Hz整数duration_ticks；root、握点、护手、刀尖同步变换；命中停帧不烘进基础动画 |
| 分层 | 武器后段 → 身体 → 武器前段 → 手指；具体逐帧遮挡用真实包数据定义，不用一条固定层序代替所有姿态 |
| 参考/生成 | standard_v1身份＋已认可c3比例＋动作/握点引导；后续每次真实传入哪些图、完整prompt和能力限制随新源图记录，不预填“已生成” |
| 加工入口 | 比例/身体导出用 `tools/check_actor_proportions.py` 与 `tools/explore/standard_actions_pilot.py`；本轮 `tools/explore/swordsman_layer_trial.py` 已支持骨架投影与分层试验，全身深度求解与游戏适配未实现，不是正式万能管线 |
