## 一、标准身份规格（漂移项按建议取值，待负责人确认）

| 项 | 规格 |
|---|---|
| 体型 | 精瘦健壮的青年男性，约 7.5 头身 |
| 发型 | 银白乱刺发，左前额一缕深红挑染 |
| 眼睛 | 深灰色（V6 原图不是红瞳） |
| 风衣 | 黑皮长风衣过膝，立领 + 翻驳领，领口 / 衣襟 / 内摆露深红内衬；袖口到前臂中段 |
| 内衣 | 黑色贴身高领 |
| 束带 | 胸前两道银扣皮带 + 银扣腰带 |
| 手臂 | 双手与前臂缠深红布绷带到肘部，露指，无火焰，手臂上**没有金属护具** |
| 下装 | 黑长裤塞进黑靴，深钢色护膝 + 护胫 |
| 刀 | 黑柄、深红菱形缠绳、圆形铁镡，黑漆刀鞘带银色尾端，挂左腰 |

## 二、候选与自检

| 候选 | 内容 | 优点 | 问题 |
|---|---|---|---|
| `sheet_main_c1` | A1 四向 + A4 素体 | 最接近 V6；绷带和胸前束带在每个视角都一致 | 侧面缺护膝护胫；背面看不到刀鞘；素体多了护膝 |
