## 首批本地来源与依赖

- 图像来自本机“情怀60复古”客户端 ImagePacks2，经本轮本地资源库筛选；优先常规 sprite 命名包。此选择不冒充原客户端补丁优先级。
- 动作配置来自同目录的 111Script.pvf 备份。实际运行中的 PVF 与此备份尚未证明一致；只接入已找到完整图像的片段。
- 选中身体、默认衣装/头发/鞋裤、三武器、两种哥布林图像；运行包与预览共用同一套原生图集。
- 场景选用原始森林远景、中景、地面图块、树/石/草、方向门栏；本关为验证布局，不宣称恢复原版地图文件。
- UI 采用原始 HUD 部件；血蓝、技能冷却、房间小地图和结算由新版真实状态驱动。
- 音频采用原客户端对应声音与森林 BGM，保持原 Ogg 编码。本轮是用户授权的原资源本地适配，不是按 20 模板新制作音效或给旧工程替换音频。
- 保留原始音频的注释问题与来源哈希，不将其宣称为已符合旧工程48kHz/单声道/三变体生产规范。

## 玩法接入范围

1. 方向移动、同向双击跑动、跳跃、后跳、格挡、受击与死亡。
2. 地面三连、跑动攻击、空中斩、上挑浮空、浮空追击与落地恢复。
3. 剑魂的拔刀斩/连突刺，狂战士的血怒/双段怒斩；MP、CD、攻速、霸体承伤、出血。
4. 哥布林追击与原生攻击节奏；硬直、浮空、弹地、倒地、起身、死亡。
5. 命中停帧、白闪、震动、原生命中特效与伤害跳字。
6. 五房路线为右/上/右/上；未清房前后门均关闭，清房后可往返，破坏物与清房状态保存。
7. 领主房清完直接结算，所有门关闭；失败与胜利均可重新挑战。

## 表现与玩法之间的显式适配

- 前两刀身体 ANI 缺少攻击框，命中窗口按出刀姿势单独配置；第三刀及连突刺参照原 ANI 的攻击框时间段。
- 起手、有效段、收招依照动作时间线组织；技能缓冲不得截断当前动作的最后有效攻击段。
- 原攻击框为六维盒，首轮保留原字段作为依据；运行判定采用原生坐标下的朝向距离、纵深带和高度条件。尚未实现完整原版盒体解释器。
- “怒斩”沿用我们已有双段/出血玩法，选用资源中十字双斩姿势适配；不冒充原版同名技能的完全还原。
- 门栏根据四方向使用原始画面方向，清房后移除阻挡并显示出口提示；没有把侧门纹理旋转成上下门。
- 原生地面透明留白显式裁去，画面仍用原像素平铺；物件遮挡按根部深度独立排序。
- 声音由对应动作/事件触发；拔刀蓄势声与550ms出刀声分开。没有核验原客户端所有 ACT/ALS 嵌套效果。
