# 普通哥布林标准原画 v1

## 1. 身份与需求

| 字段 | 内容 |
|---|---|
| task_id / asset_id | goblin_standard_v1 / concept.enemy.goblin.standard |
| revision / replaces | v1 候选；拟作为旧哥布林身份的新设定，批准前不替换任何资源 |
| asset_type / workflow | 怪物标准原画；14 文档 E 路线，静态设定参考 A |
| style_profile / theme_pack | handpainted_action_v1 / dark_fantasy_v1 |
| owner / integration_owner | ws1 / 后续接入待分配 |
| scope | 全身候选与原画交付路径；不做动作帧、特效、音效或游戏接入 |
| lifecycle | spec_ready；生图确认超时取消，首轮源图尚未生成 |

2026-10-16 用户需求：旧哥布林头偏大，比例不对；旧画风方向正确；普通攻击使用小木棒槌。

保留绿皮、尖耳、黑乱发、黄眼、简陋棕皮革和布料的普通怪辨识。缩小头部，不把身体整体拉长成高个兽人；保留矮小、灵活、有一点狡黠的气质。简化疙瘩、扣件和肌肉碎细节，不改变手绘风。

首轮默认：约 4.5 头身（头高不含头发/耳朵）；怪物站直高度约玩家 70%，是设定目标而非引擎配置改动。肩背略前倾，腿不要深蹲挤短。头和四肢比例以实际出图评审为准。

武器默认：右手单手握短柄、粗圆头的整木棒槌，无钉、无刃、无金属包头，不做巨型狼牙棒。首轮是低位持械标准站姿，不以特效或夸张攻击姿势遮挡身材。

待用户看图确认的设计点：是否采用“小头、矮而灵活”的方向；木棒槌是否符合所指的造型（默认不是横头 T 形木锤）。数值配置不单独占确认环节。

## 2. 原画产出路径与批准门

| 阶段 | 产物 | 完成条件 | 本轮范围 |
|---|---|---|---|
| P1 规格与首轮样张 | 任务包、1 张朝右三分之四全身候选、完整生成记录、旧新比例对照 | 主体/手/脚/武器完整；用户能直接找到图 | 本轮执行 |
| P2 造型评审与迭代 | 用户批准文件与范围，或新候选及退回原因 | 比例、画风、气质、武器获认可 | 等用户看 P1 图 |
| P3 标准设定补齐 | 正/右侧/背视图、头部表情、色板、武器侧视与握点、关键服装材质 | 各视图身份一致；武器尺寸与握法明确 | P2 通过后制作，不自动量产 |
| P4 母版锁定与静态交接 | 母版、透明主体、weapon/部件裁切、manifest、校验与组合预览 | 原图/规格可追溯、加工可复现、用户认可标准设定 | 原画范围最终交付 |
| P5 后续动作制作 | 待机/移动/攻击/受击/浮空/倒地/起身/死亡任务包 | 能真实传入母版的工具、动作相位与游戏契约明确 | 本轮不做，另立任务 |

不承诺仅凭文字生图自动统一多个视图。P3 若出现身份漂移就退回，不把另一只哥布林拼入标准设定。没有参考图生成入口时，P5 不记为可执行完成。

### 文件归属

- 任务与批准：本文（唯一评审记录入口）。
- 源图与生成记录：art/characters/goblin_standard_v1/；新候选保留原始输出，不覆盖旧图。
- 用户评审媒体：docs/previews/goblin_standard_v1/；旧新对照必须注明静态比例模拟，不冒充实机。
- 后续锁定入口：该源目录 manifest.json（P4 才建立；当前没有正式母版）。
- 接入目录：game 仅由后续接收区在批准后修改；本轮不修改。

## 4. 静态规格与后续动作意图

- 首轮目标画布 1024×1024、sRGB、无文字/水印/场景/特效，背景为平灰色；实际文件格式与 alpha 另验。
- 朝右的横版三分之四视角，全身、两脚和棒槌完整，图内四周留白；侧视不冒充当前候选已完成。
- 主色为橄榄绿、棕皮革/褐布、黑发、黄眼；无重甲、精英冠饰、魔法光环或大号武器。
- 本轮不重复旧 2px/40 阶后处理、不调游戏 model_scale/hurtbox、不用等比放大冒充改头身比例。
- 普通攻击后续意图：举棒蓄势 → 过顶 → 向前下砸 → 余势 → 回到待机；当前只登记，不生成动作。
- 固定武器可采用身体/木棒同帧；独立武器原画用作尺寸与握法规格，不宣称旧 actor 已支持换武器。
- 动作导出仍需 root/画布/60 Hz 相位标定；不能直接把静态原画当动作帧实装。

验收项（当前没有图片，以下均未执行）：
- [ ] 比旧版明显减小头部占比，躯干和腿有独立体积，不是大头短腿 Q 版。
- [ ] 保持绿皮、尖耳、黑发、黄眼、旧手绘材质与描边方向。
- [ ] 木棒槌较小、无钉刺；握法清楚，手/柄没有穿插或悬浮。
- [ ] 全身和武器无裁切，平灰背景没有特效干扰。
- [ ] 旧新相同主体高度对照、缩略可读性检查；明确为离线静态对照。
- [ ] 文件可打开，尺寸/颜色模式/透明度及生成来源已记录。

用户批准：无。当前未获批准：新头身比例、武器造型、母版与后续动作。技术检查通过也不能代替用户认可。

## 7. 交接与后续

本轮实际发布对象仅为本文的规格/产出规划及生成调用记录。没有源图候选、评审对照或正式可实装怪物。图片生成成功后再补登记对应入口；按仓库协作规则提交/推送，只 stage 本轮文件。

后续动作区需要另行确认：标准母版、固定武器尺寸/握点、动作清单、源姿势相位、锚点、朝向、战斗窗口、旧新切换及实机回归。不得将未执行的实机接入/验收写为完成。
