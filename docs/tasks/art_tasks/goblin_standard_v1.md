# 普通哥布林标准原画 v1

## 1. 身份与需求

| 字段 | 内容 |

2026-10-16 用户需求：旧哥布林头偏大，比例不对；旧画风方向正确；普通攻击使用小木棒槌。

保留绿皮、尖耳、黑乱发、黄眼、简陋棕皮革和布料的普通怪辨识。缩小头部，不把身体整体拉长成高个兽人；保留矮小、灵活、有一点狡黠的气质。简化疙瘩、扣件和肌肉碎细节，不改变手绘风。

首轮默认：约 4.5 头身（头高不含头发/耳朵）；怪物站直高度约玩家 70%，是设定目标而非引擎配置改动。肩背略前倾，腿不要深蹲挤短。头和四肢比例以实际出图评审为准。

武器默认：右手单手握短柄、粗圆头的整木棒槌，无钉、无刃、无金属包头，不做巨型狼牙棒。首轮是低位持械标准站姿，不以特效或夸张攻击姿势遮挡身材。

待用户看图确认的设计点：是否采用“小头、矮而灵活”的方向；木棒槌是否符合所指的造型（默认不是横头 T 形木锤）。数值配置不单独占确认环节。

## 2. 原画产出路径与批准门

| 阶段 | 产物 | 完成条件 | 本轮范围 |
|---|---|---|---|
| P1 规格与首轮样张 | 任务包、1 张朝右三分之四全身候选、完整生成记录、旧新比例对照 | 主体/手/脚/武器完整；用户能直接找到图 | 本轮执行 |
| P2 造型评审与迭代 | 用户批准文件与范围，或新候选及退回原因 | 比例、画风、气质、武器获认可 | 等用户看 P1 图 |

不承诺仅凭文字生图自动统一多个视图。P3 若出现身份漂移就退回，不把另一只哥布林拼入标准设定。没有参考图生成入口时，P5 不记为可执行完成。

## 4. 静态规格与后续动作意图

- 首轮目标画布 1024×1024、sRGB、无文字/水印/场景/特效，背景为平灰色；实际文件格式与 alpha 另验。
- 朝右的横版三分之四视角，全身、两脚和棒槌完整，图内四周留白；侧视不冒充当前候选已完成。
- 主色为橄榄绿、棕皮革/褐布、黑发、黄眼；无重甲、精英冠饰、魔法光环或大号武器。
- 本轮不重复旧 2px/40 阶后处理、不调游戏 model_scale/hurtbox、不用等比放大冒充改头身比例。
- 普通攻击后续意图：举棒蓄势 → 过顶 → 向前下砸 → 余势 → 回到待机；当前只登记，不生成动作。
- 固定武器可采用身体/木棒同帧；独立武器原画用作尺寸与握法规格，不宣称旧 actor 已支持换武器。
- 动作导出仍需 root/画布/60 Hz 相位标定；不能直接把静态原画当动作帧实装。
