# 逐件原武器外观 v1

用户2026-10-29明确要求不同武器物品按各自外观同步场景角色。沿用原版像素资源路线与既有角色动作，不生成新原画或音频；当前全部可穿戴原武器一起接入，不只交付几个样例。

| 字段 | 约定 |

| task_id / asset_id | dnf_weapon_appearance_v1 / actor.player.weapon.original_item |

| 影响 | 城镇角色、战斗角色、后跳残影、角色读档和换装显示；不改变战斗动作、判定、AI和伤害 |

## 规格与来源约束

- 原ID独立映射外观，保留模型/配色二元编号、EQU/LAY/ANI/IMG路径与SHA256；不能只用太刀/短剑/巨剑类别代替。
- 按源武器ANI的IMG模板代入variation，保留前后层、各动作帧号、时长、坐标与旋转。不得猜测后缀或用同类默认图掩盖缺失。
- 原资源确实共享同一模型/配色时去重存储，仍保留每个物品的绑定，不人为改色制造“不同”。
- 角色身体共享无武器底图；保留现有战斗动作层序，移动/奔跑使用已有完整腿部分层。武器后层650位于身体后方，前层2790位于身体前方。
- 图片逐帧只裁透明边并保存原偏移；原尺寸、原RGBA，不放大、平滑或重画。图集宽2048，实际高度及每帧尺寸由manifest逐项登记，不用统一画布拉伸源帧。
- 城镇与副本共用同一外观身份。镜像、离地高度、闪白、着色跟随角色；绝对ANI时钟由角色输入，不另起动作时钟。残影复制当前武器外观。
- 换装只有候选存档成功后才换外观；读档恢复绑定，卸下武器显示空手。此任务不取消现有“仅城镇换装”规则。
- 旧样板物品的外观适配单独登记，不冒充原ID来源；未提供逐件字段的独立战斗调用保持旧包兼容。
