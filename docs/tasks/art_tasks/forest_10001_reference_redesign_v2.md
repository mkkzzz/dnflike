- 输入均为仓库现有项目美术；仅沿用已有批准用途，无外部图片或外部游戏素材导入。

## 4. 五房共同规格与区别

共同基准：低机位侧向三分之四横版视角，轻微俯看平地；屏内后草边约在 y=40%，其下为宽阔可行走平面；树干沿后方横向排列，包括画面中部，不从两侧夹出中央通道。青灰绿远景、深橄榄/苔绿树冠、灰棕树皮、暖棕细土地面；左上柔和日光，背景低对比。

| 房间 / 稳定子 ID 尾段 | 正式原生画布 | 同风格内的环境区别 | 本轮实际 |
|---|---|---|---|
| R01 / r01.background | 5120×1600 | 疏密适中的入口林地、平稳横向引导 | 一屏样张 c1/c2；不是长房成品 |
| R02 / r02.background | 5120×1600 | 同树种与材质，树群间距略变化、远林更密 | 未生成 |
| R03 / r03.background | 3840×1600 | 同光向的紧凑林地，略密的后草带 | 未生成 |
| R04 / r04.background | 2816×3200 | 同林地增补高处树冠与纵向镜头余量，地面仍平坦 | 未生成 |
| R05 / r05.background | 5120×1600 | 成熟树群横向散布、宽阔战斗空地；不加祭坛或新题材 | 未生成 |

所有房间真实新绘，不用镜像/平铺凑足尺寸；门、木桩、果树、火把、栅栏、骨堆及独立灌木/石块不烘进背景。样张为森林与地面一体 RGB、不透明 normal；原点左上、x 向右 y 向下，不翻转。正式分层、拼缝、世界坐标、可行走边界与相机余量仍需由实际房间包逐项校验；当前样张不是分层成品。静态图时钟不适用。

## 6. 加工与复现

源图保留工具原始字节，未裁切、调色、放大或抠图。包入口：[manifest.json](../../../art/concepts/scenes/forest/10001/reference_redesign_v2/manifest.json)。

从仓库根执行 `python art/concepts/scenes/forest/10001/reference_redesign_v2/build_review.py` 可重建检查报告、标准图/c1/c2 等宽对照板及 c2 的 0.75 缩样。只缩小评审副本，不改源图；生成模型具有随机性，不声称可逐像素重生原画。

## 9. 防复发

上一批根因是只传文字、误读横向树林，并用镜像延伸强化夹景；这轮保留真实参考输入与两次原图，先检查构图再给用户评审。新的能力限制是 prompt 中写尺寸并不能保证实际尺寸；必须读 PNG 实际像素，未达到原生规格时只标样张，不伪报正式成品。
