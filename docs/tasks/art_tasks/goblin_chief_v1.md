2026-10-16 用户需求：形象参考普通哥布林，作为新手关 Boss；背一筐石头，会丢石头和木棒敲人。

保留普通哥布林的尖耳、黄眼、黑乱发、尖牙、粗糙绿皮、矮壮体态与旧手绘气质。不做瘦长绿皮人，也不把普通怪等比放大当新 Boss。

头目区别默认：更宽肩/粗前臂/腹部，眉上旧伤和一片简陋肩垫；背有装灰色石头的藤编筐，两道负重肩带。木棒沿用部族木头/粗铁钉材质，一手握棒、一手握石展示用途。无王冠、华丽金属甲或魔法光环。

配置默认：站立身高约普通哥布林 1.2 倍；石筐不高过发顶，露筐口与石块，不盖住脸；投石可单手拿，木棒不能大到像树干。当前静态图尚未与实机标定，不把 prompt 比例当已达成。

用户评审的设计点：是否认可这种“背石筐的粗野头目”身份，以及木棒/石筐对轮廓的占比；数值无需单独拍板。

后续动作意图（不是本轮已经制作）：
- 投石：从筐口取石 → 肩后举石/瞄准预警 → 向前投掷 → 随势 → 回待机。木棒低位保持，不能多画一只手；石头与手分离后才是投射物。
- 敲击：握棒举起、重心蓄势 → 向前下砸 → 余势 → 回待机。石筐随身体负重摆动，不能插入躯干。
- 待机/移动/受击/浮空或硬直/倒地/死亡需按实际 Boss 机制另列；不沿用普通怪配置就称完成。

## 4. 后续原画路径

1. c1 造型评审：怪物身份、石筐/木棒、脸与体态是否合适；不满意新开 c2，不覆盖 c1。
2. 批准后优先补侧/背视图与“手从筐中取石”的设定、筐的绑带/筐口、独立石头与木棒尺寸/握点。
3. 标定同场比例和材质色板，按需要处理透明背景、裁切部件，锁定标准母版及 manifest。
4. 另立动作/技能资源任务：演员、石头投射物/轨迹、预警、接触、受击与音效事件，各自分配 ID；需要真正可传母版的生成入口。
5. 原画/动作认可后才接入游戏 AI 与事件，录实机并验收；本轮不修改 `game/`。
