# 战斗 Demo V3：武器分层与手感打磨

日期：2026-10-14。目标是把现有三波战斗 Demo 的角色动作、基础操作、连段、视听反馈和持续打桩体验向前推进，并为后续可更换武器的装备系统保留正确的表现结构。

本轮已完成可操作的战斗与连段训练版本。真实渲染运行、无 `.godot` 缓存的新副本导入运行，以及 30 / 120 FPS 渲染步长检查均得到 `COMPLETE checks=83 failures=0`。这些检查证明指定行为、资源导入和流程可以重复运行；“是否达到市场精品独立游戏水准”仍需要玩家实际试玩、听音与反馈评估，不能由自动断言证明。

## 运行与操作

在工程根目录启动：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run_demo.ps1
```

入口保留鬼剑士、狂战士、剑魂选择、三波遭遇战、胜负结算和重玩，另增加“连段训练”。

| 输入 | 行为 |
| --- | --- |
| ← / → | 行走；同向双击或按住 Shift 奔跑 |
| ↑ / ↓ | 调整战斗纵深 |
| C / 空格 | 起跳；松开缩短上升，按住保持完整跳跃 |
| X | 地面三连；奔跑中冲斩；空中空斩 |
| Z | 上挑；命中后可接 C 起跳追击 |
| V | 正面格挡；起手短窗口可精确格挡 |
| ↓ + C | 后跳 |
| A / S | 当前职业的两个代表技能 |
| 1 / 2 | 生命 / 魔力药水，共享冷却 |
| Esc / R / F1 | 暂停 / 重玩 / 操作提示 |
| 训练中的 Tab / F2 | 重置训练 / 切换无限补给与实战蓝耗、冷却 |

实机记录：[真实输入演示录像](previews/combat_v3_showcase.mp4)、[训练画面](screenshots/demo_v3_training.png)、[武器分层画面](screenshots/demo_v3_weapon.png)。录像展示实际输入驱动的跑动、冲斩、跳跃、空斩、上挑与职业技能。

## 身体动作与独立武器

运行时有 **20 个主角动作，使用 73 个独立身体源姿势**。walk、run、attack1、attack2、attack3、upper、air_attack、dash_attack 八个核心动作各有 8 个不同的实际源姿势；核心动作没有用重复图片或图片交叉淡入填充帧数。横斩、反撩、重劈、上挑、空中下劈和奔跑切入分别拥有身体与衣摆动作。

身体源图完全去除武器、刀柄和剑鞘。统一帧画布为 320 × 248，脚底 root 为 `(144, 230)`，站姿约 190 px。整张源 sheet 按统一比例缩放；跑动腾空帧使用固定的虚拟地面基线，避免追随鞋底逐帧移动锚点。

每一帧都有相对脚底、未镜像的 `hand` 握点、刀向 `angle`、前后遮挡 `layer` 和源姿势记录。`phase_frames` 把准备、出手、收势与战斗帧表对应，多段技能额外声明 `segments`。`AnimLib` 读取这些阶段信息，攻速变化与取消后不会继续播放过期动作。

`WeaponRig` 作为角色子节点独立渲染刀身、刀柄、护手和材质高光。身体、握点与武器共同读取 `body_transform()`，只做一次朝向镜像；前后层级与握拳覆盖让武器保持在手里。刀向在动作阶段内平滑推进，地面招式限制刀尖穿入地面，真实刀身覆盖也参与当前近战判定，避免“画面刀尖碰到、判定却没到”的明显落差。

默认武器 profile 为“墨钢长刀”。`weapons.json` 可独立描述长度、曲度、宽度、护手、握柄与配色；验收用短刀 profile 证明武器几何改变时身体贴图无需重做。**本轮没有开发背包、装备属性、换武器操作或切换 UI**；这里完成的是未来装备系统需要的身体与武器分层结构。

素材来源、提示词、校准、动作复用说明见 [美术源图记录](../art/sheets/v3/README.md)。烘焙脚本为 `tools/bake_body_v3.py`，运行时产物位于 `game/assets/actors_v3/`。

## 移动、跳跃与状态衔接

所有新增手感参数都进入 `player.json`、`moves.json`、`skills.json`，战斗帧表仍以项目的 **60 Hz 物理 tick** 为基准。

| 参数 | 当前值与作用 |
| --- | --- |
| 走 / 跑速度 | 225 / 450 px/s；分别使用 walk / run 动画 |
| 走 / 跑加速 | 5200 / 5400 px/s²；起步立即响应、短时间达到目标速度 |
| 地面刹车 / 转向加速 | 6500 / 12500 px/s²；抬键迅速停稳，反向输入立即改变朝向 |
| 同向双击窗口 | 250 ms；同时保留 Shift 奔跑 |
| 起跳速度 / 重力 | -780 px/s / 2500 px/s² |
| 起跳缓冲 / 土狼时间 | 各 6 个物理帧 |
| 松键短跳 | 上升速度乘 0.62，并限制剩余上升速度到 -500 px/s 以内 |
| 普通行动输入缓冲 / 连段衔接窗口 | 14 / 16 个物理帧 |
| 纵深速度 | 100 px/s；空中纵深控制为地面的 0.65 倍 |

跑跳保留水平惯性，空中有可调加速、转向与轻微阻力；起跳、攻击与技能切换按招式保留合理动量，收招逐渐减速。起跳伸展、落地压缩、呼吸与微小移动倾斜只影响表现变换，不改变实际受击盒。走跑动画速度跟随实际移动速度，脚步按移动距离触发。

起跳只消费一次输入边沿，按住跳跃不会在落地后自动连跳。空中死亡后角色继续落地；重玩清空输入、跳跃、空斩次数、惯性、取消状态、冷却、buff、视觉变形与特效，并处理 teleport 后尚未更新的地面接触缓存。

## 基础连段与取消

三连、冲斩和空斩使用专用招式。基础攻速按浮点数推进真实战斗时钟，当前可配置范围为 0.5–2.2；血怒的 1.3 倍攻速会缩短实际招式时长，不仅改变贴图播放。

下表为 1.0 倍攻速时的帧表，命中停帧另计。取消帧表示动作时钟达到该值后才允许相应衔接；命中与挥空使用不同窗口。

| 招式 | 准备 / 活动 / 收招 | 伤害 | 命中 / 挥空衔接取消 | 命中停帧 |
| --- | --- | ---: | --- | ---: |
| 第一击 | 5 / 5 / 10 | 34 | 8 / 14 | 3 |
| 第二击 | 5 / 5 / 11 | 39 | 8 / 15 | 3 |
| 第三击 | 7 / 6 / 15 | 62 | 14 / 24，第三击不能在此直接重开第一击 | 5 |
| 上挑 | 5 / 5 / 11 | 43 | 10 / 17；命中后第 8 帧可起跳追击 | 4 |
| 空斩 | 4 / 6 / 9 | 29 | 11 / 15 | 3 |
| 冲斩 | 4 / 6 / 14 | 44 | 10 / 17 | 4 |

奔跑 X 在沿朝向速度达到 270 px/s 时触发冲斩，随后可接普攻第二、第三击，或按窗口衔接上挑、职业技能。普通三连有输入缓冲、命中确认取消和收招运动取消；挥空不能使用命中的早取消窗口。

空中 X 触发专用空斩，每次跳跃最多两次；空斩不会增加向上速度或关闭重力。落地空斩缩短为 4 帧衔接，末段可接地面攻击、上挑、技能或防御行动。上挑命中后可以起跳追击浮空目标，目标仍保留浮空时长、倒地和起身保护。

格挡与后跳也按明确窗口取消，不能随意抹掉所有前摇。普通正面格挡减少 80% 伤害；起手 3 帧的精确格挡减少 95% 伤害并给出 3 帧反馈停顿。背后攻击绕过定向格挡。后跳持续 18 帧、后移 108 px，前 7 帧无敌。

## 视听与命中反馈

真实刀根与刀尖驱动刀光，起手、各技能命中段和方向切换划分独立轨迹。命中首次进入 hitstop 时先保留接触样本，再冻结刀光、粒子、浮字和动作时钟；停帧期间继续记录输入，解除后按取消窗口消费。修复了首个接触帧被 freeze 检查跳过、刀光延迟到命中之后的问题。

三连分别使用不同方向与轻重的描线、刃缘亮光和命中火花；冲斩、拔刀、连突增加速度线和短残影。上挑有上升火花；血怒与怒斩使用红橙火星、持续微焰和不同段的斩线。格挡、精确格挡、起跳、落地、急停和转向也有对应细节。镜头震动有幅度上限和衰减，重击与普通命中分级。

声音改为本工程原创的离线程序化分层拟音：**27 类声音，每类 3 个独立变体，共 81 个 48 kHz、单声道、16 bit PCM WAV**。剑挥、肉体与金属命中、靴底与石板接触、格挡、拔刀、怒气和提示音都有不同配方；运行时避免连续重复同一变体，并叠加轻微音高变化、位置声像和距离衰减。声音来自程序化拟音，不能宣称为真实录音；音色真实感仍需要主观试听评估。

声音生成记录见 [音频来源与验证](../audio/combat_v3/README.md)。资产没有下载素材或第三方录音；校验记录表明 81 个文件无削波采样、首尾采样为零，最大峰值低于 0.76 FS。运行时使用优先级与同类节流，并根据活跃声道峰值上界保留混音余量。

效果与声音都有明确容量，持续群怪战斗不会无限追加节点或效果记录：

| 池 / 集合 | 上限 |
| --- | ---: |
| 刀光样本 / 粒子 | 26 / 180 |
| 描线 / 环形效果 / 残影 | 36 / 18 / 10 |
| 浮字 / 闪光 | 32 / 20 |
| 月牙 / 光晕 / 蓄力效果 | 12 / 12 / 3 |
| 空间声音池 | 10 个声道 |

重玩停止声音并清空效果、声音节流、变体历史和混音余量。

## 连段训练与伤害统计

训练场提供两个不会巡逻、追击或攻击的替身，分别用于单体与范围技能验证。替身受到致死伤害仍保留生命，脱离攻击一段时间后返回原位并恢复状态；受击、浮空、倒地和起身过程沿用实际战斗逻辑。

默认无限补给，每个物理帧恢复魔力并解除技能冷却，方便反复研究连段；F2 可切回正常消耗与冷却，Tab 完整重置训练。HUD 显示累计伤害、当前连段伤害、有效命中、最长连击、最近 5 秒滚动 DPS、当前动作与 buff 状态。统计来自目标伤害事件，包含流血跳伤；直接命中负责连击次数，DOT 不冒充额外普攻命中。修复了首击在连段清零顺序中丢失的问题。
