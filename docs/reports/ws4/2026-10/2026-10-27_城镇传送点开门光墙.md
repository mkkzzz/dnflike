# 城镇传送点原版"开门光墙"（上 / 下）

> 需求：2026-10-27 用户「在城镇里，对全部切换地图的传送点添加通用开门光墙（上）和（下）」。
> 范围：仅城镇（`game_dnf/town`）；不改走区、进出判定、存档与战斗。

## 一、素材与依据

| 项 | 内容 |
|---|---|
| 上光墙 | `sprite/common/commoneffect/gate/gateup.img` |
| 下光墙 | `sprite/common/commoneffect/gate/gatedown.img` |
| 引用动画 | `passiveobject/mapobject/pathgate/common/animation/gateall_00.ani`（上）、`gateall_02.ani`（下） |
| 帧参数 | 29 帧 × 60 ms，`items 11 type=2`（加色混合），`items 9` 全白 |
| 证据级别 | E-FILE（库由 111 备份建立；运行期有效 PVF 未锁定，见[证据与版本](../../../design/26_DNF原版拆解_证据与版本.md) 2.1） |

烘焙：`python tools/bake_town_gate_light.py` → `game_dnf/assets_local/town_gate/`（`up_00..28.png`、`down_00..28.png`、`manifest.json`）。
帧按 IMG 自带 canvas 偏移对齐成统一画布（上 82×177、下 107×39），客户端逐帧不抖。素材目录被 `.gitignore` 排除，由 `tools/run_dnf_loop.ps1` 按需自动烘焙（缺完整库时该步输出提示，不影响城镇运行）。

## 二、实装

| 文件 | 改动 |
|---|---|
| `game_dnf/town/gate_light.gd` | 新增：一个传送点 = 一个节点，上下两个 `Sprite2D`；加色混合；29 帧一次性播放后停在末帧；同城多处共用纹理缓存 |
| `game_dnf/town/native_town.gd` | `set_location()` 时重建：`world.portals()` 的每个可见传送点 + 场景的 `dungeon_entry`（副本入口）各一组 |
| `tools/bake_town_gate_light.py` | 新增：从共享库取两族帧并写清单 |
| `tools/run_dnf_loop.ps1` | 新增：清单缺失或工具更新时自动烘焙（非致命） |
| `game_dnf/tests/flow/test_loop.gd` | 新增 2 条断言（见第四节） |

定位规则：

- 锚点 = 传送点矩形底部中心 + 城镇固定的 120px 视觉偏移（角色脚部 = `ground + (0,120)`，与既有标签/角色一致）。
- 上光墙底边贴锚点，向上 177px；下光斑底边贴锚点。
- 深度：整组 `z_index = 矩形底边 y`，与角色按同一逻辑深度排序（角色 `z = ground.y`），所以角色站在门前时遮住光墙、站在门内时被光覆盖。
- 下光斑单独提到 `z = 2400`（地图美术之上、HUD 之下），否则常被门框底边整块挡住，"下有光"看不出来。

## 三、边界与已知取舍

- 传送点矩形是现版 `towns.json` 的走区（E-ADAPT），不是原版 `pathgate` 对象；光墙位置按矩形推断，不是原版门对象的坐标。若后续按原版门对象摆放，锚点需按门对象重算。
- 只在进入城镇/切图时播放一次并停在末帧；原版 `gateall_00` 的 `loop=0` 与之一致，但原版还带 `gateall_01/03`（半透明蓝色变体，用作关闭/暗淡态），本轮未接。
- 未做开关门时序：现版城镇传送没有"关门"状态，光墙常亮。
- 未按方向区分（左/右/上/下门都使用同一组上+下光）。

## 四、验证

- 无窗口套件：`powershell -ExecutionPolicy Bypass -File tools/run_dnf_loop.ps1 -Test` → `[LOOP_TEST] COMPLETE checks=341 failures=0`（原 339，新增 2 条：每个可见传送点都有上下光墙；两族帧均为 29 帧）。
- 采图套件：`-Test -Capture` 在本机离屏窗口下会挂 7 项与真实鼠标/输入相关的既有断言（HP/MP 悬停、五房真实输入等），属取图环境的已知现象；同版本无窗口运行 0 失败，不能用采图结果替代。
- 目视抽查（800×600 预览，脚本用后即删）：`temp/gate800_elvengard_inn.png`、`temp/gate800_elvengard_dungeon.png`、`temp/gate800_hendon_city.png`、`temp/gate800_hendon_main.png`、`temp/gate800_seria_room.png`、`temp/gate800_forest_gate.png`；`temp/` 不入库。
