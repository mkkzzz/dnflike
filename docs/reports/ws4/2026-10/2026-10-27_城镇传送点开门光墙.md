# 城镇传送点原版"开门光墙"（上 / 下）

> 需求：2026-10-27 用户「在城镇里，对全部切换地图的传送点添加通用开门光墙（上）和（下）」，随后「把进入副本的光墙删掉」。
> 范围：仅城镇（`game_dnf/town`）的传送点；不改走区、进出判定、存档与战斗。

## 一、素材与依据

| 项 | 内容 |
|---|---|
| 上光墙 | `sprite/common/commoneffect/gate/gateup.img` |
| 下光墙 | `sprite/common/commoneffect/gate/gatedown.img` |
| 引用动画 | `passiveobject/mapobject/pathgate/common/animation/gateall_00.ani`（上）、`gateall_02.ani`（下） |
| 帧参数 | 29 帧 × 60 ms，`items 11 type=2`（加色混合），`items 9` 全白；**循环播放**（2026-10-27 用户要求改循环） |
| 证据级别 | E-FILE（库由 111 备份建立；运行期有效 PVF 未锁定，见[证据与版本](../../../design/26_DNF原版拆解_证据与版本.md) 2.1） |

烘焙：`python tools/bake_town_gate_light.py` → `game_dnf/assets_local/town_gate/`（`up_00..28.png`、`down_00..28.png`、`manifest.json`）。
帧按 IMG 自带 canvas 偏移对齐成统一画布（上 82×177、下 107×39），客户端逐帧不抖。素材目录被 `.gitignore` 排除，由 `tools/run_dnf_loop.ps1` 按需自动烘焙（缺完整库时该步输出提示，不影响城镇运行）。

## 二、实装

| 文件 | 改动 |
|---|---|
| `game_dnf/town/gate_light.gd` | 新增：一个传送点 = 一个节点，上下两个 `Sprite2D`；加色混合；29 帧循环播放；同城多处共用纹理缓存 |
| `game_dnf/town/native_town.gd` | `set_location()` 时重建：`world.portals()` 的每个可见城镇传送点各一组；**副本入口（`dungeon_entry`）不放**（用户 2026-10-27 要求删除） |
| `tools/bake_town_gate_light.py` | 新增：从共享库取两族帧并写清单 |
| `tools/run_dnf_loop.ps1` | 新增：清单缺失或工具更新时自动烘焙（非致命） |
| `game_dnf/tests/flow/test_loop.gd` | 新增 4 条断言（见第四节） |

定位规则：

- 锚点 = 传送点矩形底部中心 + 城镇固定的 120px 视觉偏移（角色脚部 = `ground + (0,120)`，与既有标签/角色一致）。
- 上光墙底边贴锚点，向上 177px；下光斑底边贴锚点。
- 深度：整组固定 `z_index = -1500`（`native_town.GATE_LIGHT_DEPTH`）——在背景/地面层（-2500~-4000、-3000）之上，在任何角色（`z = ground.y ≥ 0`）与普通物件之下，**保证人物贴图永远压住光墙**（2026-10-27 用户要求）。
- 代价：光墙同时会被门框/雕像等普通层美术遮住一部分，只从门洞透出。若希望无人时更抢眼，可改成"角色靠近时降到 -1500、离开时回到门深"。

## 三、边界与已知取舍

- 传送点矩形是现版 `towns.json` 的走区（E-ADAPT），不是原版 `pathgate` 对象；光墙位置按矩形推断，不是原版门对象的坐标。若后续按原版门对象摆放，锚点需按门对象重算。
- 循环播放是用户要求的表现取舍：原版 `gateall_00/02` 的 `loop=0`（开门一次后停在末帧），现版传送点没有开关门状态，故常亮循环。原版还带 `gateall_01/03`（半透明蓝色变体，用作关闭/暗淡态），本轮未接。
- 未按方向区分（左/右/上/下门都使用同一组上+下光）。
- **副本入口不放光墙**：用户 2026-10-27 明确要求删掉"进入副本"的那组；`dungeon_entry` 仍按原逻辑进出，只是没有光效。

## 四、验证

- 无窗口套件：`powershell -ExecutionPolicy Bypass -File tools/run_dnf_loop.ps1 -Test` → `[LOOP_TEST] COMPLETE checks=343 failures=0`（原 339，新增 4 条：每个可见传送点都有上下光墙；两族帧均 29 帧；光墙始终在人物之下；动画循环回第 0 帧）。
- 采图套件：`-Test -Capture` 在本机离屏窗口下会挂 7 项与真实鼠标/输入相关的既有断言（HP/MP 悬停、五房真实输入等），属取图环境的已知现象；同版本无窗口运行 0 失败，不能用采图结果替代。
- 目视抽查（800×600 预览，脚本用后即删）：`temp/gate800_*.png`（前一轮布置）与 `temp/gate_layer_0/1.png`（本轮层级与循环：角色站在门口时贴图完整压在光墙之上，两帧不同）；`temp/` 不入库。
