# 原地复活与复活币提示

基线 `b5996c5b`。按用户确认的交互实装：死亡后画面中央出现提示，按 X 消耗复活币原地复活，或选择返回城镇；复活保留同一房间、怪物、掉落、任务进度和冒险时钟。

## 一、战斗与事务

- `main.gd` 记录 `combat.player_defeated` 的真实 `event_id` 为 `last_defeat_id`，两条致死路径（持续伤害与普通受击）都走同一个 `emit_player_defeated()`。
- `can_revive(spec)` 绑定 `run_id + room_id + death_id`，拒绝 stale death_id、获胜状态和仍存活的角色；`revive_player(spec)` 保留位置、朝向和技能冷却，重建玩家数值，清除死亡/临时效果，恢复配置的 HP/MP 百分比并给予保护。
- `recovery_bridge` 先写候选存档，成功后才调用战斗复活；战斗端拒绝时保留 `pending_effect`，重试不重复扣复活币。房间、敌人、敌人血量、地面掉落和冒险时钟不重建。
- `profile.resurrection_coins` 为新字段，新角色默认 3 枚；旧档缺少该字段时补 3 枚。每次复活消耗 1 枚，单次冒险最多复活 3 次；金币不再参与复活扣费。初始余额和次数上限为 E-ADAPT，后续经济系统可替换。

## 二、提示与美术

死亡窗口改为中央复活提示：原版复活币图标、复活币余额、按 X 说明、本次冒险已复活次数、HP/MP 恢复比例与保护时间，以及“返回城镇”按钮。保存失败和效果待重试分支仍保留。

新增 `tools/bake_dnf_revive_assets.py` 与 `game_dnf/assets_local/revive_v1/`：

| 资源 | 源路径 |
|---|---|
| 复活币图标 | `sprite/Item/IconStackable.img` 帧 5 |
| 复活币旋转 | `common/etc/animation/usecoin.ani` → `sprite/Common/Etc/UseCoin.img` |
| 粒子 | `common/etc/animation/usecoinparticle.ani` → `sprite/Common/Etc/UseCoinParticle.img` |
| 音效 | `sounds/ui/coin_in.ogg` |
| 布局参考 | `ui/usecoin/usecoinwindow.ui` |

动画与粒子按原图 1:1 装入独立 CanvasLayer，不放大；单帧推进最多 50ms，避免卡顿帧一次跳过整段效果。`ui/usecoin/usecoinwindow.ui` 是深渊模式窗口，普通死亡提示使用现有原版窗口框与中文文字，不声称逐像素复刻该布局。
