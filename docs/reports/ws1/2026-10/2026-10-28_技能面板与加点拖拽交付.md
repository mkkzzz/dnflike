# 技能面板 / 技能树 / 加点 / 拖拽换技能 交付记录

## 一、用户要求

做技能面板，完成技能树、加点、学习技能、拖拽更换技能；参考原版 UI、用正确素材。
决策：175 条全量展示（未实装标灰）；加点完全按原版校验 + 调试入口无视限制；做简化转职（18 级二选一）。

## 二、交付

| 项 | 内容 |
|---|---|
| 数据 | `data/skill_catalog.json`：175 条（名称、类型、等级上限、等级要求与跨度、职业上限、前置、SP 成本、图标键、是否实装） |
| 素材 | `tools/build_dnf_skill_panel.py` → `assets_local/skill_panel/`：174 个技能图标（原生像素）+ 16 个原版 Skillshop 零件（暗化、标题条、技能格、选中框、说明框、按钮、加减、SP 图标） |
| 面板 | `ui/flow/skill_panel.gd`：四类页签、9 行/页、右侧说明、加点/退点/重置、调试开关、转职按钮；挂在 O/K 窗口的“技能加点”页 |
| 规则 | `enforce_skill_requirements` 打开；`skills.change(..., force)` 支持调试绕过；`numbers.growtype` 加 18 级与一次性转职校验，`progression.job_change_level=18` |
| 拖拽 | 面板行可拖到 HUD 技能槽（`place="skill_catalog"`）；`slot_layout.move` 校验已学会、可入槽、不重复占槽 |
| 转职 | 面板 18 级后出现“转职·剑魂 / 转职·狂战士”；切换 growtype 后技能可用性随之变化 |

## 三、素材与数据来源

- 面板零件：`Interface2/UI/SkillShop/Skillshop.img` 实测帧表（暗化 14、标题 3、技能格 32/4、说明 19、加减 22/23、SP 15、按钮 20/21/30/31）。
- 技能图标：每个 SKL 的 `[icon]` 字段（如 `Character/Swordman/Effect/SkillIcon.img` 帧 94/95 上挑、8/9 拔刀斩）。
- 校验数据：SKL 的 `required_level` / `required_level_range` / `growtype_max_level` / `pre_required_skill`（E-PARSE）。
- 名称：原版 `name_ref` 只解出 `name_17730` 占位键（本地化文本不在备份库），中文名按文件名语义整理，标注 E-ADAPT 待校对。

## 四、验证

- `tools/run_dnf_loop.ps1 -Test`：348 项 failures=0；数值套件 63 项（新增拖入已学技能、同技能不重复占槽、非入槽技能拒绝）。
- `tools/run_dnf.ps1 -Test`：143 项 failures=0。
- 因校验开启，`test_numbers` 的加点样例由“拔刀斩”改为“上挑”（拔刀斩要求 35 级且剑魂），并新增“force 绕过限制”断言。
