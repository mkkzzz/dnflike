# 浅栖之地原生迷宫与对象载荷

本批把 `shallowkeep.dgn` 接入隐藏的正式 `native_maze` 路线，并补齐憎恶、投掷憎恶、水精灵、幽灵、暗精灵与摩根六个直接怪种和特殊棺/罐载荷 `ghoulstand` 的运行资源。结论只到 `runtime`：第二套 quest/hell 布局、freezing Luna 特殊对象、21 个未知 trap、城镇入口、任务奖励与用户实机验收仍未闭合。

## 一、来源与路线

- 原路径 `dungeon/act4/shallowkeep.dgn`，SHA256 `652be6d9a2d862210a92c767e5cb7c3cbb4d3f8e887868e0e98cc8fa9f9ab833`。
- 原档中文名“浅栖之地”，最低等级 37、basis level 40，区域按 `[worldmap pattern info]` 定为 `noierfera`。
- 源网格为 4×5，共 20 格；18 格连通，2 格为 `AA` 空位。
- 起点候选为 `(1,4)`、`(2,4)`，终点候选为 `(0,0)`、`(3,0)`。
- 导出包含 38 张源 MAP、88 个 cell/MAP placement、81 张原图；一次运行覆盖 18 格与 18 张当局 MAP。
- 导出诊断为 0 error、2 条 `AA` 空格警告和 38 条 raw MAP 标签信息。
- DGN 含两段 `[maze info]`：普通布局在前，quest/hell 替代布局在后，并带 `[quest connection]`。本批只消费第一段普通布局，第二段保留在 raw 中，不把 quest/hell 选择器当成普通路线。
- 普通曲为 `M_UNDERFOOT`，首领曲为 `M_SHALLOWKEEP_BOSS`；BOSS MAP 的 sound 列表还混有 `R_AMB_CAVE`，BGM 烘焙时已排除环境音。

## 二、正式入口

`game_dnf/data/dungeons.json` 新增 `shallowkeep`：

- `mode: native_maze`
- `hidden: true`
- `region: noierfera`
- `min_level: 37`
- `monster_level: 40`
- 原 DGN 路径与 SHA256

`FlowSession.depart("shallowkeep")` 可启动，普通城镇选择器仍不显示。世界内容审计当前识别 27 条非 legacy 路由、117 个固定房间和 9 个原生迷宫。

## 四、对象与箱组

38 张源 MAP 共放置 513 个场景对象：

- 322 个可执行可破坏物。
- 2 个 `shallowkeepfreezingluna` 特殊对象，当前只登记 `native_special_object`。
- 189 个静态障碍、墙体与地形对象。

箱组 0 有 3 项物品，对应 `original_1080`、`original_1081`、`original_1082`；箱组 1/2 为空，箱组 3 为空且 level 41。独立资源包 `game_dnf/assets_local/items_original_v6/` 包含 9 个 box-loot 定义和 13 张唯一原图；`NativeBoxLoot.ART` 与 `native_windows.gd` 已登记 v6。

特殊可破坏物保留 21 个未知 trap ID：

`2000`、`2010`、`2011`、`2012`、`2100`、`2110`、`2111`、`2112`、`2211`、`2212`、`2300`、`2310`、`2311`、`2400`、`2411`、`2500`、`2511`、`2600`、`2611`、`48022`、`48023`。

只有源字段完整、已验证的 `2200`、`2210`、`48003` 分支可执行；混合分支中出现任一未知 ID 时整体不执行，避免截取部分猜测行为。

## 五、共用修复

- `native_maze.gd` 只读取第一段 `[maze info]`，遇到第二段替代布局即停止；普通迷宫不再因 quest/hell 附加配置被整体拒绝。
- `build_dnf_native_box_loot.py` 不再按父对象 `id in [300,800]` 过滤。任意特殊被动对象里的正数 `[item]` draw 都会编译，第二脊椎祭坛钟与浅栖箱组因此进入 loot。
- `bake_dnf_bgm.py` 排除 `R_AMB_*` / `AMB_*`，允许同一 MAP sound 列表同时含环境音与 BGM；`RANDOM` 音乐组按 `ITEM TAG` 解析，同一 role 多曲时按出现次数取多数，平票报错。
- `compile_dnf_content.py` 支持“单值 int + `[destroy particle]`、无六项 string”的单阶段 OBJ 布局。树十字与 spiner 以 `E-INFER` 一击销毁适配，并保留未知字段。
- 特殊对象 `[monster]` ID 通过 `monster_catalog.json` 纳入内容包、运行时映射和图集范围；绝对 `passiveobject/...` 路径不再被重复 resolve。
- `combat_session.gd` 只要求非空受击音存在于资源包；空 hit sound 作为合法静默源，不再阻塞副本。
- `pipeline_dnf.py monsters` 固定为总账 → 内容包 → 映射 → 图集 → Godot `--import` → 检查。新生成 PNG/OGG 不再因缺少导入记录被 `ResourceLoader.exists` 误报为缺失；Windows 子进程输出改为 UTF-8 容错解码。

## 七、未闭合

- DGN 第二段 quest/hell 布局与 `[quest connection]` 只保留 raw，替代地图选择、hell 封印门和任务连接未执行。
- 2 个 `shallowkeepfreezingluna` 特殊对象未执行；冻结状态、作用范围、持续时间和清理时序需要原字段/原状态取证。
- 21 个混合未知 trap ID 未执行；当前只记录 `native_object_gaps`，不把相近 trap 逻辑顶替。
- 138 个 item draw 已编译来源，但确定性权重只准备实际命中的箱组；源 client 的完整随机序列、空箱与 level 41 箱组语义仍需对照。
- `ghoulstand` 使用源 Ghoul 图像与独立 MOB 动作表，特殊棺/罐中生成、位置、阵营和销毁时序仍待逐对象核对。
- 普通/首领直接怪的完整 AI、领主阶段、特殊攻击与召唤条件仍需逐招取证；本批通过的是内容、图集、动作表和迷宫依赖闸门。
- 2 个 `AA` 空格的布局语义、38 张 MAP 的静态障碍次序与原客户端同条件画面仍需对照。
- 浅栖之地城镇入口、公开选择、前置任务、奖励、结算与完整回城链未接入。
- 自动化和 headless 通过不代表原客户端同条件画面、声音、手感或用户验收。
