## 二、拓扑与正式路由

- `dungeons.json` 新增隐藏 `noirpera` 路线，`mode: native_maze`、`min_level: 59`、`monster_level: 55`。
- 源网格为 `5×2`，10 个 cell 中 7 个连通，3 个 `AA` 空格；路线只有一个起点和一个 boss：

| Cell | MAP | 角色 |
|---|---:|---|
| `(0,0)` | 7101 | start |
| `(1,0)` | 7102 | normal |
| `(1,1)` | 7103 | normal |
| `(2,1)` | 7104 | normal |
| `(2,0)` | 7105 | normal |
| `(3,0)` | 7106 | normal |
| `(4,0)` | 7107 | boss |

- 普通路线为 start → right → down → right → up → right → right boss。
- 导出包含 7 个固定 placement、7 张 MAP、81 张原图；没有直接对象行。
- 诊断：0 error、3 个 `cell_without_map` warning、7 个未处理 MAP 标签 info。
- BGM 解析为 `M_NPERA → npera`、`M_NPERA_BOSS → npera_boss`；环境声保留 `AMB_DARKSTAGE_01` raw。

## 四、对象与地图边界

- 本图 7 张 MAP 的对象数组全部为空；没有可破坏物、trap、箱组或 action-object。
- 运行 `build_props()` 应为 0，且不产生对象专项 gap；这不代表 MAP 的 `[extended tile]`、`[NPC]` 或 `[monster specific AI]` 已经消费。
- MAP 保留 47 条 `[monster specific AI]=[normal]` 和 boss 房 1 个 NPC 行；NPC 生命周期与 NPC 触发的对话/任务未接入。
- `[extended tile]` 在 6 个房间保留 raw；扩展地形/碰撞若影响画面，需后续按原客户端同条件对照。
