# 技能系统源数据与职业树

## 一、目标

用户要求把技能做成原版经典系统，覆盖学习、职业区分和实际效果，并按原版数据复刻。本轮以 `dnf-native-assets-v1-20261022` 的剑士配置为参照，先打通可验证的技能源数据、职业树、学习事务、动态技能栏和一组完整战斗效果；未具备动作、判定或效果语义的节点继续明确标为未实装。

## 二、源数据

- 原档案：`111Script.pvf`，SHA256 `f48850456b7dc0107278fb3f3a74fd68ee404889b95880f3204ce10fbd179be0`。
- 技能索引：`skill/swordmanskill.lst`，175 条剑士技能。
- SKL 字段：名称、简介、长说明、类型、等级要求、职业等级上限、前置、SP、图标和 `[dungeon]` 等级表均从 SKL 读取。
- 本地化：146 条名称通过 `n_string.lst` 的 `type 9/10` 引用解析到 `skill/skill.kor.str`；另外 29 条由 SKL 直接保存显示文本。175/175 条都有名称与说明，不再使用“未开放技能”占位名。
- `skill_catalog.json` 升级为 schema 2，并保存本地化表、键、行号与直接文本来源，便于逐条回查。
- `tools/build_dnf_skill_panel.py` 现在同时生成技能目录、运行时说明 `items/skill_descriptions.gd` 和技能图标。原版档案只读，未修改。

## 三、职业树与学习

| 职业筛选 | 可见节点 |
|---|---:|
| 鬼剑士 | 60 |
| 剑魂 | 90 |
| 狂战士 | 81 |

- `skill_defaults` 改为原版起步：上挑、鬼斩为初始技能；其余技能为 0 级，由 SP 正常学习。
- 18 级转职仍为当前简化入口：鬼剑士二选一剑魂或狂战士；正式任务剧情尚未接入。
- 学习继续校验角色等级、职业列、前置、SP、技能上限和退点成本；`weapon_mastery_up` 可提高短剑/太刀/巨剑精通的职业列上限。
- 旧存档做增量迁移，不丢弃已学等级；非法技能栏项、未学习技能和重复绑定会被清洗。

## 四、可执行节点

本轮将运行时可见节点从 6 条扩展到 16 条：

| 类别 | 节点 |
|---|---|
| 鬼剑士主动 | 上挑、鬼斩、三段斩、十字斩、月光斩、格挡 |
| 剑魂主动 | 拔刀斩、破军升龙击 |
| 狂战士主动 | 血之狂暴 |
| 被动 | 短剑精通、太刀精通、巨剑精通、武器奥义、血气旺盛、物理暴击、生命之源 |

- 鬼斩使用原版 `hardattack.ani`、`hardattack.atk`、暗属性魔法伤害及两只 `HardAttackBlade` 特效；缺攻击盒的运动由原特效不透明范围生成击窗。
- 月光斩使用原版两段身体运动/ATK，按 SKL 等级行选择两段伤害列。
- 破军升龙击使用原版冲刺与上挑两段运动/ATK、原版位移静态值和源特效；需要武器精通追加的第三段终结尚未接入。
- 血之狂暴效果继续由 `frenzy.skl` 驱动施放、MP/CD/等级，持续修正数值仍是 E-ADAPT，未冒充已核实公式。
- 血气旺盛会把十字斩的 MP 消耗替换为 HP，并提高原版出血触发概率；`bloody_vigorous.static_data = [400]` 作为 40% 适配值。
- 短剑/太刀/巨剑精通只在对应武器类型下生效；物理暴击与生命之源直接用 SKL `level_row` 和显式换算系数计算。

## 五、技能栏与战斗接口

- HUD 的 A/S/D/F/G/H 不再写死五个招式，而是由角色存档中的六个技能槽驱动。
- `CombatSession.submit_skill(index, ...)` 将槽位索引交给战斗内核，因此同一技能拖到任意槽后仍播放正确招式。
- 拖拽只允许已学习、已接入运行时的主动技能；被动技能不可入槽。
- 技能栏与存档在城镇、出征、战斗失败/复活、读档和旧档迁移中保持一致。
