# 比尔马克帝国试验场原生迷宫与对象载荷

本批把 `dungeon/ancient/vilmark.dgn` 接入隐藏正式 `native_maze` 路线，闭合 6×1 源网格、6 个连通房、6 条固定 MAP、37 只直接怪、6 个怪种、209 个对象、77 个可执行可破坏物和两首原曲。结论只到 `runtime`：古副本/邀请物语义、封印门、hell 生命周期、混合 trap、空箱组、贵重箱、召怪器、城镇入口、任务奖励、结算与用户实机验收仍未闭合。

## 二、拓扑与正式路由

- `dungeons.json` 新增隐藏 `vilmark` 路线，`mode: native_maze`、`min_level: 55`、`monster_level: 58`。
- 源网格为 `6×1`，6 个 cell 全部连通，从 `(0,0)` 单向经过 4 个普通格到 `(5,0)` boss；没有 AA 空格。
- 固定 specification 为：

| Cell | MAP | 角色 |
|---|---:|---|
| `(0,0)` | 5201 | start |
| `(1,0)` | 5202 | normal |
| `(2,0)` | 5203 | normal |
| `(3,0)` | 5204 | normal |
| `(4,0)` | 5205 | normal |
| `(5,0)` | 5206 | boss |

- 导出包含 6 个 MAP、18 个 greed-eligible placement 和 47 张原图；所有对象都有 sprite，诊断只有 6 条未处理标签 info。
- BGM 由 MAP sound key 和 `audio.xml` 解析：`M_VILMARK → vilmark`、`M_VILMARK_BOSS → vilmark_boss`。

## 四、对象与载荷

209 个对象分为 159 个 `[passive object]` 和 50 个 `[special passive object]`。按现有可破坏契约形状统计：

- 189 个进入可破坏候选。
- 77 个获得 `native_breakable`：39 个 `vilmarkbox` 与 38 个 `transporter_*`。
- 112 个候选缺少可执行破坏源：49 个 `largegrassmirkwood`、33 个 `smallgrassmirkwood`、8 个 `eventbarrier_1`、16 个 `eventbarrier_2`、3 个 `mobgen_1`、2 个 `mobgen_2` 和 1 个 `treasurebox`。
- 另有 20 个 `burnttree1/2` 属于 obstacle，不是当前接触可破坏契约；保持 source-only，不以空 ATK 冒充机关。

特殊载荷：

- `[special passive object item]` 解析出 group 0、1、2；group levels 都是 -1。
- group 0：物品 1091 `浓缩的元素药剂`、1092 `跃翔药剂`，权重各 2000。
- group 1：空组；5 个 `vilmarkbox` 虽请求 1 次抽取，合法结果只能是空。
- group 2：物品 1079 `大块肉干`，权重 2000；唯一 `treasurebox` 请求 7 次抽取，但该对象没有 `native_breakable`，因此本批不生成运行箱。
- 19 条源箱行中，13 个 group 0 箱合计请求 18 次抽取；5 个 group 1 行保持空组；1 个 group 2 贵重箱保持显式缺口。

运输器与 trap：

- 26 个特殊对象满足 `NativeJarTraps.candidate_rows()`，可执行已验证的 40002/48003 分支。
- 11 个未解 trap ID 保留：`2010`、`2011`、`2110`、`2111`、`2211`、`2212`、`2311`、`2510`、`2511`、`2610`、`2611`。
- 2210 与未知 2211/2212 混合时整对象不执行猜定分支；2311/2511/2611 与 2510/2610、2110/2111、2010/2011 同理。
- `mobgen_1/2` 的召怪行为、`eventbarrier_*` 的触发链和 `burnttree_*` 的地图行为仍待原状态与 MAP 事件取证。

## 六、未闭合
