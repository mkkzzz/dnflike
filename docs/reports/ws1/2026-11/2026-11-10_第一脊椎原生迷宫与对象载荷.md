# 第一脊椎原生迷宫与对象载荷

本批把 `1stbackbone.dgn` 接入隐藏的正式 `native_maze` 路线，并补齐 Starfish King 的运行 bank。结论只到 `runtime`：第二套 quest 4329/hell 布局、21 个混合 trap、海星卵、扫臂与重力 trigger、城镇入口、任务奖励和用户实机验收仍未闭合。

## 一、来源与路线

- 原路径 `dungeon/act3/1stbackbone.dgn`，SHA256 `005a1cba836b48bd1f56f2a6a6dd5e72ffa91786c701cc0b2a6791027176da85`。
- `[name]` 字符串键为 `dungeon/dungeon.kor.str` 的 `name_270`，即“第一脊椎”。
- 原档最低等级 32、basis level 35；`[worldmap pattern info]` 指向 `behimoth` 的 slot 4。
- 源网格为 4×4，共 16 格；10 格连通，6 格为 `AA` 空位。
- 起点为 `(0,3)`，首领候选为 `(1,2)`、`(2,2)`。
- 导出在 `MapGreed` 过滤后保留 20 张源 MAP、28 个 cell/MAP placement 与 50 张原图；一次运行覆盖 10 格、10 张当局 MAP，预检保留 15 张可达候选 MAP。
- 导出诊断为 0 error、6 条 `AA` 空格警告与 20 条 raw MAP 标签信息。
- 第一段 `[maze info]` 含 4 条普通 `[map specification]`；第二段替代布局含 2 条普通 spec、1 条 boss spec 与 `[quest connection] 0, 4329, 1`。本批只消费第一段。
- DGN 还保留 `[hell dungeon]` 与 `[seal door map index]=60012`；本批不执行该特殊模式。
- 普通与首领 MAP 的 `[sound]` 分别解析为 `M_1ST_SPINE`、`M_1ST_SPINE_BOSS`，环境音键为 `R_AMB_WIND`。

## 二、正式入口

`game_dnf/data/dungeons.json` 新增 `firstbackbone`：

- `mode: native_maze`
- `hidden: true`
- `region: behemoth`
- `min_level: 32`
- `monster_level: 35`
- 原 DGN 路径与 SHA256

`FlowSession.depart("firstbackbone")` 可启动，普通城镇选择器仍不显示。世界内容审计当前识别 28 条非 legacy 路由、117 个固定房间和 10 个原生迷宫。

20 张源 MAP 共放置 176 只直接怪、8 个直接怪种与 3 条 `[boss]` 行：

| MOB | 数量 | 运行 bank |

| `monster/starfish/starfish.mob` | 48 | `native_starfish` |
| `monster/starfish/starfishdevourer.mob` | 40 | `starfish_starfishdevourer` |
| `monster/starfish/starfishrukuku.mob` | 38 | `native_starfish_rukuku` |
| `monster/zealot/raxy-a.mob` | 16 | `native_raxy` |
| `monster/dendroid/goliden.mob` | 14 | `dendroid_goliden` |

| `monster/hunter/alex.mob` | 8 | `hunter_alex` |
| `monster/starfish/starfishking.mob` | 3 | `starfish_starfishking` |

三个首领 MAP 都只生成 Starfish King。Starfish King 保留 6 个源攻击槽，包括咬击、跳击准备、滚动准备、暗属性攻击与引导攻击。

特殊被动对象还保留 20 条 `[monster]` payload，覆盖 4 个 MOB：普通海星 14、蓝章鱼 3、小章鱼 2、GBL 信徒 1。它们通过怪物总账、内容包、运行时映射与图集依赖进入预检，不直接计入 176 只 MAP 放置怪。

资源侧新增 `starfish_starfishking` 图集、`1st_spine.ogg`、`1st_spine_boss.ogg`。`pipeline_dnf.py monsters` 从头完整通过，并自动执行 Godot 资源导入。

## 四、对象与箱组

20 张源 MAP 共放置 341 个场景对象：

- 118 个可执行可破坏物，包含 67 个第一脊椎长罐、30 个莲花收集箱、15 个宝箱与 6 个长椅。
- 12 个特殊 trap 对象，当前只登记 `native_special_object`。
- 36 个普通 trigger，包含 34 个海星卵与 2 个扫臂 trigger。
- 175 个静态障碍、云层、远中近景与墙体。
- 42 个正数 `[item]` draw 对象。

箱组 0 有 5 项物品，对应 `original_1068` 至 `original_1072`；箱组 1 为空且 level 36，箱组 2/3 为空。所需原图已由既有 `items_original_v6` 覆盖，本批不新建物品资源包。

特殊可破坏物保留 21 个未知 trap ID：

`1025`、`1072`、`2000`、`2001`、`2010`、`2011`、`2101`、`2110`、`2111`、`2201`、`2211`、`2311`、`2401`、`2411`、`2412`、`2511`、`2512`、`2601`、`2611`、`2612`、`48020`。

当前没有可整体执行的已知 trap 对象，因为每个含已知 ID 的源分支都与至少一个未知 ID 混合；混合对象整体不执行，避免截取部分猜测行为。

## 五、共用接入修复

- `export_dnf_map.py` 把 `dungeon/act3/1stbackbone.dgn` 纳入已验证 `MapGreed` 名单，原生迷宫可按源布局 mask 与入口方向过滤候选 MAP。
- `build_dnf_native_box_loot.py` 登记第一脊椎来源和钉死 SHA256；箱组 0 与空组 1/2/3 均保留。
- `NativeMaze` 对双 `[maze info]` 的普通布局选择沿用浅栖修复：读取第一段并在第二段替代布局前停止。
- 特殊 payload 怪沿用现有总账 → 内容包 → 映射 → 图集链路，`starfishking` 则按直接副本引用自动进入内容包。

- Starfish King 的 6 个动作槽、暗属性攻击、引导攻击、滚动阶段与首领选择仍待逐招和原客户端同条件核对。

- 第一脊椎城镇入口、公开选择、quest 4329 前置与奖励、结算及完整回城链未接入。
- 自动化和 headless 通过不代表原客户端同条件画面、声音、手感或用户验收。
