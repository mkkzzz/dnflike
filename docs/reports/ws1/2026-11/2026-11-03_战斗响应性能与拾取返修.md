# 战斗响应、性能与拾取返修

## 范围

处理用户指出的完整循环掉帧、按键响应不顺手、拾取抢占、跳跃攻击重复和表现资源首次加载卡顿；
同时修复战斗 HUD 字体、音效池和武器奥义上限 ID 不一致。
格挡动作按用户要求暂不处理。

## 根因与修复

### 1. 完整循环每帧重算角色属性

- `LoopRoot._process()` 每帧调用 `Session.stats()`。
- 该路径会触发 `Numbers.config()` 的完整配置深拷贝，并把 `Numbers.record()` 的技能记录再次复制。
- 实测单次 `Session.stats()` 约 57 ms，单次 `Numbers.config()` 约 17.7 ms；完整循环战斗约 15 FPS。

修复：

- `Session.runtime_stats()` 增加只读缓存，`stats()` 仍返回副本，兼容测试和外部调用。
- 所有会修改 profile 的命令、战斗事件、读档和复活入口主动失效缓存。
- `Numbers.record()` 使用共享配置并缓存技能解码记录。
- `LoopRoot` 在战斗中使用 `CombatSession.read_runtime_view()`，移除每帧完整属性快照和重复 `read_view()`。
- 任务追踪刷新降到 5 Hz，调试面板只在可见时刷新。

### 2. 首次特效/角色纹理解码

- `FxView.setup()` 原先在首次生成特效时同步解码纹理；profiler 曾记录到单次约 21.5 ms。
- `ActorView` 每次生成角色还会新建 Shader。

修复：

- 新增 `view/texture_cache.gd`，在战斗初始化时预热玩家、怪物、特效和对象图集。
- 角色共用一个预编译 Shader；特效按混合模式共享 `CanvasItemMaterial`。
- 常见掉落图集在流程适配器初始化时预热。

### 3. 击杀同帧多次存档

- 多段攻击同时击杀多个怪物时，耐久观察和战斗事件会在同一帧创建多个 Session 并多次写盘。
- profiler 曾记录到最坏帧约 753 ms，其中存档和候选 Session 构造占主要部分。

修复：

- 耐久累积不再为每个伤害事件构造完整 `Session`，只复制 profile/run。
- 耐久进度不再每击写盘；仅在耐久阈值变化或当前持久事务需要时加入存档队列。
- XP、任务、掉落和耐久存档合并为下一可处理帧的单次提交。
- `Store.write()` 记住当前主存档已验证，避免每次备份前重复 `Session.restore()`。

### 4. 输入、跳攻与拾取

- 增加 120 ms 的受击/倒地恢复输入缓冲，输入不再在不可控状态直接消失。
- 跳跃时记录起跳移动速度，跳斩不再把跑动速度突然降为普通走路速度。
- 每次腾空只允许一次跳斩；落地后重新允许。
- 后跳除了既有普通攻击取消外，可在技能主动判定结束后取消收招，不在攻击窗口内抢断。
- X 拾取只在角色站稳且附近没有贴身敌人时接管；E 始终可精确拾取。
- 拾取配置改为缓存，避免每次判断重新解析 `loot.json`。

### 5. UI 与音效

- UI 字体改为随资源包分发的原版 `msjh.ttf`，缺失时才回退系统字体。
- BGM 改为按曲目键懒加载，城镇和战斗不再各自一次性载入全部 BGM。
- 战斗音效同名节流从 75 ms 调整为 50 ms；声池优先使用空闲声道，不再无条件覆盖正在播放的语音。

### 6. 武器奥义 ID 不一致

运行时 `mastery_fields` 使用 `blademastery`，本地配置使用 `blade_mastery`，导致学习武器奥义后太刀精通上限没有增长。
现在同时接受原始字段和去下划线 ID，数值回归恢复通过。

  - `violations=0`
- `python tools/check_game_chinese.py`
  - 无韩文代码文本；原图文字仍需渲染复核

隐藏渲染 profiler（VSync 关闭，完整的战斗/掉落/击杀序列）：

- 平均帧时间约 `0.71 ms`，最坏帧约 `2.78 ms`。
- 开启 VSync 后平均 `16.665 ms`，稳定 60 FPS。
- 首次特效不再出现 20 ms 级 `FxView.setup()` 峰值。

## 仍是已知边界

- 从城镇进入战斗的同步 mount 仍约 4.27 秒；这次处理的是战斗内掉帧，进场加载还没有改成异步加载/明确 loading 场景。
- 普攻 1/2 段和部分技能判定仍受 `combat.json` 的 E-ADAPT 盒体限制；实际 PVF 未锁定前不填猜测盒。
- 小地图、结算/暂停覆盖层、部分技能 CD 和房间提示仍是程序绘制；本次只统一到原版字体。
- 音色、混音和手感仍需 rainmk 实机试听/试玩确认，自动化通过不等于听感或手感验收。
