# 输入分派与拾取动作返修

## 范围

复查战斗内输入、拾取、道具使用和动作表现后，处理与原版默认键表或当前资源链冲突的确定问题。
有效运行 PVF 仍未锁定，原版事实只对 `111Script.pvf` 备份成立。

## 修复

- `E` 不再无条件兼任拾取。上排第 3 槽绑定技能时，`E` 只施放技能；空槽时保留精确拾取兼容。`X` 仍是原版主拾取路径。
- 拾取动作改用 CHR `[getitem motion]` 的 `GetItem.ani`：1 帧、200ms。角色出招、受击或腾空时立即停止拾取姿势覆盖。
- 斜向奔跑按 `X` 现在也进入 `dash_attack`，不再因归一化后的横向分量转成 0 而退回普通攻击。
- `G` 槽绑定技能时不再同时进入硬编码格挡；空槽保留现有格挡兼容。
- 成功使用恢复道具时，按即时/持续类型播放原版 `common/commoneffect/animation/heal.ani` 或 `fastheal.ani`。该映射为 E-INFER，资料未证明物品使用音效，因此没有合成替代音。
- 拾取成功后不再重建整套快捷栏；数量由现有 HUD 刷新路径更新。
- 修正恢复配置单测仍使用旧 `revival.gold` 字段的问题。
- 修正物品拆分 GUI 测试在 SpinBox 提交前立即点击造成的旧值覆盖。
- 重建 quest rules/audit 的输入哈希，清除完整循环启动闸门的陈旧状态。
- 对绕过 `Session.command` 的强化/附魔/修理专项测试显式失效属性缓存。
- 存档恢复在 `item_state` 结构损坏时先交给校验层拒绝，不再于 `Inventory.sync` 中崩溃。
