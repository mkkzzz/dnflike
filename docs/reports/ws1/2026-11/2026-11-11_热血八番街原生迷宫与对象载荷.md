# 热血八番街原生迷宫与对象载荷

本批把 `odesa.dgn` 的 hell 基础 block 4 接入隐藏正式 `native_maze` 路线，闭合 7×4 源网格、13 个连通房、13 张固定 MAP、114 只路线怪、RocketMan 领主、43 个路线对象、原物品 3230 和两首原曲。结论只到 `runtime`：四张 Cartel 墙门帧、任务/逃脱/hell 变体、可破坏物源契约、封印门、事件怪、城镇入口、奖励/结算与用户实机验收仍未闭合。

## 一、来源与多迷宫选择

- 原路径 `dungeon/village/cartelarad/odesa.dgn`，SHA256 `1fed07147d1f2be9a4071572589b208a7e2c493410925df8f92d8655f7d5ed7b`。
- DGN 索引 60，本地化名称为 `熱血八番街`，正式名称使用简体 `热血八番街`；最低等级 52、basis level 55。
- `[worldmap pattern info]` 指向 `WorldMap/SelectdungeonSlot/cartel.img`；route region 使用 `westcoast`。
- DGN 有 5 个 `[maze info]` block。block 0～3 都绑定任务并带 escape，唯一基础布局 block 4 没有 quest/escape，但带 `[hell dungeon]` 标记。
- 旧选择逻辑只接受“无 quest、无 escape、无 hell”的普通 block，会错误落到 quest block 0。本批把选择规则固化为：先选无 quest/escape/hell 的普通图；没有时，再接受无 quest/escape 的 hell 基础图；最后才保留旧 fallback。
- 全库 325 个可解析 DGN 扫描后，新规则只改变奥德萨和 `genteastgate` 的选择；现有已接入副本选择不变。

- 基础 block 的 28 个源格中 13 格连通、15 格 `AA`；起点 `(0,0)`、首领 `(5,3)`。
- 16 条普通 `[map specification]` 和 1 条 boss specification 中，仅 13 个连通格参与首局路线；起点从 `odesa01` 的 `[start area]` 选择，终点固定到 `odesa19`。

- `.ai` 选招表按源优先级加载；RocketMan 没有可解析选招规则，只保留动作与距离驱动回退，不能宣称已复现原 Boss 状态机。

## 三、对象与可破坏物

全部 5 套布局共 100 个对象，其中 68 个 `[passive object]`、32 个 `[special passive object]`。

基础路线 43 个对象：

- 12 个 `odesarice1`、2 个 `odesarice0`：可渲染静态障碍。
- 20 个 `trashcan`、9 个 `odesabox`：结构上符合 `NativeBreakable.supports()`，但 OBJ 没有 HP/阶段/破坏动作契约，运行 prop 为 0。
- 29 个可破坏候选的 sprite 都缺失；`trashcan` 和 `odesabox` 的 destroy particle 已编译，不能据此宣称可破坏行为已接通。
- `odesabox` 的路线 payload 包含 trap 2210、2010、2110；2210 有已验证候选分支，2010/2110 仍为未知 trap。由于 breakable source 缺失，这些对象整体保持显式 gap。

DGN `[special passive object item]` 为 group 0、level -1、draw 1，唯一候选是原物品 3230 `垃圾桶盖`，权重 1700。

- 新增不可变 `game_dnf/assets_local/items_original_v11/`，聚合 37 个 runtime/box 物品定义与 55 张唯一原帧。
- `NativeBoxLoot` 与原生物品窗口扫描切到 v11；不覆盖 v1～v10。
- `pick(0..1699) = original_3230`，`pick(1700) = 空`；开箱概率和图标依赖实际可破坏 prop，本批受 breakable source 缺口阻断。

## 六、未闭合

- Cartel Arad 的 `ca_exitup010.img` 与 `ca_exitup08.img` 四个左右墙门帧在已发布图库中没有 validated IMG；本批只验证这些对象不属于普通路线绑定门，未制作替代图。
- 20 个 trashcan、9 个 odesabox 的 HP、阶段、破坏动作/音效和 source binding 未取证；v11 只准备物品图标与原帧，不能宣称实际开箱发奖。
- Odesa box trap 2210 有已验证候选分支，2010/2110 仍未知；breakable source 缺失时不能选择性执行部分 payload。
- `rod_boss` 5 招和 `macgee` 8 招虽然进入运行表，但阶段、命令/移动组合、冷却共享、目标选择和实际命中仍需原客户端同条件验收；RocketMan 的 17 个动作槽没有源选招规则。
- 封印门 60044、事件怪 61728、hit count、quest 3901/3903/3904/3906、四套 quest/escape block、hell marker、任务奖励、城镇入口、结算与回城链未接入。
- `westcoast` 当前城镇选择器只指向 Sky Tower 路由；热血八番街仍是隐藏 `FlowSession.depart` 入口。
- 自动化与 headless 通过不代表原客户端同画面、声音、手感或用户验收。
