# 60 级单机一致基线

> 本文件由 `python tools/build_dnf_60_baseline.py --write` 生成。
> 目标是离线单机 60 级 PVE 内容与表现一致；不做更新器、联网服务端、组队/交易/邮件/公会/拍卖/PVP。
> 当前来源仍为 111 备份候选，不声明已锁定实际客户端版本。

## 一、目标范围

| 约束 | 当前基线 |
|---|---|
| 等级上限 | 60 |
| 60 级以上内容 | 保留为后续拓展，不计入当前 60 内容分母 |
| 服务端进程 | 不实现；服务端规则本地化 |
| 更新器/热更新 | 不实现 |
| 社交/PVP | 不实现；多人条件内容单列 |
| 完成定义 | 目标内容可运行，并完成原版同条件对照与用户验收 |
