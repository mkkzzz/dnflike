# 冰心少年原生迷宫与对象载荷

本批把 `theboywithcoldheart.dgn` 接入隐藏的正式 `native_maze` 路线，补齐冷心少年、冷心、四个玩具怪与冰奈斯的直接怪物链、27 个水晶可破坏物、冻结 Luna 缺口和原曲 `M_COLD_BOY`。结论只到 `runtime`：事件怪 61728、事件位置、冻结触发、首领阶段/选招、城镇入口、任务奖励与用户实机验收仍未闭合。

## 一、来源与路线

- 原路径 `dungeon/act5/theboywithcoldheart.dgn`，SHA256 `dcf7202c45f573b15c34dcd576872ffca34370ed7ec049464543229b4b562a03`。
- 本地化名称解析为“冰心少年”，条目 `dungeon/dungeon.kor.str:name_395`；说明条目为 `explain_395`。
- 进入标题为 `Title/TheBoyWithColdHeart.ani`；原档最低等级 43、basis level 46。
- `[worldmap pattern info]` 指向 `WorldMap/SelectdungeonSlot/snowmt.img`，正式 route region 为 `snowmt`。
- 源网格为 `2×1`，两格连通；起点为 `(1,0)`，首领格为 `(0,0)`，greed 为 `BBEE`。
- MapGreed 过滤后保留 3 张 CDN MAP、3 个 placement 与 46 张原图；一次运行覆盖两格。
- 普通房为 `s5801`；首领格同时登记 `b5802` 与 `b5803`。两张首领 MAP 的源 SHA256 都是 `31c2075689c903878f313b62c08091ea09125015e1b9e39a9986bcf443f0d81b`，保留为同内容的两个 map ID/候选，不声称二者有行为差异。
- DGN 没有 `[hell dungeon]`、封印门或 `[quest connection]`；`[event monster]` 61728 保留 raw。
- DGN 的 `[cutscene image] Map/CutScene/Charnak.img`、`[minimap image] Map/MiniMap/Act3.img` 与 3 张 MAP 的 `[event monster position]` 尚未执行。
- 普通曲与首领曲都解析为 `music/cold_boy.ogg`；`audio.xml` 源键为 `M_COLD_BOY`，环境音键为 `R_AMB_SNOWWIND`。

## 二、正式入口

`game_dnf/data/dungeons.json` 新增 `theboywithcoldheart`：

- `mode: native_maze`
- `hidden: true`
- `region: snowmt`
- `min_level: 43`
- `monster_level: 46`
- 原 DGN 路径与 SHA256

`FlowSession.depart("theboywithcoldheart")` 可启动，城镇选择器仍不显示。世界内容审计当前识别 33 条非 legacy 路由、117 个固定房间和 15 个原生迷宫。

3 张源 MAP 共放置 16 只直接怪、7 个直接怪种与 2 条 `[boss]` 行：

| MOB | 数量 | 运行 bank | 攻击槽 |

| `monster/toy/hiddena.mob` | 2 | `toy_hiddena` | 2 |

冷心少年和玩具 C 的投射对象、PTL 路径、发射帧与源 ATK 已编译；冷心少年另保留施法、拳击、冲刺动作槽。`pipeline_dnf.py monsters` 内容链新增 6 个此前未运行的 bank，冰奈斯沿用既有 bank；60 级基线怪物 runtime 从 158 更新为 164。

## 四、对象与箱组

3 张源 MAP 共放置 30 个场景对象：

- 27 个源完整可执行可破坏物：首领变体各 11 个水晶，普通房 5 个水晶。
- 3 个 `shallowkeepfreezingluna.obj`：登记为 `native_object_trigger`，当前不执行冻结/伤害等行为。
- 没有 item draw 或箱组；不新增物品版本。

单次两房运行最多实际构建 16 个水晶；专项测试对全部 3 张候选 MAP 逐张预检，确认 27 个水晶都能按源对象索引生成一次。冻结 Luna 不进入交互道具数组，避免以普通陷阱替代未知原行为。

- 当前共享内容重编时补出 ws2 已引用的 `fx_obj_gorecross_c1a39b50.png`；本批只保留生成物，不改其规则。
