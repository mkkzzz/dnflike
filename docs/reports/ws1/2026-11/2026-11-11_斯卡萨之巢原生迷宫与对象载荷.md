# 斯卡萨之巢原生迷宫与对象载荷

本批把 `scasalair.dgn` 的 hell 基础布局接入隐藏正式 `native_maze` 路线，闭合 3×4 源网格、10 个连通房、12 张候选 MAP、双起点、Scasa 领主、8 个怪种、273 个基础对象和两首原曲。结论只到 `runtime`：quest 4571/escape 变体、封印门、事件怪、27 个 scasa egg 破坏契约、item pocket trap 2211、blizzard factory、领主阶段、城镇入口、奖励/结算与用户实机验收仍未闭合。

## 一、来源与布局

- 原路径 `dungeon/act5/scasalair.dgn`，SHA256 `33d86d36e372ad3d17ed062ce82a80710ec54395b19785c784a9419e760cb536`。
- DGN 索引 45，本地化名称 `斯卡薩之巢`，正式名称使用简体 `斯卡萨之巢`；最低等级 54、basis level 57。
- `[worldmap pattern info]` 指向 `WorldMap/SelectdungeonSlot/snowmt.img`；route region 使用 `snowmt`。
- DGN 有 2 个 `[maze info]` block。block 0 无 quest/escape，带 `[hell dungeon]`，固定 boss MAP 9310；block 1 绑定 quest 4571 并带 escape，保持未选中。
- block 0 的 12 个源格中 10 格连通、2 格 `AA`；起点候选为 `(1,3)`、`(0,3)`，boss 为 `(0,0)`。
- 基础 block 没有普通 `[map specification]`，只有 `[boss map specification] 0,0,9310`；普通房按 greed mask/入口随机挑选源 MAP。
- 导出包含 16 张源 MAP、21 个 greed-eligible placement、74 张原图；`NativeMaze` 单局解析为 10 房，基础候选池合计 12 张唯一 MAP。
- 两个起点互不冲突：第三个 `CC` 起手列可从 row 2 的横向连通格向下回访；独立探针确认两个起点 roll 都能完成预检。

## 三、对象与可破坏物

全部两个 block 共 374 个对象：373 个 `[passive object]`、1 个 `[special passive object]`。基础 12 图候选池为 273 个对象：272 个 passive、1 个 special。

基础池可执行/缺口：

- 56 个 `crystal`、39 个 `frozentree`、8 个 `stonetomb`、4 个 `stonetomb2`：107 个运行可破坏 prop，HP/阶段/碰撞/粒子和音效进入预检。
- 12 个 `scasaegg_breakable`、15 个 `scasaegg_active`：没有基本动作/静态 sprite，`native_breakable` source 也没有生成，合计 27 个 egg 契约缺口。
- 1 个 `itempocket`：带 `[trap] 2211`，special payload 存在但没有 breakable source；`NativeBoxLoot.required()` 为 false。
- 1 个 `blizzard` particle factory：登记 `native_particle_factory`，不执行暴雪时序。
- 静态 `frozen tree/tombstone`、`bulltotem`、`scasaegg_obstacle` 保留地图绘制；行为和生成生命周期未接入。
