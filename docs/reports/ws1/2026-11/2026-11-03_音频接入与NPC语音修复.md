# 音频接入与 NPC 语音修复

## 结论

本轮修复了角色选择界面残留林纳斯语音、靠近 NPC 后环境语无限循环、对话/告别重复或互相叠音的问题，并接入首批统一 UI 音效。NPC 环境语现在是“进入听觉范围播一句，停留不重播，离开并重新进入后才可再次触发”；BGM 与城镇环境底噪仍是连续背景层，两者不再共用同一套循环策略。

自动化验证通过，但音色、音量平衡以及点击/悬停音的实机听感仍需负责人试听确认。

## 实现

| 范围 | 改动 |
|---|---|
| NPC 语音 | `town/native_town.gd` 改为一个环境语声道与一个对白声道；环境音强制 `loop=false`，加入 150/190 px 进出滞回；对话、告别会抢占旧台词 |
| 对话状态 | `flow/loop_root.gd` 统一管理当前交谈 NPC；首次打开对话播一次 talk，切换任务/商店页不重播问候，结束整段对话只播一次 farewell |
| 生命周期 | 返回选人、进副本、切地图时停止 NPC 环境语与对白；隐藏的城镇不再在创建角色页面继续播放语音 |
| UI 音效 | 新增 `ui/flow/ui_audio.gd`，自动接管 UI 树中的 `BaseButton`/`LineEdit`；按钮按下、悬停、窗口开关、页签、角色选择/创建、任务接受/完成、交易、修理、强化、升级等使用语义键 |
| 资源 | 新增 `tools/bake_dnf_ui_audio.py`，从原版 `sounds/ui` 复制 27 个 Ogg 原字节到 `assets_local/ui_audio/`，生成 `data/ui_sounds.json` |
| BGM/环境音 | `flow/loop_root.gd` 让城镇环境底噪按组轮换续播；BGM 仍保持单曲循环，避免环境底噪播完一次后永久静音 |
| 门禁 | 新增 `tools/check_dnf_audio.py`，检查 BGM、UI、NPC 语音及哈希；`tools/run_dnf_loop.ps1 -Test` 已接入该检查 |

## 资源来源

- UI 音效均为原版 `sounds/ui/*.ogg` 原字节，未转码、未改音高，映射和 SHA256 见 `game_dnf/data/ui_sounds.json`。
- NPC 语音沿用 `data/npc_voices.json` 的原版 `amb/talk/farewell` 条目；当前共 15 个 NPC、127 个语音文件。
- 本轮没有新增外部素材，也没有用合成音替代原版 UI 音频。

## 验证

- `python tools/check_dnf_audio.py`：BGM 32、UI 27、NPC 15（语音文件 127）全部映射和哈希有效。
- 角色/音频专项：64 项 `failures=0`，覆盖停留不重播、离开重入、对话切页不重播、返回选人停声、窗口/按钮/悬停音。
- 完整循环：`[LOOP_TEST] COMPLETE checks=434 failures=0`。
- `python tools/check_docs.py`：通过。

## 试听项

- UI 点击使用 `sounds/ui/click1.ogg`，悬停使用 `sounds/ui/mouseover.ogg`；若实际听感偏密或偏响，需要按页面类型调整节流和音量，而不是更换资源来源。
- NPC 语音目前按每名 NPC 的原始变体随机一条；若希望在同一 NPC 旁隔一段时间再次播放，需要另行定义“停留重播间隔”，本轮按用户指出的循环问题默认不重播。
- 角色创建、选人、窗口开关、任务、交易、强化和升级音效需要真实窗口试听；自动化只验证触发、生命周期和资源完整性。
