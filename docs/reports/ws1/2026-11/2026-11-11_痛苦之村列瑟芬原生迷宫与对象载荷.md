## 二、拓扑与正式路由

- `dungeons.json` 新增隐藏 `leshphon` 路线，`mode: native_maze`、`min_level: 55`、`monster_level: 55`。
- 源网格为 `2×3`，6 个 cell 全连通，路径为：

| Cell | MAP | 角色 |
|---|---:|---|
| `(1,0)` | 15057 | start |
| `(0,0)` | 15058 | normal |
| `(0,1)` | 15059 | normal |
| `(1,1)` | 15060 | normal |
| `(1,2)` | 15061 | normal |
| `(0,2)` | 15062 | boss |

- 路线是单向折返：start → left → down → right → down → left boss。
- 导出包含 6 个 greed-eligible placement、6 张 MAP 和 79 张原图；每格只有一个候选 MAP。
- 诊断：0 error、1 个 `object_unrendered` warning、24 个 info；info 中 18 个是六房三档 scroll 缺省，6 个是未处理 MAP 标签。
- BGM 解析为 `M_LESHPHON → leshphon`、`M_LESHPHON_BOSS → leshphon_boss`；MAP 同时列出 `AMB_RAIN_03`，当前 BGM 适配不执行独立雨声底层。

## 四、对象与行为边界

113 个对象全部是 `[passive object]`，没有 special-passive、箱组、trap 或当前 `NativeBreakable` 候选。15 个身份为：

- 地图静物：`sandsack` 13、`box` 12、`puddleM` 11、`tree2` 11、`puddleL` 8、`dead` 7、`tree1` 7、`obwall1` 5、`obwall2` 4。
- 雨层：`raindrop700` 10、`rain400` 9、`raindrop400` 9、`rain700` 5。
- 怪物行为：`disease_wind` 1、`hyungteo_comein` 1。

运行边界：

- 所有 113 个对象都只有 action-object 来源，当前共享内核不把它们物化为猜测战斗 prop；专项验证 `interactive_props=0`。
- `obwall1/2` 的 OBJ 写有 `[do not pass]`，但当前 action-object 碰撞生命周期未执行；不能只凭地图 walk grid 宣称原物件阻挡已闭合。
- `disease_wind` 只有 `basic.ani` 和 int data `900,1500,10,20000,7000`，没有直接 ATK；伤害/风场语义待取证。
- `hyungteo_comein` 只有 `basic action Action/comein.act`、team 100，且没有 `[basic motion]`；视觉与入场行为都保持 gap。
- 雨层对象有原 ANI 与粒子字段，但当前不执行；地图氛围不能计为已还原。
- MAP 保留 24 个 `[event monster position]`、28 条 `[monster specific AI]=[normal]` 和 boss 房 1 个 NPC 行；事件怪生成、AI 覆盖与 NPC 生命周期未执行。

## 六、未闭合

- 7 个实际 MOB 缺失于目标怪物候选清单，导致 DGN 和怪物分母不同步；其原始 level 70 与 DGN basis 55 的关系也未判定。
- 30 个动作槽的 11 个无 ATK 槽、proc/come-in/etc action、召唤、抓取、debuff 和狄瑞吉四段 HP 阈值霸体未接入。
- 113 个 action-object 的视觉、碰撞、粒子和生命周期未执行；雨层、树桩、尸体、遮挡墙、疾病风和入场特效仍是缺口。
- 24 个事件怪位置、28 条 normal AI 行、boss NPC、封门 60053、hell、champion/hit count 和 MAP 事件只保留 raw。
- required item 4430、古副本、coin limit、practice/experience 限制、北迈尔城镇入口、任务链、奖励、翻牌、结算和回城未接入。
- 原雨声环境层、动作音效、特效和同条件画面未验证。
- 自动化与 headless 通过不代表原画面、声音、碰撞、手感或用户实机验收。
