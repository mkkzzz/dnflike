# 根特东门原生迷宫与对象载荷

本批把 `genteastgate.dgn` 的 hell 基础 block 1 接入隐藏正式 `native_maze` 路线，闭合 7×3 源网格、13 个连通房、双起点/双 boss 组合、8 个怪种、152 只全部源怪、162 个全部源对象和两首原曲。结论只到 `runtime`：quest 4212/escape block、封印门、事件怪、灯柱/果袋破坏契约、spider mine、Captain Shured 阶段、城镇入口、奖励/结算与用户实机验收仍未闭合。

## 一、来源与布局

- 原路径 `dungeon/act7/genteastgate.dgn`，SHA256 `064337edb39b84d7a4dc7c7fbef089378ae64c6c1b61857224f2f9371d06d1a0`。
- DGN 索引 81，本地化名称 `根特東門`，正式名称使用简体 `根特东门`；最低等级 56、basis level 59。
- `[worldmap pattern info]` 指向 `WorldMap/SelectdungeonSlot/gent.img`；route region 使用 `gent`。
- DGN 有 2 个 `[maze info]` block。block 0 绑定 quest 4212 并带 escape；block 1 无 quest/escape，带 `[hell dungeon]`，是本批选中布局。
- block 1 为 7×3，21 个源格中 13 格连通、8 格 `AA`；起点候选 `(6,1)/(0,1)`，boss 候选 `(5,0)/(1,2)`。
- 基础 block 有 6 条普通和 2 条 boss specification；FF/EE/BB 格仍按 greed mask 与入口提供多候选 MAP。
- 导出包含 19 张源 MAP、71 个 greed-eligible placement、47 张原图；单局为 13 房，required MAP 依起点/boss 组合为 13 或 14 张。

## 三、对象与可破坏物

全部源对象 162 个；四种单局组合为 96 或 116 个。没有运行可破坏 source。

- 20 个 `smalllamp`、26 个 `roadlamp`、7 个 `roadlamp_half` 是四种组合共有；果袋为 2 或 3 个。全部只有源宽高/粒子/音效数据，`native_breakable` 未生成。
- 单局 breakable 候选 55 或 56，runtime 0；其中 lamp 53 个，果袋 2/3 个。
- `spidermine` 为 6 或 12 个，路径属于 `/trap/`，只登记 `native_object_trigger`，不把无宽度 ATK 当作接触伤害。
- 特殊果袋带 `2200/2201` 或 `2210/2201` trap；breakable source 缺失时所有 payload 保持 gap。
- `sandfence*` 静态障碍渲染；`NativeBoxLoot.required()` 为 false，没有可执行 item group。
