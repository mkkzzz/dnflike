# 堕落的盗贼原生迷宫与对象载荷

本批把 `astraythief.dgn` 接入隐藏的正式 `native_maze` 路线，闭合 5×4 源网格中的 12 个连通格、7 条普通 MAP specification、两个首领格、141 只直接怪、9 个怪种、9 个可执行可破坏物、4 个源 item draw 与两首原曲。结论只到 `runtime`：hell、事件怪 61728、封印门 60018、`q6220` 剧情图、`myojin` 阶段/选招、5 个狗柱 trigger、`act6box` 的 2211 payload、城镇入口、任务奖励与用户实机验收仍未闭合。

## 一、来源与路线

- 原路径 `dungeon/act6/astraythief.dgn`，SHA256 `72925d7c530658a4a7f9a4196fe5dccbef11d068c327c4f0d77dff85d40f81d8`。
- 本地化名称解析为 `堕落的盗贼`；原档最低等级 48、basis level 51。
- `[worldmap pattern info]` 指向 `WorldMap/SelectdungeonSlot/northmaier.img`，正式 route region 为 `noierfera`。
- 普通布局为 5×4 源网格，20 格中 12 格连通、8 格 `AA` 空位；起点 `(3,0)`，两个首领格为 `(4,3)` 与 `(3,2)`。
- 7 条 `[map specification]` 覆盖 `6203, 6202, 6205, 6206, 6207, 6208, 6209`；其余端点按 MAP `[type]` 与 `[greed]` 选择。
- 起点格同时保留两个含 `[start area]` 的 normal MAP：`s6201`（6201）与 `h6204`（6213）；强制首槽的测试路线选择 `6213`。
- `q6220.map` 没有 `[greed]`，本批保留完整 room raw，写入 `layout_absent` info，但不生成普通 cell placement。
- 导出保留 14 个房间、19 个 placement 与 102 张原图。
- 首个首领格路线为 `[6213, 6202, 6203, 6205, 6206, 6207, 6208, 6209, 6211]`，八步移动为 `left, left, down, right, down, down, right, right`。
- 普通曲与首领曲分别解析为 `M_THIEF`、`M_THIEF_BOSS`，环境音为 `AMB_TOWN_01`。

地图导出诊断：

- 8 条 warning：全部是 `AA` 空格。
- 15 条 info：14 个含未处理标签的 MAP、1 个 `q6220` 无布局 MAP。
- 0 条 error。
