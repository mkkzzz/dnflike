# GBL教孵化场原生迷宫与对象载荷

本批把 `gbl_hatchery.dgn` 接入隐藏的正式 `native_maze` 路线，闭合带环的 13 格普通图、11 条普通 MAP specification、114 只直接怪、7 个怪种、57 个可执行可破坏物和两首原曲。结论只到 `runtime`：hell、事件怪 62502、封印门 60042、`bossaltar`、27 个 `gblhelipad`、56 个倒地障碍对象、城镇入口、任务奖励与用户实机验收仍未闭合。

## 一、来源与路线

- 原路径 `dungeon/village/gbl/gbl_hatchery.dgn`，SHA256 `266393055e4e3894218aa8f26b4ab35c1e7a416ec0b486b57cdfc1fe5b5b70ce`。
- 源名称解析为 `GBL教孵化场`；原档最低等级 47、basis level 50。
- `[worldmap pattern info]` 指向 `WorldMap/SelectdungeonSlot/gbl.img`，正式 route region 为 `behemoth`。
- 普通布局为 4×4 源网格，16 格中 13 格连通、3 格 `AA` 空位；起点 `(3,0)`，首领 `(2,2)`。
- 11 条 `[map specification]` 覆盖 `13027..13037`；起点 MAP `13026` 与首领 MAP `13038` 由端点角色选择。
- 首领格保留 `g3(b)001`、`g3(n)002`、`g3(n)010` 三个同布局候选，运行按 MAP `[type]` 选唯一 `[boss]`。
- 导出保留 13 个房间、19 个 placement 与 46 张原图。
- 最短首领路线为 `[13026, 13027, 13028, 13029, 13032, 13038]`，五步移动为 `left, left, down, down, right`。
- 普通曲与首领曲分别解析为 `M_GBLARAD_HATCHERY`、`M_GBLARAD_HATCHERY_BOSS`，环境音为 `AMB_INSIDE_01`。

地图导出诊断保留：

- 85 条 warning：82 个 `object_unrendered`、3 个 `AA` 空格。
- 52 条 info：39 个 `scroll_absent`、13 个含未处理标签的 MAP。

本批同时修正导出器元数据：`g3(s)001` 与 `g3(b)001` 这类以地图族前缀开头的文件，不再因文件名不是直接以 `s`/`b` 开头而统一标成 normal。路线选择仍以 MAP `[type]`、`[greed]` 和 DGN 端点为硬门禁。

## 二、正式入口

`game_dnf/data/dungeons.json` 新增 `gbl_hatchery`：

- `mode: native_maze`
- `hidden: true`
- `region: behemoth`
- `min_level: 47`
- `monster_level: 50`
- 原 DGN 路径与 SHA256

`FlowSession.depart("gbl_hatchery")` 可启动，城镇选择器仍不显示。世界内容审计当前识别 40 条非 legacy 路由、117 个固定房间和 22 个原生迷宫。

`thrower` 的四个动作没有直接 ATK 文件，`cocoon` 的六个 cast 动作也没有 ATK；它们仍只完成动作、图集和内容编译，不把无 ATK 动作冒充直接伤害。

## 四、对象与特殊载荷

普通首局 13 张 MAP 共 150 个场景对象：

- 65 个对象具备可破坏物候选结构。
- 57 个已有运行契约并可实际破坏，包含长椅花盆、短/长罐、白色废墟长罐、第二脊椎长罐与 treasure pot。
- 8 个 `altar2/altar3` action-object 没有已证实的 HP/阶段运行契约，登记 `native_breakable_source` gap。
- 1 个 `bossaltar.obj` 是独立 trap 路径，登记 `native_object_trigger`，不当作接触伤害。
- 27 个 `gblhelipad.obj` 没有基本动作，登记 `native_action_object_behavior` 与 `native_action_object_visual`。
- 56 个 `altar`、`ladydown*`、`throwerdown*`、`gbltentacledown*`、`craxydown*` 与 1 个 `act3_outerwallalter` 保留静态障碍/表现数据。

两个特殊长椅花盆带已登记的 `2210` trap payload。本批把原生迷宫中普通 `[special passive object]` 的 trap 选择从仅服务旧 `raw[0]==771` 的 `prepare()` 改为已验证候选 `prepare_candidate()`，使两个 `2210` 分支实际进入运行 prop；不支持的 trap ID 仍整体拒绝，未扩大猜测范围。

DGN 的 `[special passive object item]` 保留两个组：

- group 0：`1072/1500`、`1069/1000`、`1068/1000`。
- group 1：空组，level `-1`。

但这 13 张普通 MAP 的特殊长椅没有 `[item]` draw，因此 `NativeBoxLoot.required(dungeon)` 为 false。箱掉构建器已改为“地图引用组必须全部可编译，但允许零组”，本批未生成新物品包或虚构箱子。

事件、封印与隐藏层字段同时保留：

- `[event monster]`：62502，出生地图 10000。
- `[seal door map index]`：60042。
- `[seal door pos]`：`(1,1)`。
- `[seal door appear rate]`：10。
- `[hell dungeon]`：1。
- `[champion]` 与五条 `[hit count] 50` 只保留 raw。
