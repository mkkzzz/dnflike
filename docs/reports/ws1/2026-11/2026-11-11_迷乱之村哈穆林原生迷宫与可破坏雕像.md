# 迷乱之村哈穆林原生迷宫与可破坏雕像

本批把 `dungeon/act6/villageoftemptation.dgn` 接入隐藏正式 `native_maze` 路线，闭合 5×5 源网格中的 16 个连通房、3 个 boss 候选格、9 个怪种、146 只非 dummy 源怪、295 个非 dummy 对象、27 个可破坏物和两首原曲。三张 `[dummy]` fake-boss MAP 保留 raw 并排除在首局图之外。结论只到 `runtime`：EventMonster、封印门、champion/hit-count、trap 2211、任务/奖励/结算和用户同条件验收仍未闭合。

## 二、拓扑与正式路由

- DGN 只有 1 个 `[maze info]` block，选择结果为 `hell_base`：

| 项目 | 源值 |
|---|---|
| 网格 | 5×5 |
| Cell | 25 |
| 连通 Cell | 16 |
| 空格 | 9 个 `AA` |
| 起点 | `(2,4)` |
| boss 候选 | `(0,0)`、`(0,1)`、`(1,0)` |
| 固定普通 MAP | `(2,0)=6410`、`(2,3)=6402`、`(4,1)=6415` |

- `dungeons.json` 写入一条可复现的 8 房最短样本：`6401 → 6402 → 6403 → 6405 → 6407 → 6408 → 6410 → 6423 boss`。运行时 `NativeMaze` 仍保留全部 3 个 boss 候选和完整 16 房图。
- 源导出含 22 张 MAP、46 个 placement 和 75 张原图。
- `[greed]` 已按“布局 mask / 入口 mask”成对解析，支持同一 MAP 的 `NN II`、`FF EE` 等多入口候选。
- 3 个 boss 选择都能到达全部 16 房：

| Boss cell | 合法 boss MAP | 运行图 MAP 并集 | 怪物并集 | 对象并集 |
|---|---:|---:|---:|---:|
| `(0,0)` | 6422 | 17 | 128 | 265 |
| `(0,1)` | 6416 | 16 | 122 | 253 |
| `(1,0)` | 6423 | 17 | 128 | 266 |

- MAP 6418、6420、6424 的 `[type]` 为 `[dummy]`，分别载有 fake Peter 和 9/8/9 只怪；本批保留来源但不把 fake boss 冒充普通路线。BGM 表把这三张 MAP 登记为显式 source gap。
- 诊断：0 error、9 个 `cell_without_map` warning、22 个 MAP 未处理标签 info；单一 block 不产生额外的 `maze_block_selected` info。
- BGM 解析为 `M_HAMELN → hameln`、`M_HAMELN_BOSS → hameln_boss`；`AMB_TOWN_01` 环境声保留 raw。
