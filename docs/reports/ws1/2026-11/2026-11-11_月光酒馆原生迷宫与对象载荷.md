# 月光酒馆原生迷宫与对象载荷

本批把 `aganzo.dgn` 接入隐藏的正式 `native_maze` 路线，并从同一文件 6 套布局中选出唯一普通 block：5×4、10 个连通格、21 个 placement、62 只普通路线怪、5 个怪种和 95 张原图。结论只到 `runtime`：quest 4102～4106、最终 hell、`q` 变体、135 个无 HP/阶段契约的家具可破坏候选、2211 payload、Sinead 阶段/选招、城镇入口、任务奖励与用户实机验收仍未闭合。

## 一、来源与多迷宫选择

- 原路径 `dungeon/village/moonlightpub/aganzo.dgn`，SHA256 `882dc960c67fc9378e11b20e2331ad628cf012f78cc581c6e2f463280461524e`。
- 本地化名称解析为 `月光酒馆`；原档最低等级 49、basis level 52。
- `[worldmap pattern info]` 指向 `WorldMap/SelectdungeonSlot/townbar.img`，正式 route region 为 `noierfera`。
- DGN 内含 6 个 `[maze info]` block：

| block | 源网格 | quest connection | escape hell / hell | 用途 |
|---:|---|---|---|---|
| 0 | 2×1 | 4102 | escape | quest 变体 |
| 1 | 2×1 | 4103 | escape | quest 变体 |
| 2 | 5×1 | 4104 | escape | quest 变体 |
| 3 | 5×2 | 4105 | escape | quest 变体 |
| **4** | **5×4** | **无** | **无** | **普通路线** |
| 5 | 5×4 | 4106 | escape + hell | 最终 hell 变体 |

- 导出器现在保留全部 block 的 size、greed、start/boss、normal/boss specifications、quest/escape/hell 和封印门元数据，并显式写入 `maze_block_index=4`。
- `NativeMaze` 只读取 selected block 的 specifications；旧单 block 导出因缺少新字段默认 block 0，行为不变。

## 二、普通路线

普通 block 为 5×4 源网格，20 格中 10 格连通、10 格 `AA` 空位；起点 `(4,1)`，首领 `(3,3)`。

- 7 条普通 `[map specification]`：`16005,16003,16002,16001,16006,16007,16008`。
- 首领 specification：`(3,3) -> 16009`。
- 起点格保留 `aganzoboss` 与 `aganzostart` 两个同 mask 候选，按 `[start area]` 选 `16000`。
- 首领格同样保留两个候选，按 `[type] [boss]` 选 `16009`。
- 普通路线为 `[16000,16001,16002,16003,16006,16007,16008,16009]`，七步移动为 `left, left, left, down, down, right, right`。
- 普通 block 的封印门为 60039，位置 `(3,1)`。

导出保留 13 个源 MAP、21 个 placement 与 95 张原图。诊断：

- 135 条 `object_unrendered` warning，对应 81 个 chair、34 个 siktak、20 个 namutong action-object。

## 六、音频

`M_AGANZO` 与 `M_AGANZO_BOSS` 在源 `audio.xml` 中都解析到 `music/aganzo.ogg`：

- `aganzo.ogg`：SHA256 `65cfb5af423eb9ce0828247898eff7d8acce09ec1f1046b505b8767ffeee8072`，1,610,805 bytes。
