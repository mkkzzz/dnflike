# 根特周边原生迷宫与对象载荷

本批把 `outergent.dgn` 的 hell 基础布局接入隐藏正式 `native_maze` 路线，闭合 5×5 源网格、15 个连通房、双 boss 分支、6 个怪种、149 只全部源怪、186 个全部源对象和两首原曲。结论只到 `runtime`：封印门、事件怪、hell 生命周期、灯柱/APC/果袋破坏契约、drum tongue 行为、Bentinck 阶段、城镇入口、奖励/结算与用户实机验收仍未闭合。

## 一、来源与布局

- 原路径 `dungeon/act7/outergent.dgn`，SHA256 `246884645ad85315f63f144f86b1347fa52b4d8cc5df29006bccd2ff6d3dfdb7`。
- DGN 索引 80，本地化名称 `根特週邊`，正式名称使用简体 `根特周边`；最低等级 55、basis level 58。
- `[worldmap pattern info]` 指向 `WorldMap/SelectdungeonSlot/gent.img`；route region 使用 `gent`。
- DGN 只有 1 个 `[maze info]` block，尺寸 5×5，带 `[hell dungeon]` marker。
- 25 个源格中 15 格连通、10 格 `AA`；起点 `(2,2)`，boss 候选为西 `(0,2)`、东 `(4,2)`。
- 4 条普通 `[map specification]` 固定 `10hard/11hard` 与两条 normal 格；没有 boss specification，boss 格由 `[boss map]` 和 MAP `[type]` 解析。
- 每次 boss roll 选择一个 boss 房，另一个 boss 格从 `boss_not` 普通变体补齐；两条分支都是 15 房、15 张 required MAP。
- 导出包含 17 张源 MAP、29 个 greed-eligible placement、53 张原图；`NativeMaze` 单局解析为 15 房。

## 三、对象与可破坏物

全部源图 186 个对象；西 boss run 160 个、东 boss run 153 个。两个 run 都包含 2 个 `[special passive object]` 果袋。

- 运行可破坏源：0。所有 `smalllamp`、`roadlamp`、`roadlamp_half`、`jailapc`、`fruitsack2` 都只有源宽高/粒子/音效数据，没有当前 `native_breakable` HP/阶段/动作契约。
- 西 boss run 有 73 个 breakable 候选，其中 34 smalllamp、19 roadlamp、10 half、7 jailapc、3 fruitsack2；东 boss run 有 72 个，其中 roadlamp/half 数量不同。
- 西/东 run 分别有 43/37 个 `drumtong` trap 对象，均只登记 `native_object_trigger`，没有敲击/区域伤害/生命周期。
- 2 个特殊果袋分别带 `2200/2201` 或 `2210/2201` trap；因 breakable source 缺失，所有 payload 保留 gap。
- `sandfence*` 静态障碍渲染；`NativeBoxLoot.required()` 为 false，没有可执行 item group。

- 封印门 60034、事件怪 61728、hell、MAP 事件与回城链未接入。
- Bentinck 12 招阶段/油火组合、Nife Claese 3 招、Cartel soldier 投掷/射击投射物、Spy crouch/reload 和普通兵选招仍需原客户端同条件验收。
