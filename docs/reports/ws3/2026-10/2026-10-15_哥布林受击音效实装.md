# 2026-10-15 哥布林受击音效（生物叫声层）实装

> 范围：实机 `game/`（`scripts/combat_audio.gd`、`scripts/battle_fx.gd`）+ 音频资源 `game/assets/audio_v3/`。
> 起因：负责人反馈「攻击音效太差」，要求区分**主角攻击**与**怪物受击**，并给哥布林配受击叫声。
> 结论：受击路径原本**只有通用撞击拟音、完全没有生物叫声**——这是"差"的实际原因。本次在撞击层之上**分层叠加**一条哥布林惨叫（[D032](../../../design/决策清单.md)），并按负责人试听结果定稿。

## 1. 现状诊断：音效分工本来就分开了，缺的是生物叫声

排查 `combat_audio.gd` 与调用点后，实际分工如下：

| 类别 | 现有 key | 调用点 | 本次是否改动 |
|---|---|---|---|
| 主角攻击 | `swing_light` / `swing_back` / `swing_heavy` / `swing_air` / `swing_upper` / `dash_strike` / `draw_strike` / `thrust` / `rage_strike` | `battle_fx.gd` 攻击 active 相位 | 未改 |
| 命中撞击 | `light` / `heavy` / `launch` / `metal_hit` | `battle_fx.gd` `on_hit()` | 未改（保留） |
| 怪物死亡 | `death`（别名 `monster_death`） | `monster.gd` `_die()` | 未改 |
| 玩家受伤 | `hurt` / `death` | `player.gd` | 未改 |
| **怪物受击** | **（无）** | — | **本次新增 `goblin_hurt`** |

关键点：`hurt` 是**玩家自己**用的音效（`player.gd:1358/1375`），怪物受击不走这条。怪物受击只经 `monster.take_hit()` → `fx.on_hit()` 播出撞击拟音，没有任何生物发声。

因此本次不是"重做音效"，而是**补上一层缺失的生物叫声**。

## 2. 方案选择（负责人拍板）

| 方案 | 内容 | 结果 |
|---|---|---|
| **A（采用）** | 撞击拟音 + 生物叫声**分层并存** | 既保留刀砍肉体的打击实感，又听到哥布林在嚎 |
| B（否） | 用叫声**替换** `light`/`heavy` | 会丢掉打击实感，手感变轻 |

## 4. 加工链路（本机无 ffmpeg，全部绕过）

本机没有 ffmpeg，Python 只有 numpy（无 soundfile / scipy），因此搭了一条纯 WASM 链路：

1. **多流 Ogg 解复用**（关键坑）：Commons 这些文件是**两条复用流**——`serial=…410` 是 Ogg Skeleton（`fishead`/`fisbone`/`index`），`serial=…408` 才是 Vorbis。`stb_vorbis` 不支持多流，直接解码会报 `Failed to decode Ogg Vorbis stream`。需先**按 serial 抽出 Vorbis 流的页**重组为单流。
2. `stb-vorbis`（WASM，Apache-2.0，127 KB，零依赖无原生编译）同步解码为 44100 Hz 单声道 f32。
3. 20 ms 窗 RMS 找叫声段，按**平顶长度**与时长排序选取（避免从发声中间切断），首尾留 8 ms / 45 ms 余量。
4. 重采样到 48000 Hz。
5. **变调：升 16 个半音（倍率 2.5198）**。变调用重采样实现，故时长同比缩短——这是物理必然。
6. 去直流、归一化到峰值 0.72（低于工程上限 0.76）、首尾各 3 ms 渐变。
7. 输出 48 kHz / 单声道 / 16 bit PCM。

**已实测确认**：字面「8 个八度」会把 760 Hz 的质心推到超声、只剩 4 ms 静音；「8 度」按半音理解才对。最终按负责人在渲染样本中选定的一档（+16 半音）定稿。

## 6. 接线

**`combat_audio.gd`**

- `SOUND_SPECS` 新增：`"goblin_hurt": [-12.0, 2, 320]`（基准 −12 dB，steal 优先级 2，**节流 320 ms**）
- 节流取值理由：叫声长达 0.34~0.43 s，沿用撞击类的 40~65 ms 会让八连击糊成一片
- `ALIASES` 新增 `"monster_hurt": "goblin_hurt"`，与既有 `monster_death` 命名对称

**`battle_fx.gd` `on_hit()`**

```gdscript
# 怪物受击的生物叫声。放在两条分支之前，让 V6 招式与旧动作都覆盖到。
# on_hit() 目前只有 monster.take_hit() 一处调用入口，玩家被打不会走到这里，
# 所以无需按攻击方区分；将来若加入召唤物/友军互击，需要在此加参数区分。
play_sound("goblin_hurt", world_pos.x, 1.10 if heavy else 0.90)
```

放在 V6 / legacy **两条分支之前**是必须的：V6 招式在 `if authored:` 分支内提前 `return`，若写在分支之后，V6 四招（即当前主力招式）会完全没有叫声。重击强度 1.10、轻击 0.90。

## 7. 实测代价：混音余量

`combat_audio.gd` 有 **0.86 的硬预算**：所有活跃声道峰值和超出时，按比例整体降增益。加入本层后复刻该算法估算：

| 场景 | 峰值和 | 余量系数 | 影响 |
|---|---|---|---|
| 轻击（`light` + 叫） | 0.57 | 1.00 | 无 |
| 重击（`heavy` + 叫） | 0.64 | 1.00 | 无 |
| 上挑（`swing_upper` + `launch` + 叫） | 0.93 | 0.92 | 轻微压低约 8% |
| 三段普攻命中（`swing_heavy` + `heavy` + 叫） | 1.02 | **0.82** | **所有声道压低约 18%** |

这是既有混音架构的必然结果，不是本层引入的缺陷。**若实机听感认为连招压音明显**，把基准从 −12 dB 降到 −14 dB 即可缓解，`SOUND_SPECS` 一行可调。

## 8. 过程中发现的一个会坑到所有人的问题

回归首跑 **failures=1**：

```
[DEMO_TEST] FAIL offline foley variants contain valid sixteen-bit PCM
```

判据是每个音频流需满足 `stream is AudioStreamWAV and stream.data.size() > 2000 and stream.format == AudioStreamWAV.Format.FORMAT_16_BITS`。

排查：新 WAV 的 `.import` 里 **`compress/mode=2`（IMA-ADPCM）**，而**既有 81 个文件全是 `compress/mode=0`（PCM）**。ADPCM 会让 `stream.format` 变成 `FORMAT_IMA_ADPCM`，直接违反判据。导入缓存体积也印证了：新文件 `.sample` 只有 WAV 的 **0.21 倍**，既有文件是 **1.01 倍**。

**这不是我这批文件特有的问题**：编辑器里没有任何 wav 导入默认值（`project.godot` 无 `importer_defaults`，`editor_settings-4.7.tres` 无 wav 项），说明新文件走了与既有一批不同的导入默认值。**结论：以后任何人往工程加音频，都可能默认被导成 ADPCM 并被回归拦住。**

处理：把 3 个 `.import` 的 `compress/mode` 改为 `0` 并入库（`.import` 是被 git 跟踪的，修复对其它 clone 同样生效），重新导入后体积比回到 1.008~1.01，回归恢复 271/0。

> **给后续加音频的人**：`.import` 生成后请确认 `compress/mode=0`，否则会触发上面那条回归失败。
