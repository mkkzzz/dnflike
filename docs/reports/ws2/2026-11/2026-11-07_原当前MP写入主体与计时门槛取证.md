## 当前MP写入主体

实际执行的 `D073C0` 返回 `actor+2BEC`。当前MP getter `D07AC0` 从该地址的 `+0C` 保护槽读取，即角色 `+2BF8`，完整执行到返回。虚表460、514、518分别指向 `D073C0`、`812260`、`D07AC0`。

在上述准备前提下，`812268..8122D8` 的真实顺序是：

1. 以角色 `+3598` 为计时对象，调用 `11AFA40`，实际读取/解码对象 `+0C`，取最低位。
2. 最低位为1时，调用 `11AFCF0` 检查计时结果是否达到对象 `+18` 的阈值。未达到才通过原虚表518读取当前MP。
3. 仅在“最低位为1、尚未达到阈值、目标值按有符号比较小于当前值”时跳过写入。相等与更大值仍允许。
4. 允许时，向当前MP槽 `+2BF8` 发出保护写入。第二参数低8位非零时，再向角色 `+3110` 写入FFFFFFFF；该字段后续用途未解。
5. 在 `8122D8` 保护出口前停止。另行准备一次 `D07AC0` 调用，让原getter读取同一保护存储夹具，验证主体写入/跳过后可读值；这不是伪装成完整setter返回。

禁止写入时两个槽都不更新。允许分支在本段没有零下限或上限夹取，负数/大值按32位写入；**这个结论只适用于已执行主体，不能扩展成整个原游戏没有资源值限制**。

## 原计时函数实际读取

本批完整执行 `11AFA40`、`11AFCF0`、`11AFBD0` 和 `11E64B0`，未将它们简化为返回真假的替身。

| 原对象字段 | 已证消费 |
|---|---|
| +0C | 解码后使用低位标志 |
| +18 | `11AFCF0` 比较阈值 |
| +14 | 标志低三位均为1时，直接返回此缓存值 |
| +08 | 非缓存分支的全局时钟表索引 |
| +10 | 非缓存分支加到所选时钟值上的偏移 |

`11AFBD0` 在低两位没有同时为1时返回0；同时为1且位2为1时返回缓存值，否则调用原 `11E64B0`，从全局表 `1BCAAE0 + index*4` 读取并解码，再加偏移。加法按32位回绕，随后阈值比较是有符号比较。

`11AFCF0` 的SETGE只写AL，高24位保留计时结果。比如计时值7FFFFFFF、阈值100时，完整EAX为7FFFFF01；回绕到80000000时返回80000000，AL为0。原调用方测试AL，不能把整个EAX非零当作条件满足。

时钟表在夹具中准备16个不同值的槽，覆盖索引0、2、15，以检验真实索引/步长。时间单位、时钟通道的玩法含义、生产/更新频率、计时对象初始化及触发时机仍未知，因此没有补造恢复间隔或施法消耗规则。
