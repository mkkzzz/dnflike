# 洛兰原副本选择器

正式洛兰入口以前按页内序号取通用区域图和卡片。现从原 WDM、UI balloon 和位置表编出 DGN 1、2 的区域图、卡片和连线。生成器将原 Dungeon LST 的 ID、DGN 路径和 SHA 与现行路线逐项比对，再绑定卡片。原 WDM、UI、位置表、两份 DGN 和 LST 均在指定客户端的 ImagePacks2 PVF 中通过 CRC，与共享库字节一致。 [选择器构建](../../../../tools/build_dnf_flow_assets.py) [资源清单](../../../../game_dnf/assets_local/flow_v1/dungeon_selector_v1/manifest.json)

原 `0x106DBBD` 以 balloon 的模式索引读取位置表，`0x106D630` 用原 UI 锚点加收起和展开偏移。收起卡图使用原 0.7 倍，点击区为 118×53，展开点击区为 168×63。DGN 自己的图集和帧字段只决定卡片身份。洛兰使用模式 3，收起和展开位置分别是 `(399,234)`、`(399,226)`。洛兰深处使用模式 1，对应 `(234,351)`、`(210,352)`。当卡片重叠时先让展开卡接收点击。 [共用窗口](../../../../game_dnf/ui/flow/native_windows.gd)

正式游戏交互 170 项、生成检查 5 项通过。实际操作覆盖洛兰深处锁定时点击、完成前置后同位点击、展开卡片和难度选择。两张展开卡各 49944 个不透明帧缓冲像素与源图匹配。难度条、锁定染色及当前简中按钮沿用工程样式。天空之城六张普通卡已核源，任务路线 DGN19 的原帧 7 在现有同名图集中缺失，原 UI 和 WDM 的背景引用也需核对。其它区域继续使用既有窗口，入口和开放条件由正式流程控制。 [正式交互检查](../../../../game_dnf/tests/flow/test_interactions.gd)
