# 基础精通原生作用范围与误加修复

原实现把基础精通第0列直接编译成全局物理攻击百分比，因而会提高无关物理技能的伤害。本批重放指定客户端的原攻击记录修正函数、鬼剑士状态门槛、攻击类别选列及等级包装器，并移除该错误全局加成。基础精通对普攻的正确加成仍待接入，不以删除错误实现宣称整招复刻完成。

## 原来源

原客户端为用户目录中的 `情怀60复古/DNF.exe`，外层SHA256为`8748e19abf6155ca5a20d13244eaca0b9442c3d7569e8e5002bddffeeb9366ac`，内嵌引擎SHA256为`187ad34ab6bfff040d9b12bb145bdda0bba29f82aaa41183280b0ae42e914b84`。工具只读字节并在Python解释器中重放，不启动原程序。

原技能174路径为`skill/swordman/basicattackup.skl`，版本`dnf-native-assets-v1-20261022`，SHA256为`d6287b7182bb5471a578b6225bcc369d82665163362801fa660e22973ebad0e4`。原说明链接`skill/skill.kor.str`的`basic_attack_up_explain`，只增加基本、前冲、跳跃攻击。等级展示`basic_attack_up_level_property`依次列出三类攻击的增量百分比；原等级表为3列、100行，各行三个值均为`24*(等级-1)`，静态第0列为1，展示比例为0.1。

原最大等级100、六职业上限均为1、关联技能索引161。不能仅根据这组字段推断自动成长算法，也不能直接把角色等级当作技能等级。完整字段、原说明链接/行号/文字表SHA和原指令块见[机器证据](native_basic_mastery.json)。

## 原指令路径

| 路径 | 本次证实的行为 |
|---|---|
| `83FA10`完整入口/返回 | 空攻击记录退出；虚表`+7D0`查询174，等级不大于0退出；`+804`找不到技能退出；通过`+878`类别/状态门槛后才修改攻击记录 |
| 鬼剑士虚表`16F972C` | `+878`指向`C9EE60`，`+87C`指向`83C040`；按原表实际分派 |
| `C9EE60` | 依次检查owner的`+6A44/+6514/+67E8`状态指针；非空时调用状态虚表`+70`，任一返回真便拒绝，后续状态不再查询；否则进入`83C020` |
| `83C020`/`83C040` | 只接收类别8、7、15，分别读取技能174的第0、1、2列；与原说明三列顺序相符 |
| `9095B0`完整包装器 | 读取技能安全字段`+59C`中的等级，向保护值服务`908770`传入列、等级、owner、−1、−1、14、0、0；返回值先经`13CD690`截断为整数 |
| `83FA10`修正尾段 | 读取静态第0列；非零走单精度乘法分支，零走整数除10加法分支；只写本次攻击记录`+24`，不写角色全局物攻 |

令`V`为等级值服务返回值截断后的整数，`B`为攻击记录原`+24`整数。静态列非零时，逐步执行：`float32(V)*float32(0.1)`、加100；`int32(B+100)`转float32后与前者相乘，再乘float32(0.01)，减100，最后截断为整数。每次SSE运算均发生单精度舍入，不能合并成一次双精度计算。静态列为0时则向原记录加`trunc(V/10)`；原技能当前配置走非零分支。

例如输入记录35、原第60行1416，输出记录226。这里是攻击记录修正结果，**不是最终伤害值**。合成24/48/72三列用于识别选错列的实现；原档案三列相同，单用原表样本无法暴露该错误。
