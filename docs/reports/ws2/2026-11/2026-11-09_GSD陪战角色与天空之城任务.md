# G.S.D. 陪战角色与天空之城任务

## 原 AI 行为与按键映射

运行时读取上轮核对过的 APC201、202 程序。它保留原普通版和觉醒版的行动树，按原导入路径解析分支，并使用原 `[quick skill]` 顺序和 KEY 命令确定技能 ID。`8CAF3B` 经剑士 `+928` 调用 `852ED0` 判断技能能否使用，包含有效等级、冷却和 MP。`8CAF7B` 经 `+930` 调用 `C9D3E0` 检查相应技能的对象状态，自动格挡和杀意波动使用各自的附件对象。

`8C9820` 使用按朝向镜像的整数前后区间和独立 Y 区间。`8DA00C..8DA034` 用 `+8` 距离函数写入目标距离，`406580 -> 7F10A0` 对地面深度投影并截断后再算距离。`8DA059..8DA086` 读目标虚表 `+B8` 的原状态，原枚举表 `sqr/dnf_enum_header.nut` 定义 `STATE_DOWN` 为 4。Godot 程序专项 38 项通过，覆盖左右边界、按 Y 投影的 600 距离门槛、普通和觉醒版分支、命中后出招和两版的十条 KEY 绑定。

现有战斗执行器将选出的 KEY 映射为技能调用，技能动作、对象时钟和命中复用现有剑士内核。三连普通攻击后接冰刃的 KEY 状态门槛仍待执行器接入。原 KEY 按住、等待以及目标移动方法的完整状态机仍待核对。 [AI 执行入口](../../../../game_dnf/combat/action/companion_program.gd)

两版 AIC 的 18 个装备 ID 逐个解析。外观来自 G.S.D. 专用短剑 27102、眼罩 39172、无像素头发槽 39559、白胡须 39898、披风 40299、手臂 40776、裤子 41174、腰带 41503、鞋 41950 和肤色 42211。两份原 PVF 的 324 项 AIC、索引、EQU、CHR、LAY 与 ANI 逐字节一致，本机原 NPK 的 15 份图像与提取输入一致。图集包含 141 个合成帧和 21 个动作键。

原 LAY 的装备层顺序参与合成，身体插入在原后层和前层装备之间作为当前适配。波动斩蓄势的白色剑身使用原动作帧着色。Godot 实绘检查站立、冲刺、镜像、上挑、波动剑和倒地，并在龙人之塔 MAP1618、人偶之塔 MAP1819 的正式战斗入口截取两版角色，站位分别为 `[250,245,0]` 和 `[186,238,0]`。 [外观图集](../../../../game_dnf/assets_local/companions_v1/manifest.json)

## 战斗与存活事件

陪战者按原地图位置生成，独立持有血量、MP、技能等级和冷却。两版 AIC 的 0.6 与 0.2 伤害倍率接入相应角色。角色按原分支选招，玩家及陪战者只能攻击敌方，怪物可对陪战者造成实际伤害。活角色带剩余血量和原实体身份切房，阵亡角色保持阵亡，并发送一次事件。终房事件携带实际 MAP ID 和存活 APC ID。当前基础属性沿用现有角色数值，目标优先级、追随路线和切房落点为适配。完整 AIC 属性及技能修正、原移动方法与全部觉醒动作仍待核对。

陪战战斗专项 36 项通过，验证两张原起点图的角色站位和图集，原怪物招式实际命中两位 APC，友方波动剑不会误伤，陪战者从原 AI 选招并命中，存活或阵亡都跨房保留，两张终房回报对应的 MAP 和 APC 状态。两个实绘截帧分别记录普通版释放地裂波动剑和觉醒版进入杀意波动。 [战斗入口](../../../../game_dnf/combat/api/combat_session.gd)

## 任务开放与领取

原任务 4307 为 16 级且需要 4306，4308 为 18 级且需要 4307。两者均由 G.S.D. 接取和交付，不可放弃，原奖励各 5000 金币。Session 仅在单人勇士级、正确专用路线、正确终房 MAP 和对应 APC 存活时写入陪战进度。进度服务再次检查地图、路线、难度、人数和存活记录。普通图、APC 阵亡、其它角色、旧战斗事件与重复交付用例均通过。

任务专项 225 项通过，使用正常任务目录受理后通过两条专用路线，使用击杀夹具清完 18 房，实际战斗终房事件推动两条任务完成，并回 G.S.D. 领取各 5000 金币。后续 4309 拜访凯丽、4310 冒险级石巨人塔、4311 冒险级幽暗回廊也验证接交。可执行原任务由 127 条增至 132 条，原 127 条定义逐项一致。本批新增任务经验暂为 0，仍待原公式接入。 [任务规则](../../../../game_dnf/data/native_quest_rules_v2.json)
