# 地裂波动剑等级列与对象大小修复

全游戏还原目标下继续核对地裂·波动剑（源技能 ID 20）。本批修复技能等级列错位、固定伤害分量丢失，以及对象大小没有进入显示和碰撞的问题。整招动作、特效组合和释放状态仍未还原完成。

## 原始证据

来源为只读库 dnf-native-assets-v1-20261022；SKL/ANI/OBJ 属于此前与用户指定目录 ImagePacks2 PVF、111 备份逐文件校验一致的范围。此次另外读取两个 PVF 的 sqr/common.nut，文件 CRC 均通过，SHA 与库一致。尚未证明原客户端实际选择哪个 PVF。

| passiveobject/character/swordman/normalwave.obj | 7b8505e1dee77fe84745f6f84cb7ded0ece9d88445c6f96398d808c309272085 | 绑定对象动画与攻击信息 |

SKL 的 dungeon.level_info 首值3表示三列，第一行 `[69,115,317]`，第二行 `[78,116,357]`，共70行，末行 `[726,183,3309]`。level_property 参数顺序为 `[-1,2,1.0, -2,0,1.0, -1,1,1.0]`，零基列2对应百分比伤害、列0对应固定分量、列1对应大小百分比。

该字段的文字在通用 cp949 解码结果中乱码。本次从 SKL token 偏移2577取得字符串索引455600，再按 stringtable.bin 的原偏移读取原字节；cp950 严格解码可读为“魔法攻擊力 : <int>%% + <int> / 大小比率 : <int>%%”。没有覆盖全库编码或把乱码译文当依据。

## 实现与验证

- 生成器仅为 normalwave 明确声明 percent_col=2、fixed_col=0、size_col=1，重新生成运行数据；其它技能的静态列不作类推。
- MoveTable 分别传递百分比和固定分量，按原大小百分比计算 size_rate。已有伤害公式继续负责独立攻击力分量，本批没有认证该公式全部常数。
- 对象保存生成时的比例，经快照传给 FxView.base_scale；碰撞盒的本地偏移和长宽高绕对象锚点同比缩放，之后转换朝向和世界坐标。不修改共用源 ANI，未声明比例的对象保持原尺寸及原快速路径。
- 新增数据断言在旧生成结果上失败（旧值为列0，缺固定/大小列），修复后技能数据11项通过。
- 引擎检查全部70个等级行，验证魔法攻击与独立攻击分别改变对应伤害分量；双朝向、默认/115%大小、共享源不被污染，以及实际生成对象→快照→视图→边缘目标碰撞均通过。专项34项、完整战斗229项通过，日志无 SCRIPT ERROR。
- 正式入口完整循环435项通过；依赖、性能、数值配置检查通过。测试数量表示回归覆盖，不表示技能一致性验收。

## 仍需继续核对

- 当前仍使用 summon2 通用身体动作。wave.ani 有9帧，首帧10000ms，其余50ms×7及150ms；首帧明显需要状态控制，尚无原生状态代码证明应如何退出，不能机械播放整段10.5秒。
- common.nut 已给出专用挥剑特效绑定；其5帧各50ms，但脚本只负责加载，没有给出生成时机。身体动作、武器双层、挥剑特效与出波时刻需作为一组接入。
- 当前出波340ms、速度520、存续1500ms仍是旧适配参数；SKL static_data 为 `[250,100,-150]`，语义尚未取证，不据此随意替换参数。
- 原说明限定转职阿修罗后才可强制中断普通攻击。本批未修改取消门槛；待与原状态机一并核对。
- 大小列来源已确认；当前三轴碰撞随视觉统一缩放是引擎适配，仍需原生对象代码确认缩放轴、锚点及边界规则。全技能与全游戏目标继续进行。
