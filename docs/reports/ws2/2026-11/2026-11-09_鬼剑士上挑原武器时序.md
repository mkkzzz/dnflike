# 鬼剑士上挑原武器时序

以《情怀60复古》v48984 的两个安装档案和原客户端为依据。配套武器 B、C 动作与战斗身体取自两档字节一致的条目。运行时继续使用[原武器清单](../../../../game_dnf/assets_local/weapon_appearance_v2/manifest.json)和[姿势补充清单](../../../../game_dnf/assets_local/weapon_appearance_v3/manifest.json)。

原客户端装备挂接路径 `0x81A0FF → 0x8441C0` 将身体同索引帧的延时复制给两个武器层，再推进各层。上挑的身体 HitBack 开头为 100 ms，随后每帧 50 ms，末帧 400 ms。武器原文件总长 550 ms，挂接后与身体同为 850 ms。此次在运行时附加复制帧长，保留原 ANI 字节。普攻三段也沿用同一挂接方式。 [武器层接口](../../../../game_dnf/content/api/weapon_appearance.gd)

| HitBack 时钟 | 修正前身体 / 后刀 / 前刀 | 修正后身体 / 后刀 / 前刀 |
|---|---|---|
| 50 ms | 51 / 52 / 52 | 51 / 51 / 51 |
| 100 ms | 52 / 53 / 53 | 52 / 52 / 52 |
| 400 ms | 58 / 59 / 59 | 58 / 58 / 58 |
| 450 ms | 59 / 59 / 59 | 59 / 59 / 59 |

已核对 63 种武器外观的两层数据。外观规则通过 33,490 项，正式换装、读档、进图和真实 Z 输入通过 28 项。ws1 可在已发布运行包上复验实际进图和 50–100 ms 三层同时保持第 51 帧。 [外观规则专项](../../../../game_dnf/tests/items/test_weapon_appearance_rules.gd) · [实战专项](../../../../game_dnf/tests/items/test_weapon_appearance_quick.gd)

接触规则已定位到 `0x81A6B0`。原客户端先检查主 ANI，再按直属子层检查。普通状态按目标 actor 登记一次，安装新 ATK 时清除登记。后续战斗批次接入源命中盒与采样窗口，并分别校对增强短剑分支、特效、音效和取消条件。
