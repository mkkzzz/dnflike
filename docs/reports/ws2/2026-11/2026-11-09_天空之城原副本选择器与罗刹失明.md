# 天空之城原副本选择器与罗刹失明

## 天空之城

- `worldmap/skycastle.wdm` 指向 `skycastle.ui`。客户端 `110F801…110F834 → 111C1EC…111C283` 在普通选图读取 UI 的 `IDC_WORLDMAP_BACKGROUND`，使用 `Lorien.img#0`。WDM 里的 `SkyCastle.img#0` 属于独立的关卡地图入口。缩放和点击区域从 UI、原连接器偏移表和各 DGN 共同解析。
- 已开放路线中的 DGN 11、12、13、14、15、17 使用原卡图。亚蒙下层 DGN19 的 `IDC_WORLDMAP_BUTTON1` 要求 `WorldMap/SelectDungeonSlot/SkyCastle.img#7`，用户图包中该唯一同路径图集只有帧 0–6。原 `11AA190…11AA1A7` 越界分支返回 `6FD626…6FD660` 加载的 `Interface/Base.img#91`，即 1×1 透明帧。实装复用透明帧，在原黑底卡位内加中文可点击提示，保留原连接器、任务门槛与路线。
- 独立构建包含 13 张源帧。13 张 PNG 逐像素匹配相应原 IMG，洛兰包重建逐字相同。Godot 实际渲染和交互检查 186 项通过，覆盖从西海岸步入、锁定、完成前置任务、逐卡点击及 DGN19 真正出征。DGN29 与 UI504 尚未接入这组选择器。通用外框、难度控件与分页文字仍沿用项目当前实现。

## 罗刹失明

- 原罗刹子体进入稳定附着后才允许抽取异常。原 `1124952…1124995` 每次抽取将上次触发时刻增加一个源等级间隔。每个更新只抽一次，抓附切换同一更新只处理状态切换。指令重放覆盖间隔 2599/2600 毫秒、一次跨过两个间隔及同帧后续补偿边界。
- 原 `8AC500 / 8146A0` 消费独立失明抗性，`8ADBB0 → 8AE001` 用等级差修正持续时间和两项载荷。`8B5281 → 8B535C` 按两项载荷和总持续时间比较，只有更强的效果重启计时。原 `8B5CC1` 把普通怪物背部索敌距离折半，`880487…8804D0` 对缩短后的距离乘 1.4 后截断并使用原投影距离。原距离为零会跳过距离限制。
- 实装以项目现有 MOB 视野作为普通怪物原背部索敌距离的输入适配。Godot 技能专项 294 项通过，包含无提前抽取、抓附转换、抗性、重施、投影距离与到期恢复。技能构建回归 22 项通过。失明的落空判定、头顶动画、中毒、出血以及特殊怪物视野字段仍待接入或核对。

同批正式游戏流程 465 项、独立战斗 575 项通过。
