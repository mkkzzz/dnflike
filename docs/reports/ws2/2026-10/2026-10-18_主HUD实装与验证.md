# 主 HUD 实装与验证

本轮执行用户“把 UI 实装一下，原先那些非正式的、调试类的都去掉；帧数信息小一点放在角落”的要求。已认可样张和首批资源未换稿，直接复用同包导出，完成运行时接线，待用户实机试玩。

## 实装结果

- [HUD](../../../../game/scripts/hud.gd)以原生 2K 布局绘制新金属底栏、红蓝液面和静态玻璃、轮盘、技能/道具框、目标栏、标题和小地图。底板重复平铺，目标条重复中段，不放大装饰贴图。画布逻辑尺寸保持原有值，由 canvas_items 以实际窗口分辨率绘制。
- HP/MP、真实怪物目标/血量/多层血条、连击、实际副本图连接/当前房/已清房/末房标记全部读取游戏状态。未实现的经验保留空轨，假评价、假增益、示意道具不渲染。
- 技能两排十二格 QWERTY/ASDFGH，默认 A/S 放当前职业技能；支持点击施放、拖换位置及职业独立保存。技能身份与 MP/冷却独立于槽位。数字 1/2 与红蓝药点击调用原战斗行为。
- 轮盘齿轮打开原有显示设置，可设置 FPS/垂直同步；F3 保留。角落 FPS 约 14 像素（1080p），旧常驻显示设置按钮/大 FPS/帮助文本、模块 ID、未实现回城按钮清掉。T/R 调试绑定移除，供十二格技能使用。隐藏 P 开发面板保留，不常驻显示。
- 底部栏维持整组前景让位，适配轮盘升高后的起始位置；遮挡时半透明，离开后恢复。设置/GM/暂停时不接收战斗 HUD 点击。

资源入口：[运行时清单](../../../../game/assets/ui/hud_v2/manifest.json)逐项列出文件、源、哈希、尺寸和是否使用。首批导出与运行时复制逐字节一致；血怒/怒斩追加图的[真实生成记录](../../../../art/ui/hud/reference_v2/runtime_additions/generation.json)保留原始输出和提示词。使用 96×96 图标，源为 1254×1254，仅缩小。旧 theme_v1 与未实现道具源图保留归档。

## 验证及隔离范围

本轮以 `b173d20` 正式主线加 HUD 变更建立 `temp/hud_integration_check` 独立无 Git 快照，运行 Godot 4.7.2 导入和测试。这避免把同工作区尚在生成/导入的 V7 c6 动作候选混入 HUD 验证或提交。快照使用现行森林、门、实体、哥布林与已提交角色表现，没有重新生图场景。

- 原有主回归：`[DEMO_TEST] COMPLETE checks=373 failures=0`，退出码 0。
- HUD 专项：`[HUD_TEST] COMPLETE checks=18 failures=0`，退出码 0；覆盖真实 MP/施放/冷却、换槽后身份、缺蓝阻挡、药水、真实地图/目标更新、整组让位、齿轮暂停与恢复、资源加载及常驻调试清理。
- 两种窗口分辨率各通过上述功能检查和两张帧缓冲保存，`checks=20 failures=0`，退出码 0；独立快照导入/测试无引擎错误。
- [证据 JSON](../../../screenshots/hud_v2/verification.json)记录快照基线、消费者哈希、测试摘要及图片尺寸/哈希；[专项输出](../../../screenshots/hud_v2/hud_checks.txt)保留原始结果。易变质量基线见[进度看板](../../../project/01_进度看板.md)。
- 共享工作区另行运行 HUD 检查也通过，但并行 V7 c6 运行曾出现动作层 PNG 未导入错误；该错误不计作本轮无错误验证。没有修改或删除这些并行产物；动作候选的后续导入/验收由其任务继续处理。

复现：在已提交 HUD 的游戏目录先执行 Godot `--headless --editor --import --quit --path game`；专项使用 `--headless --fixed-fps 60 --path game --script res://scripts/hud_regression.gd -- --hud-test`；实拍去掉 `--headless`，添加 `--resolution 1920x1080` 或 `2560x1440`，参数换为 `-- --hud-capture`，输出到 `temp/hud_runtime`。原有主回归使用 `--headless --path game --fixed-fps 60 --quit-after 18000 -- --test`。

## 剩余验收

用户在正常战斗中确认整体比例、金属/液面观感、前景让位及拖换手感。自动化和截图只说明接线与运行结果，不代替用户视觉验收。经验系统、其他道具与轮盘剩余按钮不在本轮新增功能范围。
