# C9 整身步态重做

## 当前结论

整套基础动作仍处于源图制作，未新增实装。用户否决的 C8 拆件步态不再沿用；C9 每张均重新绘制完整人物，没有固定躯干套腿、分腿 IK 或局部缩放头部。已认可 idle、即时转身、受击修复及第一刀 GM 试用保持原状。

用户先指出拖刀样张“握刀不自然”，随后明确“拖刀的动作其实是对的，但是刚刚你的手握刀不自然”。因此退回的是旧握持，拖刀方向保留。中途按错误理解制作的向前持刀稿已废弃。新版 C3 重画拇指扣握、手指包柄与手腕关系，用户答复“握持方向可以继续”；批准仅限单张握持方向，允许继续整身姿势制作，不是完整循环或实机验收。

入口：[交互预览](../../../previews/v7_c9_whole_body/index.html)、[源规格](../../../../art/animations/players/swordsman/v7/sources/whole_body_gait_c9/spec.json)、[握持方向批准](../../../../art/animations/players/swordsman/v7/sources/whole_body_gait_c9/run_drag_grip_c3/direction_approval.json)。批准绑定实际展示的独立太刀预览、身体与分层 manifest SHA。

## 视觉检查与经验

- 新旧拖刀原画对照显示，早期几次局部改图仍复制旧手形，不能因调用成功就认定握持修好了。改用完整人物重新绘制后，才得到可辨认的弯曲手指与拇指扣握。
- 缠布覆盖的拇指也是前景遮挡。只提取肤色会漏掉拇指，让刀柄盖在缠布上；当前 C3 用经核对的整段拇指/手指多边形覆盖，身体底图逐像素不变。
- 近远腿身份以髋部遮挡关系、完整大腿/膝/脚连接检查，不能按图左右或文件命名推定。第一次“近侧蹬伸”实际画反，已保留退回；后续借完整人物反侧步态参考纠正。
- 八张原画的源比例通过后，合图仍暴露压缩和腾空不对称。下一步应改源姿势和补整身交叉原画，不能直接插值后实装。
- 过程参照了 AnimSchool 的 [Walk Cycle Animation Tips](https://blog.animschool.edu/tag/animation-tips/page/6/) 与 [The Key Poses of a Run Cycle](https://blog.animschool.edu/tag/animschool/page/6/) 的文字关键姿势说明；没有声称观看或分析未实际查看的游戏录像。
