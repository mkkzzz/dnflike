# C9 整身步态重做

## 当前结论

最新反馈：用户认为 C4 连播没有迈步感，像两脚反复交替；因此不能只修正几张极值姿势。按“那你试试呢”试制 C5 整身收腿/过步草稿，已放到预览页顶部。C5 仍是待修正的动作设计试验，不是正式 actor 导出，具体见文末。

整套基础动作仍处于源图制作，未新增实装。用户否决的 C8 拆件步态不再沿用；C9 每张均重新绘制完整人物，没有固定躯干套腿、分腿 IK 或局部缩放头部。已认可 idle、即时转身、受击修复及第一刀 GM 试用保持原状。

用户先指出拖刀样张“握刀不自然”，随后明确“拖刀的动作其实是对的，但是刚刚你的手握刀不自然”。因此退回的是旧握持，拖刀方向保留。中途按错误理解制作的向前持刀稿已废弃。新版 C3 重画拇指扣握、手指包柄与手腕关系，用户答复“握持方向可以继续”；批准仅限单张握持方向，允许继续整身姿势制作，不是完整循环或实机验收。

入口：[交互预览](../../../previews/v7_c9_whole_body/index.html)、[源规格](../../../../art/animations/players/swordsman/v7/sources/whole_body_gait_c9/spec.json)、[握持方向批准](../../../../art/animations/players/swordsman/v7/sources/whole_body_gait_c9/run_drag_grip_c3/direction_approval.json)。批准绑定实际展示的独立太刀预览、身体与分层 manifest SHA。

## 视觉检查与经验

- 新旧拖刀原画对照显示，早期几次局部改图仍复制旧手形，不能因调用成功就认定握持修好了。改用完整人物重新绘制后，才得到可辨认的弯曲手指与拇指扣握。
- 缠布覆盖的拇指也是前景遮挡。只提取肤色会漏掉拇指，让刀柄盖在缠布上；当前 C3 用经核对的整段拇指/手指多边形覆盖，身体底图逐像素不变。
- 近远腿身份以髋部遮挡关系、完整大腿/膝/脚连接检查，不能按图左右或文件命名推定。第一次“近侧蹬伸”实际画反，已保留退回；后续借完整人物反侧步态参考纠正。
- 八张原画的源比例通过后，合图仍暴露压缩和腾空不对称。下一步应改源姿势和补整身交叉原画，不能直接插值后实装。
- 过程参照了 AnimSchool 的 [Walk Cycle Animation Tips](https://blog.animschool.edu/tag/animation-tips/page/6/) 与 [The Key Poses of a Run Cycle](https://blog.animschool.edu/tag/animschool/page/6/) 的文字关键姿势说明；没有声称观看或分析未实际查看的游戏录像。

源引用/请求/输出共38次生成记录逐项核对哈希；获认可的握持图、同身体三武器与原画视频绑定验证通过。文档检查只报既有的19音效流程365行超过300行，本轮未修改该文件。预览链接曾被自动识别连入中文后缀产生404，已将当前标签恢复到正确地址并验证；后续使用 Markdown 链接。

最新续做改为先解决承重脚后移、身体经过支撑脚、屈膝收腿经过身体下方的连续关系；C4 不直接加补间。随后才处理正式姿势比例、去刀层、握持标点与同身体三武器连续回放。步行仍需匹配两侧承重和过步。两者达到完整动作要求后再做起停及实机接入。后两刀仍按原任务继续，技能后置。

详细退回与下一步分别见源目录的 motion_review.json、run_cycle_c4/motion_review.json。保持语义 ID、根锚点、60Hz时钟及现有混合契约；候选预览与实装必须来自同一导出包。原生2K源画布尚未达标，未用放大补足。

## C5 连续迈步试验（10月21日至22日续做）

- 用户要求先试做连续运动。使用内置 image_gen 生成两张动作板；第一张未遵守过步相位，退回。第二张额外实际提交整身运动定位图，选作连播诊断。完整提示词、参考/结果哈希和弃用理由见 [生成记录](../../../../art/animations/players/swordsman/v7/sources/whole_body_gait_c9/run_motion_c5/generation.json)。
- 定位图是整个人体的绘画参考，标出左右腿连续轨迹；其中解析关节计算只画技术示意，未变形成品人物、未生成腿件、未拼接身体。实际人物由生成器整身绘制。参考了 Animation Mentor 的 [Dynamic Run Cycles](https://www.animationmentor.com/blog/animating-dynamic-run-cycles/) 关于承重、过步和蹬伸的文字说明，未观看其视频。
- 请求原生2560×1440、4×3格，每格640×480、站高380；实际两图均1672×941。第二张实际12个完整人物，人工检查格界后只裁切、整体平移，保留源像素和alpha；回放460×340，合图1840×1020，未放大。周期36 tick，12张原画，60Hz视频重复6次；没有RIFE/交叉淡化或肢体变形。
- 这套低分辨率动作板没有同图直立标尺，**未通过正式G1，也不是可换武器交付**。作为源动作设计试验单独保存于预览目录，禁止绕过门禁用于正式 actor 或游戏。临时草稿锚点(280,320)仅用于这个1:1裁窗；游戏锚点契约未变。
- 第二稿有更紧凑的收腿和双腿接近的过步轮廓，但左右膝遮挡仍难辨、脚底与地面有偏差、头脸/衣摆/画入的刀跨帧漂移。源稿阶段仍需修正，不能登记自然、完整、流畅或获认可。
- 浏览器已验证0.5倍/1倍播放、逐张切换按实际非等长原画起点定位；移除视频内置控制条以免遮住脚，使用上方按钮。图像来自同一 [草稿回放包](../../../previews/v7_c9_whole_body/run_motion_c5/manifest.json)，正式连续与实装尚未制作。
