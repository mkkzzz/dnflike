# 游戏中文与原图文字清理

用户要求项目为中文，游戏中不要出现韩文。已记录到[共用语言规范](../../../design/15_统一风格与题材规范.md#游戏语言所有工作区)，对ws1战斗、新版循环及其它工作区同样适用。

## 实际修改

| 部位 | 问题/处理 | 来源与外观 |
|---|---|---|
| 背包标题 | 原图韩文标题改为“背包 / 装备”；恢复原凸起标题边框 | 仅用原标题无字纹理按1:1平铺修补字区，再画中文 |
| 背包负重 | 原图韩文“负重”字区完整清理，改为“负重” | 沿用原负重栏纹理，不叠字、不用纯色块遮盖 |
| 林纳斯招牌 | 不可读的原布面字样改成“林纳斯 / 铁匠铺” | 旗布、铁砧标记、边框与旗杆保留，原无字布纹补字区 |
| 地下城选择 | 普通难度改为中文文字层 | 原场景插画/按钮继续使用，不再上屏英文难度字图 |
| 结算 / 等级 | “通关结算/冒险结算”和“等级”中文显示 | 原S/A/B评价图与按键/HP/MP记号保留 |
| 动态文字 / 提示 | 标签、按钮、提示及物品悬停文本经过韩文拦截 | 意外韩文不会原样上屏；正式内容仍必须人工翻译，兜底不算交付 |

原IMG/PNG和字体没有修改，82原帧逐像素检查仍通过。原始库保留韩文来源用于追溯，不表示游戏画面可以保留韩文。
处理代码为[native_skin.gd](../../../../game_dnf/ui/flow/native_skin.gd)、[native_text_patch.gd](../../../../game_dnf/ui/flow/native_text_patch.gd)、[language_guard.gd](../../../../game_dnf/ui/flow/language_guard.gd)与城镇表现层；未改ws1战斗主文件。
