# V6 美术接入错位修复与验收

2026-10-14。当前主线继续 DNF-like。修复对象为已获预览认可的 V6 三段普攻与拔刀斩，使用原有资源，不重新生成美术。武侠 V1–V3 按用户要求[搁置归档](../../../tasks/art_tasks/wuxia_archive.md)，未来另作独立工程。

## 问题与修复

用户实机反馈属实：旧实装虽然通过 162 项检查，但刀光、受击、一闪与人物实际像素没有对齐。原测试多在检查节点位置、配置或解冻后的状态，未证明画出的 PNG 锚点和时钟正确。

| 根因 | 实际影响 | 本轮修复 |
|---|---|---|
| Sprite 开启 centered 又 offset=-anchor | 刀光多偏 (-320,-180)，受击多偏 (-192,-160)，地裂多偏 (-256,-96)，一闪多偏 (-480,-40) | 非居中 Sprite；右向 -anchor、左向 width-anchor.x；验证 get_rect/to_global 得到的真实 PNG 锚点 |
| 节点前冲后 actor 绘图又加 root_dx | 拔刀斩额外前移最多 104 px，可见剑与判定不重合 | 节点仅应用一次前冲，actor 原点固定为 -anchor；blade 与原画共用 root |
| 合并记录的 duration_ticks 被当作单帧 | 拔刀刀光 tick17 可能取末尾透明记录；一闪也过早跳帧 | SeqLib 按整数 duration 展开逐 tick，全部 21 clip 对照源 manifest 每个 tick 的真实 PNG |
| 所有层一起停帧、秒/tick 混算、收招 reset | 火星/地裂/一闪冻结，压暗时长不对，取消截断效果 | 动作与刀光共享 phase_t；接触效果按 60 Hz 独立推进；clear_action 只收刀光，reset 才清全池 |
| 池实例缺少 blend/固定 facing | 光层使用普通混合，转身翻转已出生效果 | 每实例按 manifest 设 normal/add，锁定出生点与方向 |
| 刀光固定 z 与旧程序形变/插值 | 不同纵深层序可能反转，落地接招或渲染插值时身体与刀光不同步 | 刀光跟 player z±1；V6 原画使用刚性镜像/纵深，在动作期间关闭节点物理插值，旧移动动画仍恢复插值 |
| 压暗在起手触发，遮全场 | 与已认可命中一闪不一致 | 真实 iai 接触时触发，仅压背景；保持 7 tick，再用 8 tick 恢复 |
| 扫掠历史用当前 root、地裂仍查旧布尔 ground | 历史刀线偏移，切到 manifest 参数后不再出地裂 | 历史刀线使用对应 tick 的实际 root，过去与当前前冲分别做舞台限位；按 ground_tick 与可见刀尖触地，在 (tip.x,ground_y+depth) 生成 |
| 接线 JSON 重复作者数据 | 与资源契约漂移 | 动作窗口/时长/前冲/混合从 manifest 读取，JSON 只保留接线与一闪设置 |

同纵深顺序为目标身体 → 后侧刀光 → 玩家 → 前侧刀光 → 接触效果/一闪。地裂使用地面层。源和运行资源的 282 张引用 PNG 与 manifest 已核对一致；不通过移动火星或改图掩盖接入问题。

## 停帧与原预览计数对齐

原预览先画接触帧，再重复 N 个 real tick，故命中比挥空恰好多 N tick、接触姿势共显示 N+1 帧。BattleFX 在 Player 前更新计数器，实装补一格调度计数，但不改变资源中的 N，也不再叠额外艺术停顿。

| 招式 | manifest N | 实际接触姿势总帧数 | 命中比挥空多 |
|---|---:|---:|---:|
| attack1 / attack2 | 3 | 4 | 3 |
| attack3 | 6 | 7 | 6 |
| quick_draw | 7 | 8 | 7 |

以上来自真实逐物理帧观察，而不是读取 last_hitstop 元数据。一次接触只登记一次停帧，hit/ground/iai 在停帧中继续播放。

## 验证结果

- Headless 固定 60 渲染步长：`COMPLETE checks=219 failures=0`。
- 真实 GL 的 30 / 120 FPS 渲染步长：各 219 项通过。物理保持 60 Hz，不能把该结果当设备可稳定达到 120 FPS 的性能保证。
- 仅复制 Git 跟踪的 `game/` 文件、无 `.godot` 缓存导入成功；同步最终脚本后，该干净副本 219 项回归通过。
- 资源侧 `tools/test_seq_v6.py` 六项通过，含完整四招、alpha/混合、源标定附近像素、边界/时长及预览恰好一次停帧。
- 新回归验证实际 PNG 锚点和刀尖，四招左右/舞台边界、左右贴墙拔刀的上一帧刀尖、完整 duration 表、效果出生朝向、层序、混合、跨取消存续、地裂坐标与压暗结束；原三波通关、技能、训练与输入回归保留。
- 最终引擎日志未出现脚本错误或引擎警告。怪物轮廓读取改为 PNG buffer 解码，消除源图 Image.load 的导出警告；依然有 Texture2D 图像回退路径。
- [14 张真实接触/后续帧](../../../screenshots/v6_alignment)与[坐标记录](../../../screenshots/v6_alignment/contacts.json)已保存，四招左右各一张、重劈和拔刀 age5 共四张、挥空地裂两张。截图不保留测试夹具的无敌闪烁。
- [6.37 秒、382 帧真实 Godot 录像](../../../previews/combat_v6_showcase.mp4)：四招与左向示例均记录一次真实命中。逐招恢复目标和站位用于对位对比；它不是连续玩家输入录像。
