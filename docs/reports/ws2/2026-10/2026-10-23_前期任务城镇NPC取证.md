# 前期任务、城镇与NPC取证记录

用户要求先拆解DNF前期设计，记录供后续实装。本轮只增加设计、只读取证工具与必要字段快照；不改玩法、任务、场景或玩家存档。

设计入口：[前期任务城镇与NPC](../../../design/30_前期任务城镇与NPC设计.md)。来源遵循[26证据分类](../../../design/26_DNF原版拆解_证据与版本.md)：当前备份文件的事实不等于用户实际运行版本的激活规则。

## 实际读取与筛选

来源是asset_store.json锁定的dnf-native-assets-v1-20261022完整库，其中pvf_config.sqlite与原内容已在既有私库共享。工具通过原读取器的只读SQLite连接访问；不执行原客户端、不启动候选服务端、不修改原文件。

- 任务：n_quest/quest.lst、epicquest.lst；Elvengard/Handonmyre/WestCost及对应common目录，最低等级1～20、all或swordman；另读取s_鬼剑士转职候选。
- NPC：原npc.lst与23个NPC定义的角色、技能、field ANI、小/大/popup肖像及名称字段；另取每位NPC前两条[dialog]作为人物口吻与教学样本，不代表完整对白或运行触发顺序。
- 城镇：艾尔文防线、赫顿玛尔、西海岸3份TWN；其MAP引用及相应(r)/(f)/jap_replace候选，实际读取29份MAP的结构/NPC字段。
- 副本：读取dungeon.lst，筛选minimum required level为1～20的40条索引记录，保留basis level以区别字段；这是调查候选，含现代/活动/定制内容，不是前期启用白名单。
- 本地化：n_string.lst与相关STR表，9/10类型的表ID/键引用相邻匹配；本备份中文STR严格CP950解码并验证原字节往返。直接文本也保留CP950候选，不全局修改原cp949解析器。

本轮结果为114份候选QST，其中71份被当前quest.lst引用、43份未索引；不能把未索引文件自动激活，也不能把已索引等同服务端已开放。

[原字段快照](2026-10-23_前期世界原包字段.json)保留源路径/SHA256/CRC、字段顺序与重复标签、9/10原值/偏移、名称/条件文本的来源键/行号、任务前置引用和缺失地图诊断。它是专项摘录，不是完整无损PVF、客户端程序源码或可直接执行的任务内容包。

## 可复现命令

```powershell
# 其它工作区先按现有锁取得完整库，已有则跳过
python tools/dnf_asset_store.py sync --full
# 只读提取，默认生成到temp/early_world_audit/evidence.json
python tools/audit_dnf_early_world.py
# 第二次独立输出可逐字节对照
python tools/audit_dnf_early_world.py --output temp/early_world_audit/repeated.json
```

默认使用既有工程外缓存，完整库位置由同步工具决定；可显式传--library。生成输出限定temp，发布的文本证据另审查复制到本目录。其它区无需访问ws2本机绝对路径或聊天缓存即可阅读文档和快照。

## 对实装最重要的发现

1. **任务链横跨目录**：1901/501/502在common目录；epicquest章节共享503/504/505等任务，不能复制成重复任务与奖励。
2. **前置与章节不同**：文件名、章节展示顺序、最低等级和实际前置应独立读取；例如112文件名含8，字段最低等级12。
3. **18级与20级转职并存**：当前索引指向18级四个单关转职候选，中文条件均为暗黑雷鸣王者；20级多步骤材料链多数起始ID未索引。只能分层研究，不能拼成一套所谓“原版任务”。
4. **城镇引用缺口**：6个通用MAP引用缺少同名文件，包含Elvengard/Gate、Gate_Hendon、Gate_West、Hendon、WestCoast、WestCoast_Magic；库中部分有(r)/(f)等候选，不能自动替代。
5. **NPC位置/装扮有变体**：凯丽/风振/诺顿等在不同MAP里的摆位和邻居不同，赛丽亚定义还引用带装扮意味的ANI名称；需要实际客户端选择证据。
6. **名字/文字不是唯一规则**：原文有旧地区/难度称呼；201的标题“辛达遗失的锤子”和目标文本提及石头并不相同，int data仍需解析。任务掉率、收益公式、特殊地图完成条件没有因此自动确认。
7. **低等级筛选不是内容准入**：商人手续费系列、宠物进化、时间之门、活动/修练副本也会落在筛选范围。应建立目标版本白名单而非整批导入。
