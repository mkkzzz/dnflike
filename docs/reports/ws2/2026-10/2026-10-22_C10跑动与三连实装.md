入口：[实机与同包慢放](../../../previews/v7_c10_run_combo/index.html)、[源规格](../../../../art/animations/players/swordsman/v7/sources/base_batch_c10/spec.json)、[候选导出](../../../../art/animations/players/swordsman/v7/exports/run_combo_c10/manifest.json)、[游戏安装包](../../../../game/assets/swordsman_v7_c10/manifest.json)。导出与安装 manifest 字节一致；离线媒体直接读取这一包，实机媒体由真实操作输入与帧缓冲录制。

本次只完成跑动及地面三连的制作与接入。行走、跳跃、防御、受击等继续使用已有资源；整个非技能基础动作任务仍未全部验收。已认可 idle 的像素、帧表、时钟和原武器资源保持不变；即时翻面与受击无透明闪烁的修复继续有效。

## 动作与绘制方法

沿用 C3 拖刀握持方向与 C5 收腿/过步方向批准，新增关键图中头、躯干、髋、双腿、手臂和衣摆同时绘制。没有分别生成腿件、固定躯干拼装或按姿势单独放大头部。

| 片段 | 实际方案 | 60Hz 采样 |
|---|---|---|
| run | 两侧接触、过步、蹬地中间姿势、完全蹬伸、腾空与落脚准备；左右完整一周期 | 36 tick，12 个完整人物源姿势 |
| run_start / stop | idle → 前倾启动 → 循环；减速 → 制动 → 站稳 → 原 idle | 9 / 10 tick |
| attack1 | 复用 C8 已生成的完整身体/手指采样，挂回统一独立武器库 | 30 tick |
| attack2 | 上一刀余势 → 双手蓄势 → 挥出中间姿势 → 向右切过 → 余势/恢复 | 32 tick |
| attack3 | 第二刀余势 → 低位蓄势 → 全身蹬伸 → 向上挑 → 高位余势 → 恢复 | 41 tick |

本轮保留 22 次内置生图的真实请求和原图；选择的新完整人物关键姿势为 20 张，其余为标尺、废稿或未选姿势。已有 C8 第二刀三张、第三刀低位一张及第一刀资源按来源引用复用。新增图数与 158 个最终采样分开登记。

每组 `generation.json` 保存真实参考路径/哈希、完整请求文件、返回文件名、尺寸、透明通道和去留原因。六人动作板因比例/物理尺度不一致或重复迈同侧腿被退回，不进入生产帧；原宽跨落脚改为较窄接触姿势。第三刀初稿肩部遮下颌，换为露出下颌的修订后再标点。

所有入用源图通过同图直立标尺 G1，并保存人工复核的头顶、下颌及握点叠图。源人物只按全身统一比例缩小；没有将蹲下姿势拉等高，也没有局部调整头部。

连续身体由完整 RGBA 图之间的 RIFE 对应场与遮挡选择生成；身体与前景手指使用同一场。没有把腿切出后分别驱动。曾尝试的轮廓距离外推产生长靴尖，已移除；蹬地与腾空间出现靴子收缩，补完整人物腾空图并调整快相位时序，最终不采用该失败中间帧。细节仍存在光流带来的衣褶/头发变化，完整自然度留给连播和试玩评审，不能由 G1 推导合格。

## 武器、时钟和过渡

身体去掉固定刀、刀柄、镡与鞘，独立武器通过实际握点、刀身投影、护手、刀尖和刀口/刀背标记绘制；前景手指压住握柄。三种武器共用身体、手指文件和时钟，物理刀长分别为 256 / 320 / 140.8 px。

第二刀中间姿势最初将主副手标反，导致刀口短暂逆向；已按实际近侧右手修正握点，并明确有效挥砍段穿过镜头平面的投影。检查覆盖三刀有效段刀口朝运动方向、跑动刀口朝下、巨剑刀尖不穿地及源采样不大于 1。三连仍为双手左挥、双手右挥、由下向上挑。

用每片段 `weapon_set=c10` 选新短柄武器，旧 idle 和其他动作继续用自己的武器源，避免新柄贴图覆盖已认可 idle。新整身帧没有拆件骨架数组；与旧帧衔接时只在兼容骨架存在时计算关节混合，避免旧/新数组长度不一致和再拆腿驱动。

动作语义、攻击持续时间、真实命中停帧/碰撞及物理保持现行契约。实际连段输入测试覆盖缓冲三连；攻击中切换武器不重置身体、根锚点或时钟。视觉停步在物理减速完成后触发，之后恢复 idle，不在释放方向键的同一帧冒充已进入停步片段。

## 尺寸与真实证据

| 项目 | 实际值与限制 |
|---|---|
| 生图请求 / 返回 | 请求 2560×1440，实际均 1672×941；生成器未满足原生 2K 源画布目标，明确保留此限制 |
| 角色制作 | 1024×1080 透明边距画布，root=(448,840)，2K 站高约 380 px；入用人物源像素足够，仅缩小 |
| 实机连续录像 | 2560×1440、60fps，三种武器 × 左右朝向，984 个连续渲染帧；没有缩放或用离线渲染替代 |
| 实机近景 | 从上述原生帧裁切 1120×880，跟随实际人物位置；不放大，裁切框逐帧入证据 |
| 1080p | 真实 1920×1080 帧缓冲保存六片段静图；角色按 0.75 显示，非事后放大/缩小伪装实机 |

连续录像采用 Godot `frame_post_draw` 无损 WebP 原帧；保存接口的布尔参数是 lossy，初次审片编码误传 true 已废弃，现明确使用 false。每个原生 RGB 帧在引擎内计算哈希，保存后逐帧解码比对，确认没有有损改写；不靠文件扩展名或容器名称判断无损。MP4 为审片编码，原帧哈希、连续渲染号、片段/时钟、武器、朝向、位置和实际身体来源保存在 [2K 证据](../../../previews/v7_c10_run_combo/gameplay_native_2k.json)；[双分辨率静图](../../../screenshots/v7_c10/)。截图与录像不含模拟命中：真实怪物命中另由功能回归验证；本段录像将怪物移远以观察完整动作。
