# 原生素材城镇循环首轮实装

## 本轮实际结果

用户要求ws1搭战斗底层，ws2开始循环，强调原版美术与细节。本轮交付独立可玩的城镇→接任务/购买→选副本→真实五房战斗→结算→回城交付→装备成长→保存/重进入口。
同一人物还能第二次出征、撤退返回；旧战斗验证场景与main.gd未修改。本轮不改用户原有game/project.godot本地差异。

```powershell
tools/run_dnf_loop.ps1
tools/run_dnf_loop.ps1 -Test -Capture
```

独立场景为[loop.tscn](../../../../game_dnf/scenes/loop.tscn)。方向键移动；林纳斯附近E交谈，右侧森林口E出征；I背包、Q任务、D出征、H药剂、F5保存、Esc菜单。
战斗保留X/Z/A/S/C/V/G操作；外部管理禁止R自行重开和Tab/数字键切换临时角色/武器，避免越过长期Profile。

## 结构和跨区边界

| 模块 | 入口 | 责任 |
|---|---|---|
| Session/Profile/Run | [session.gd](../../../../game_dnf/flow/session.gd) | 纯流程状态、命令、快照、任务/奖励/成长与存档数据 |
| 物品 | [catalog.gd](../../../../game_dnf/items/catalog.gd) | 固定语义ID、试炼装备/药剂的适配参数 |
| 存档 | [store.gd](../../../../game_dnf/save/store.gd) | 临时文件→原子替换、仅有效旧档备份、主档损坏后恢复 |
| 城镇 | [native_town.gd](../../../../game_dnf/town/native_town.gd) | 复用T2加载原地图与NPC、逐帧循环、卷轴/走动/交互 |
| 流程根 / UI | [loop_root.gd](../../../../game_dnf/flow/loop_root.gd)、[native_skin.gd](../../../../game_dnf/ui/flow/native_skin.gd) | 外层编排、原素材界面、鼠标操作与错误提示 |
| 临时战斗接入 | [legacy_combat_port.gd](../../../../game_dnf/flow/legacy_combat_port.gd) | 单独继承现版战斗，隔离旧内部字段知识；接收Run属性并输出终局事件/复制快照 |

临时桥是兼容现版的过渡层，不是29的combat/api或start_room实现。现有main内的五房切换与开门仍由旧战斗执行；ws2未把它们偷偷搬到UI，也未同时修改ws1文件。
ws1发布F0/F5后，将此桥替换为combat/api，地图/门编排再迁至ws2的world层。当前未接T2洛兰真实战斗地图，不能宣称城镇＋原地下城全部还原。
UI只通过命令、复制快照/只读属性和桥方法改变状态；装备倍率集中在桥的start_run适配，原主文件与combat.json不变。

## 原素材、规格与可共享来源

[美术任务包](../../../tasks/art_tasks/dnf_loop_native_v1.md)登记全部来源、尺寸、裁切/缩小与依赖。
构建器直接读取已共享完整库，逐个IMG校验SHA256；NPC动画来自原MAP→NPC→ANI→IMG链。原图未重绘/放大，未调用生图工具。
城镇来自艾尔文防线MAP/TIL，场景含锻炉、树屋门、路面、旗帜、林纳斯/土罐；UI用原背包、商店、边框/按钮、血蓝球、Lorien插画与Results字/评价图，字体来自原Fonts/msjh.ttf。

逻辑视口640×480，窗口1280×960整数呈现，与旧战斗独立入口区分。实际查看帧缓冲后修正：

- 原HUD底图内盘遮住球体：调整图层，真实红蓝球在原环内显示。
- TextureRect最小尺寸导致缩图越界：按原纹理尺寸加缩小变换，副本插画完整落在面板内。
- 通用窗中部透底影响文字：改用原商店无文字纹理裁切平铺，不新画纯色块。
- 通知遮挡弹窗/标题：弹窗期间隐藏通知；原按钮改深色文字保证原浅金底可读。

## 规则、存档与适配事实

原版实际生效PVF仍未确认；源配置来自备份111Script。地图偏移120/层序/视差继承T2推定，城镇走区暂为适配范围，未声称原版碰撞规则。
本轮E-ADAPT参数：初始500 HP/180 MP、300金币/3药剂；药剂40金币恢复150HP；通关150金币/120XP/药剂1；任务奖励200金币/林间太刀；每级最大HP＋25；林间太刀伤害倍率1.20、商店价240。
评价按实际受伤≤50为S、≤250为A、其余B。奖励、任务对白、物品中文名与这些平衡参数均为项目试炼配置，图标使用原图不代表恢复了原版物品全部规则。

存档默认user://native_loop_v1/profile.json，与旧版数据分离；测试写独立temp路径。
每个Run使用存档内递增序号；结算前核run_id，奖励和已结算账本一次提交。已结算界面重载不重付、过期/重复终局事件无收益。
接受任务/购买/装备/消耗/终局/回城均保存；中断战斗安全回城，无通关奖励，已消耗物品不回滚。
有效旧档才备份；损坏主档可回读备份；写入失败持续显示状态提示，不静默称已保存。
背包是v1固定语义ID堆叠，无有限格容量和静默丢弃分支。

第二次出征实测525最大HP、普攻伤害30，撤退不新增通关收益，回城再次读档保持数据。
反例覆盖未知物品/无主装备/重复出征/战斗换装拒绝、过期终局、非领主不结算、重复收益、任务重复领奖、快照不可改源、死亡/撤退、损坏备份恢复、畸形背包/结果与写入失败。
Python工具2项通过：82帧逐像素与字体SHA256核对、跨区安装/基础戳不变/本地改动保护/非法版本拒绝。
既有独立战斗回归59项仍通过，未改主入口。发布后从远端新下载循环/证据包和基础小运行包，逐文件校验，在没有本地库/消费资源的新源码目录导入并实跑同组46项通过；新目录不拷贝ws2现有assets_local。
