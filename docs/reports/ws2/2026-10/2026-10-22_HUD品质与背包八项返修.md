# HUD、品质与背包八项返修

用户认可背包格子后，要求继续处理HUD快捷格、物品品质、详情层级、血蓝悬停、关闭位置、分类页签、背包底栏及武器槽。此轮保留原图、全中文与ws1战斗接口。

## 八项修正与依据

| 项目 | 实际问题及修正 |
|---|---|
| HUD道具/技能格 | 原HUD已烘焙格框；其步距为30，与背包32不同。图标原来y555越过上边框，技能x537盖住左边。道具28×28移到(85,558)，技能28×28移到(538+30i,558)，不再另铺格子。通用按钮底板为空，真实像素核对原框未被盖住 |
| 品质 | 原STK/EQU有独立[rarity]，不等同最上级/下级的数值品级。本轮接普通白、高级蓝、稀有紫、神器粉、史诗橙的统一显示表；图标和标题共用。框形状取原Interface/Base.img第119帧28×28透明中性框，运行时染色，不重绘原图 |
| 详情页 | 原先同色正文缺少分区。改为名称/品质类型、等级职业重量、属性效果、操作/购买价格四层；原WindowCommon第230帧细线分隔，标题16、正文12、效果14，配白/紫/绿/灰区分。黑底继续用原Global九片，叠原中心增加可读性；不虚构未恢复的攻击/魔攻/耐久等词条 |
| 血蓝 | 移除常驻百分比Label。球体原来忽略鼠标，已有tooltip_text也无法正常触发；现接真实mouse_entered/exited，用原说明框显示生命值或魔法值的当前值/上限，随实际状态刷新，移出消失 |
| 关闭按钮 | 原PNG把×烘焙在宠物页签，运行时又在同处叠按钮。用相邻原奶油色纹理清理烘焙标记，独立按钮移到(268,35)的装备标题行，不与顶部页签相交，真实点击仍可关闭 |
| 分类条 | 原48px分类合计240宽，与258宽格底不齐；按钮高度也留下褐色空隙。改为4×52+50=258、统一22高，左/右与网格齐边，选中使用原pressed状态 |
| 底栏 | 旧代码混用了原货币整图和散放数字，把金币放在空栏。现用Inventory_tw原104×23/141×23底板、复活币图和原货币符号，按相同两列/两行、27px行距放名称和右对齐数值；重量独立一行。金币使用真实profile.gold，其余未实装货币显示0，不据此声称复活/商城已可用 |
| 武器槽 | 原来(177,88)位于首饰组左侧空区。原图实际武器格为(208,86,32,32)，28px图标改到(210,88)。背包只显示未穿戴数量，已装备的一件保留在武器槽；持有数量/存档结构不变，卸下的旧武器回到可见背包 |
