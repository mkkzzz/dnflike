# V7 头部比例核查与重做准入

2026-10-17。用户认为 v7 相比标准原画头偏大，要求确认、必要时重做并防止再犯。本轮结论：**当前 c2 的头部显示尺度不合格，停止将它作为试玩接入候选**；已补上真实导出门禁，并完成一张 c3“直立基准＋准备姿态”小样。全套动作尚未重做，现行 V6 不变。

## 1. 实际测量与结论边界

基准为锁定的 [standard_v1](../../../tasks/art_tasks/char_swordsman_standard_v1.md) A1 正面与三分之四原图；新补 [人工比例表](../../../../art/concepts/characters/players/swordsman/standard_v1/measurements/proportion_v1.json)。测量单位是**可见发顶到下巴的竖直包络**，除以实测直立身高，不是传统解剖头身数，也不拿蹲姿、奔跑或收腿后的外接框高度当身高。

旧导出配置固定站立等效身高 190 px，但三个源表使用的 410 / 430 / 400 px 只是手工估值，没有同尺度直立姿态证据。以下是**按现有配置得到的屏幕头部尺度**，不是“已经证明源图骨骼缩短了多少”。

| 190 px 站立尺度口径 | 原图发顶→下巴 | 使用的源站立等效身高 | 显示头高 | 相对标准 |
|---|---|---|---|---|
| 标准 A1 正面/3/4 | 各约 104 px | 681 / 686 px（实测） | 约 28.9 px | 基准 |
| c2 普攻准备帧 | 72 px | 410 px（未验证估值） | 约 33.4 px | +15.4% |
| c2 奔跑接触帧 | 87 px | 430 px（未验证估值） | 约 38.4 px | +33.0% |
| c2 跳跃恢复帧 | 71 px | 400 px（未验证估值） | 约 33.7 px | +16.7% |

测量为人工看图标点，约 ±3 源像素；报告中的局部区间**不包含未验证站立等效身高的不确定性**。本轮只抽测 3 个代表姿态，未声称把全部 24 个独立姿态都量完。缺失姿态也会让新门禁判失败，不会按 3 个样本把整包标成通过。

初测点位包含了半透明毛边且部分 x 坐标不准确，现已按可见像素修正；初测约 +19%/+36%/+23% 的 [原始对照图](../../../previews/v7_proportions_2026-10-17/measurement_comparison.png)、`audit_initial.json` 与 `report_initial.json` 保留追溯。该原始图实际传给 c3 生成器作反例，不能用新版图覆盖后再声称是原输入。最终证据见[修订对照图](../../../previews/v7_proportions_2026-10-17/measurement_comparison_refined.png)与 [report.json](../../../../art/animations/players/swordsman/v7/reviews/2026-10-17_proportions/report.json)。

## 2. 已查出的根因与不能越界的结论

- `standard_actions_pilot.py` 使用每张源图一个等比缩放系数，没有单独放大头部；因此不能把问题说成导出器把头局部拉大。
- 旧 `standing_height` 缺少同尺度直立基准，且没有检查导出头高。统一使用“190 px”不等于人物尺度已经统一，也不能用蹲姿外接框强行补身高。
- 标准旧 `measure.json` 用候选区间内最窄行猜颈部；正面选到 y=136，而下巴实际约在 y=155，旧“约 8 头身”不能拿来证明 G1 通过。新的含发包络单位和传统解剖头身数也不能互相替换。
- 源图自身的头、躯干和四肢是否全部漂移，仍需可靠归一化后逐姿态检查；不能由本表断言整套源图都必须重画，也不能只缩小整个人物就声称内部头身比已修好。

处理结论是退回**当前 c2 结果**，先重建比例基准，再区分需要重新标定和必须重绘的源姿态。已有的奔跑腿序、普攻轨迹/收势、跳跃衔接、G3 武器分层问题仍然存在。

## 3. 已落地的防复发门禁

[检查器](../../../../tools/check_actor_proportions.py)已接入[导出工具](../../../../tools/explore/standard_actions_pilot.py)，在写目录、mask 或 PNG 前执行。

1. 参考图、比例表和动作源图绑定 SHA256；换图或换标定表后旧检查不能沿用。
2. 每张新源表必须有**同尺度直立伴随姿态**，用它的发顶和脚底测站高；配置值与实测差异超限直接拒绝，不再猜 410/430/400，也不逐帧按外接框拉等高。
3. 每个独立姿态都要有发顶/下巴标点与误差；标点要落在该姿态裁切范围及可见像素上。缺标点、遮挡/强俯仰又没有单独投影参照，不能自动通过。
4. 头部尺度相对已锁定原画的初始容差为 ±8%，站高标定容差为 ±2%，具体值以比例表为准。超差停止导出，不用 prompt 写“8 头身”代替实测；通过数值仍不等于审美/身份/骨架通过。
5. 新导出按站立等效 380 px 的 2K 角色尺寸，禁止源图放大。仅针对原路径且字节哈希完全一致的旧配置保留 `--legacy-rebuild`，其输出明确为历史重建、G1 不通过，不能给新候选借用。

旧 c2 manifest 的当前状态已改为拒收并禁止新接入；原 PNG/配置不动，旧 manifest 原始字节另存 [快照](../../../../art/animations/players/swordsman/v7/reviews/2026-10-17_proportions/pilot_c2_manifest_before_rejection.json)。当前处理单见 [decision.json](../../../../art/animations/players/swordsman/v7/reviews/2026-10-17_proportions/decision.json)。

## 4. c3 第一张重置小样

使用内置 `image_gen.imagegen` 实际传入 A1 母版、A2 机位与初测反例图，生成同图两个姿态。源图 [source.png](../../../../art/animations/players/swordsman/v7/sources/proportion_reset_c3/pair_c1/source.png)，完整提示词/真实输入与哈希见 [generation.json](../../../../art/animations/players/swordsman/v7/sources/proportion_reset_c3/pair_c1/generation.json)。模型版本与 seed 未暴露。

实际源图 1774×887、RGBA、alpha 0~255；虽然小于 prompt 请求画布，直立人物实测高 855 px，可向下导出 380 px，不依赖放大。与背景整房原生 2K 画布问题是不同用途，不能混算。

| 380 px 站立尺度 | 含发头部高度 | 相对标准约 57.8 px |
|---|---|---|
| c3 直立基准 | 约 57.3 px | -0.8% |
| c3 持刀准备 | 约 60.0 px | +3.8% |

两个姿态头部尺度均通过当前门禁。[标点与比例报告](../../../../art/animations/players/swordsman/v7/sources/proportion_reset_c3/pair_c1/proportion_report.json)不代表完整 G1 通过。

实际导出入口：[manifest.json](../../../../art/animations/players/swordsman/v7/exports/proportion_reset_c3_pair_c1/manifest.json)；[技术记录](../../../../art/animations/players/swordsman/v7/exports/proportion_reset_c3_pair_c1/validation.json)。处理只有裁切、24 alpha 核心连通主体、padding=0、等比 380/855 缩小和 root 对齐。含发顶/下巴的 4 个保护点均保留，RGBA 与画布透明边检查通过。

首次直接裁切因低 alpha 边缘噪点触边而停止；带 3/1 px padding 的隔离又触及其它 alpha 核心而停止。最终采用 0 padding，丢弃核心外低 alpha 边毛，保留所选主体原像素；没有用程序缩头、拉腿或合成新姿态。过程如实记入生成记录。

看[同尺度 c3 对照](../../../previews/v7_proportions_2026-10-17/c3_reference_compare.png)。对照直接读取实际导出包，不另交一套没有导出的漂亮图。它只有两个静态姿态，**不是完成了普攻、奔跑和跳跃重做**。中立姿态仍留了入鞘刀柄，和 prompt 要求的空鞘有差别；人物身份、四肢细节、完整动作与 G2/G3/G4 均未获批准，未实装。

## 6. 继续顺序

先由用户看 c3 基准的头、躯干、腿长与成熟感；认可后再沿同一尺度做少量动作关键姿态。全部姿态标点检查通过后看裸动作和完整腿序，再做武器分层与试玩。不得把这张静态比例小样直接升级为全套动作认可。
