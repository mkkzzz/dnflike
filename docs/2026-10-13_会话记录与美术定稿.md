# 项目会话记录 2026-10-13

## 一、项目定位

- 项目名称（暂定）：dnf 怀旧风横版动作 RPG（单机）
- 开发根目录：`d:/custom/dnf`（本仓库根目录）
- 协作方式：git 双机同步。所有工作内容必须落盘到本工作区并经 git 提交，用户在两台电脑间切换工作。
- 核心诉求：还原怀旧横版动作网游的**手感、系统与氛围**；美术与音频全部原创。

## 二、边界（重要）

- **不使用、不解包、不还原任何版权素材**（角色/怪物/场景/UI/音频/BGM 均原创）。
- **不搭私服、不碰泄露服务端**，与传播无关，一律不做。
- 游戏机制本身可以高度还原：帧数据驱动手感、搓招、浮空连段、房间式地下城、疲劳值、翻牌、强化碎裂、装备品级等。

## 三、美术标杆（已定稿，用户认可）

- 风格：韩式横版动作网游手绘风，清晰的深色描边 + 赛璐璐上色 + 柔和渐变，**高清位图质感，仅保留很微弱的像素感**（2 像素块，轻度色阶量化，40 阶/通道）。
- 主角定稿造型（用户选"更酷"版，`art/characters/hero_cool.png` 为基准）：
  - 银白刺发带一缕红挑染，左眼角刀疤，红瞳
  - 黑色皮革长风衣，血红内衬，银扣
  - 左臂缠红绷带，冒暗红火焰
  - 武器：黑柄长刀（原"白衬衫深蓝外套"版为旧方案，已弃用）
- 哥布林（`art/characters/goblin.png`）：尖耳、黄眼、獠牙、钉刺木棒。
- 场景基调：哥特暗色地下城（`art/environments/dungeon_hall.png`）。

## 四、动作管线（已验证，用户认可）

1. AI 一次生成一个动作的整张帧图（同图内角色一致性最好）。
2. 脚本 `tools/make_anim.py`：绿幕抠图 → 连通域切帧（测地线生长归属剑光）→ 脚底对齐 → 微弱像素化 → 按节奏合成 GIF / 输出透明帧条。
3. 帧率优化（用户提出，待实施，三种手段组合）：
   - 大动作拆成多张帧图补到 10-12 帧；
   - 小幅动作程序插帧；
   - 程序刀光/残影盖住跳帧。

## 五、已验证的技术验证（旧程序渲染器）

- `tools/render_preview.py`：640x360 世界 + 骨骼动画 + 命中停顿/震屏/浮空/弹地/受身 + 分段血条 HUD 的实机风格预览（产物在 `temp/preview/`）。
- 该渲染器为手感验证工具，正式工程的技术路线另行对齐。
