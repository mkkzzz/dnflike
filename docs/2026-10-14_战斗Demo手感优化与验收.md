# 2026-10-14 战斗 Demo 手感优化与验收

> 范围：实机 `game/`。上一轮 V6 错位修复完成后，按试玩反馈落实五项小优化，全部以 JSON 配置 + 运行时逻辑完成，不重烘任何美术资源。

## 1. 五项优化与改动位置

| # | 反馈 | 改动 |
|---|---|---|
| 1 | 跑步时剑与角色穿模 | `game/scripts/weapon_rig.gd`：`socket_pose()` 对 `run` clip（weapon_separated）把武器改为 **155° + front 层**。原 145° back 层让刀身被大衣盖住、在握点与刀尖之间像刺穿衣摆；现在整把剑前置在衣摆上方，逐帧握点全部保留。 |
| 2 | 上下移动应有走路动画 | `game/scripts/player.gd`：`_free_state()` 的移动判定与步态累计改用 `Vector2(velocity.x, _lane_velocity)`；`_anim_step()` 的步态速度同样按二维速度取模。只按 ↑/↓ 也会进入 WALK 并推进 walk 帧。 |
| 3 | 上下移动速度再快一点 | `game/data/player.json`：`lane_speed` 100 → **140** px/s。 |
| 4 | 一次跳跃只能攻击一次 | `game/data/player.json`：`air_attacks_per_jump` 2 → **1**；`player.gd` 新增 `air_attack_limit()`：默认 1 次，技能 buff 的 `extra_air_attacks` 可加次数（负数/失效数据被防护）。超出次数的攻击按下即丢弃，不会滞留到落地变成地面斩；落地即恢复。 |
| 5 | 攻击衔接后跳不流畅 | `game/data/moves.json` / `skills.json`：三段普攻、怒斩、拔刀新增 `back_dash_cancel_after`（命中）/`whiff_back_dash_cancel_after`（挥空），比原防守取消窗口明显提前（如一段 26→18 挥空）。`player.json` 新增 `back_dash_buffer_frames: 28`。`player.gd`：↓+C 在按下时就解析为后跳请求并给独立缓冲；慢攻速下缓冲延长到首个合法窗口，命中停帧期间时钟不扣缓冲，收招直接进入后跳。 |

## 2. 验收

- **回归**：`tools/run_demo.ps1 -Test`（headless、固定 60 Hz）**265 项全通过，failures=0**（上轮 219 项，本轮新增 46 项移动手感检查）。
- 新增检查覆盖：↑/↓ 单独推进多张 walk 姿势且不横向漂移、64 px 全程 ≤33 tick（旧 100 px/s 约需 40 tick）、边界停步、对角移动与停止；重复攻击边沿只出一发空斩、落地恢复、多余输入不泄成地面斩、二次起跳可再斩、技能加成 +1 / 失效 / 负值防护、空中血怒后不再多送空斩；四招（三段+拔刀）命中与挥空都在首个合法窗口进入后跳、0.5x 慢攻速与真实停帧下 ↓+C 保留并直入后跳、普通 C 跳保持短缓冲不被误判为后跳、上挑命中后 C 仍可追击。
- **跑步持剑**：`temp/weapon_run_probe.gd` 对 8 帧 × 左右朝向渲染，before（145° back）/ after（155° front）像素对照：左右两侧各数千像素由“大衣暗色”变为“刀身亮钢色”，即刀身从衣摆内翻到衣前；改动后逐帧握点、刀尖位置由探针输出核对。
- 旧回归全部保留：三连、上挑浮空追击、停帧、技能多段、后跳无敌与冷却、三波通关、V6 逐 tick 对位等。

## 3. 边界与待办

- 空斩次数加成是通用机制（`extra_air_attacks` buff 字段），当前实装技能（血怒/怒斩/拔刀/连突刺）都没有开启它；默认就是每跳一次，将来给技能配该字段即可生效。
- 后跳取消窗口只对反馈涉及的四招配了专属值；上挑、冲斩等仍沿用防守取消窗口。
- 手感最终结论仍以用户实机试玩为准；自动回归只验证功能与数值契约。
