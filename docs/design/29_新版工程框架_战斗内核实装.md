# 新版工程框架：战斗内核实装（F3~F5）

> 上级入口：[新版工程框架](29_新版工程框架.md)。规格见[战斗内核](29_新版工程框架_战斗内核.md)、[接口契约](29_新版工程框架_接口契约.md)，原版数据来源见[内容编译](29_新版工程框架_内容编译.md)。
> 2026-10-22 ws1 实装。用户定：技能只做现有几个，连突刺改三段斩，不分剑魂/狂战士，数值按 1 级，后续数值系统覆盖。

## 一、规则来源三分

| 来源 | 内容 | 位置 |
|---|---|---|
| 原版（E-PARSE） | ANI 帧时长/攻击盒/受击盒/帧音效；ATK 伤害加成、受击反应、击退、浮空、方向、命中特效与命中音；SKL [dungeon] 蓝耗/冷却/施放时间/等级表；CHR 初始 HP/MP、跳跃力、受击恢复、武器音与命中信息；MOB 能力百分比、移速、视野、攻击间隔、受击恢复、动作、投掷；OBJ/PTL 飞出物动作/攻击信息/速度/寿命 | `assets_local/content/combat_content.json`（编译器生成） |
| 适配（E-ADAPT） | 每个试玩招式链接到哪个原版文件（引擎代码里的关联）；单位换算；缺失的基础表（攻击力、怪物基础 HP/攻击、领主倍率）；停帧时长；无盒招式的判定来源 | `game_dnf/data/combat.json`（v2，只能填原版没有的值） |
| 表现资源 | 怪物身体/动作包、飞出物、技能与命中特效、位图数字、音效键→文件 | `assets_local/combat/`（`tools/build_dnf_combat_assets.py` 生成） |

运行时由 `combat/data/move_table.gd` 合成三者；`combat/fields/handled.json` 登记哪些原版字段已真正执行，覆盖报告据此统计。

## 二、内核模块

| 文件 | 职责 |
|---|---|
| `combat/action/timeline.gd` | ANI 时间线：按时刻取帧、连续带盒帧分为命中组（同组同目标只命中一次）、最晚判定时刻=可取消点 |
| `combat/hit/hit_judge.gd` | 攻击盒与受击盒三轴相交（经 `core/box6.gd` 镜像），返回交叠中心作为命中点 |
| `combat/resolve/reaction.gd` | 按 ATK 受击反应：[damage] 硬直 / [down] 击倒或击飞 / [none] 只扣血；击退滑动、重力、落地弹起、倒地与起身；伤害=攻击力×百分比 |
| `combat/ai/monster_ai.gd` | 视野内接近到自身攻击盒射程并对齐纵深后出手；投掷型保持距离、同纵深投掷 |
| `combat/data/move_table.gd` | 运行时招式/怪物/飞出物表 |
| `combat/api/kernel.gd` | 对外入口（过渡期战斗场景 `scripts/main.gd` 只经此使用内核） |

## 五、表现变化（你试玩时会看到的）

- 出招节奏、可取消时机、判定范围全部按原版帧与盒：例如普攻 1 段要到 150ms 才有判定，打不到攻击盒外的目标。
- 被打的怪按 ATK：普攻 1/2 段是硬直并被推开；普攻 3 段、跳斩、上挑会击飞，落地进入原版倒地帧，再播起身帧。
- 停帧只冻结出手方与被打方，房间其它怪物照常行动。
- 命中特效按砍/钝击、大小、出血选原版特效；命中音用武器/ATK 指定的原版音。
- 伤害数字、连击数换成原版位图数字（白=造成伤害，红=受到伤害）。
- 删除了两处自制表现：暴走时角色整体染红、每次命中的震屏。
- 怪物换成原版洛兰哥布林外观（持棒），领主房为哥布林投掷手，会扔石头。

## 五之二、2026-10-23 试玩返修

| 用户反馈 | 原因 | 处理 |
|---|---|---|
| 怪物偶尔往下掉 | 被击飞时用原版 overturn.ani，该帧带 [ROTATE] π（倒转姿势），视图没执行旋转，图像落到地面以下 | 角色/特效视图执行 ANI 旋转（弧度，镜像时反向）与插值 |
| 上挑动作/特效/音效不对 | 用了 upperslashafter.ani，它与裂波斩试斩共用 199~203 姿势 | 换成 hitback.ani（51~59）+ upperslash1/2 + UPPER_SLASH_01 |
| 跳斩不能移动 | 招式期间不处理方向键 | 空中招式保留跳跃时的移动 |
| 按方向键+X 就出突刺 | 奔跑判定按两次"按下"计时，且招式后奔跑状态不清 | 双击改为"松开后再按"；只有奔跑中的 X 才出冲刺攻击 |
| 三段斩没有位移、不能分段转向 | 速度按角色移速单位误换算成 74px/s | 按 SKL static_data 平滑减速滑行；每段起始读左右键 |
| 缺后跳 | 只有 V 键且用错了动作 | ↓+C 后跳、可打断普攻并留虚影 |
| 十字斩特效残留 | 新月飞出物错误偏移 (70,0,60)；斩痕比招式多留 170ms | 新月放回施放者锚点；招式特效带标签，招式结束/被打断即清除 |
| 第一张图不对 | 旧场景是手拼的格兰之森裁切图 | 五房换成原版洛兰地图 |
| 血条在怪物身上 | 程序画矩形 | 屏幕上方原版 monster_hp.img 血条，小怪/精英左对齐、领主居中，头像+名字+等级 |
