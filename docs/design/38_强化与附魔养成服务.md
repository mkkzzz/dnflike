# 强化与附魔养成服务

承接[32数值](32_数值与等级系统.md)、[35物品所有权](35_物品背包与掉落拾取.md)和[37回城服务](37_回城交易分解与耐久服务.md)。用户授权先补基础功能，循环与平衡后定。本页所有成功率、成本、强化增量、附魔方案及辛达附魔入口均为 **E-ADAPT**，不声称恢复原版经济或附魔师职业。

## 玩家入口

- 赫顿主街凯丽：交谈→强化。后街辛达：交谈→附魔；原任务、整备和物品服务入口保留。
- 单击右侧背包或左侧穿戴装备，按实例编号选择目标。只处理随身或穿戴装备；锁定、仓库、待领取区、回购区与损坏装备拒绝养成。
- 主窗口和二次确认显示目标编号、当前/目标强化等级、成功率、失败等级、金币、各材料需求/可用量，以及装备自身属性的前后变化。它不是角色最终面板，体力等衍生属性仍由数值模块计算。
- 取消不扣材料、不扣金币、不推进随机状态。确认成功写盘后才更新活跃角色及界面，失败保留原确认框供重试。

## 强化

每次只尝试增加一级。逐级成本、成功率、失败后等级与上限由[upgrades.json](../../game_dnf/data/upgrades.json)的 `reinforcement.steps` 决定；列表下标对应当前等级，长度对应服务上限。

当前默认失败保留等级；配置支持回退到更低等级，不能用失败配置获得更高等级或删除装备。不加入碎装、保护券或自动连点。随机失败属于一次已完成的付费尝试，显示明确失败提示并扣除完整费用；金币/材料不足、权限失败、过期确认和保存失败属于未提交操作，全部保留。

武器沿用 `numbers.json` 的 `formula.reinforce_attack_per_level`，提高基础物攻/魔攻；其它部位增量由 `reinforcement.bonuses` 按部位/属性配置。当前上衣提高物防，项链提高魔防；未配置部位不收费。零耐久或不满足穿戴条件时，强化与装备其它加成一起失效。

降低配置上限不会改写已有更高强化装备；旧实例仍按保存等级计算，仅阻止继续通过NPC提升。装备数据层原有调试范围不变。

## 附魔

- `enchants` 定义稳定方案ID、显示名、允许部位、金币、材料及属性修正。当前使用力量、智力、体力三种功能方案，统一复用铁质碎片，不制作新卡片或伪造原版物品。
- 正式附魔必定成功；一次替换目标的全部旧附魔，预览同时展示旧属性移除与新属性加入。相同附魔不重复收费，不累积残留属性。
- 清除附魔需单独确认，当前免费，不退还历史材料。没有附魔不能重复清除。
- 原GM的直接强化/附魔命令保留为调试工具，与NPC付费服务分开；不作为玩家普通按钮。

## 所有权、材料与事务

物品所有权不移动，装备UID、品质、耐久和锁定字段不重抽。材料通过 `Inventory.stock/consume` 按实际背包堆叠消耗；锁定、仓库与待领取区不算可用。一个账单可跨多个堆叠，先预检全部材料，任一不足则不处理。

纯入口为 `Services.quote/command`，操作名是 `services.reinforce`、`services.enchant`、`services.enchant_clear`；附魔载荷用recipe选择配置，不能通过载荷自带属性或价格。Session检查城镇/邻近与NPC角色，外层 `service_action` 写完整候选后才替换Session。

确认指纹绑定完整报价和目标实体，强化额外绑定当时随机状态。目标、规则或随机序列变化后拒绝旧确认；事务编号通过既有 `services.transactions` 跨存档去重。

`services.upgrades` 保存seed与attempts。新角色生成独立初始seed，强化采用固定递推；每次已提交尝试恰好推进一次。候选写盘失败时活跃seed不变，同次重试不会重抽。这是本地存档一致性规则，不提供防存档篡改或回退保护。

养成字段为格式4时代的向后兼容扩展，当前格式与恢复策略见[39](39_消耗品冷却与死亡恢复.md)；旧档无该字段时读档补齐，已有字段先校验再使用。不覆盖旧目录；不合法seed/次数或畸形对象拒绝读取。

## 配置与验证

调参后重启游戏。启动[检查器](../../tools/check_dnf_upgrades.py)验证逐级费用、合法材料、概率范围、失败等级、强化上限、部位与附魔属性。非法配置阻止正式入口启动。

```powershell
tools/run_dnf_loop.ps1
tools/run_dnf_loop.ps1 -Test -UpgradesOnly -Capture
python tools/check_dnf_upgrades.py
python tools/test_dnf_upgrades_config.py
```

窗口复用现有原皮肤、字体、按钮和物品图标；沿用flow v13/items v2锁，没有新增贴图或音效。实机检查、证据与交付边界见[本轮记录](../reports/ws2/2026-10/2026-10-23_强化附魔养成服务实装.md)，权威进度见[看板](../project/01_进度看板.md)。
