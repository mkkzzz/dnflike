# 音效生产工作流：变调、人声与技能分层

本文承接[主工作流](19_音效生产工作流.md)第三节，保留原3.5～3.7节的技术经验与实现记录。

### 3.5 派生变体：既要"更高"又要"更长"

需求形如"比 X 高 N 度、比 X 长 M 倍"时，不要用重采样硬做——**重采样升调必缩时**
（×4 升调会把 0.43 s 压到 0.11 s，绝对达不到"更长"）。做法（已固化为
`tools/bake_goblin_death.py`）：

1. **先算两个倍数**：音高倍数 `r = 2^(半音/12)`，时长倍数 `m`
2. **相位声码器拉伸 `S = m × r` 倍**（保音高、只拉时长）
3. **再重采样 `r` 倍**（音高 ×r，时长 ÷r）
4. 净效果：时长 = 原 ×m，音高 = 原 ×r；两者互不干扰

两个实测要点：

- **拉伸要拆成多次小比例**：一次拉 8 倍时合成跳距会超过窗长，帧与帧之间出空档。
  `--semitones 24 --duration-scale 2` 对应 S=8，拆成 3 次 ×2（`stretch()` 里 `passes=3`）
- **补零必须裁掉**：声码器两端补 `n_fft` 个零，直接输出会把补零一起拉伸，
  结果时长虚长约 20%（实测 2.42 倍而非 2.0）。裁剪区间按
  `[n_fft×factor, (n_fft+len)×factor]` 映射回真实信号

**验收看两个客观量**：时长比（应精确等于 m）与**主峰频率比**（应接近 r）；
频谱质心比通常低于 r，且升得越高差得越多（声码器会抹平高频，×8 时能量已推到
接近奈奎斯特，实测质心比只有 5.3~5.9），所以**不要用质心当音高判据**。

实例：哥布林死亡声 = `goblin_hurt` +36 半音（真八度 ×8）、×2 时长 →
0.68~0.85 s、主峰 ×6.3~8.0、峰值 0.72。先按 +24（工程口径的"3 个八度"）做过一版，
负责人试听后觉得不够高，改为真八度 +36 —— **口径拿不准时先问，别默认**。

### 3.6 变调救不了音色：什么时候必须换路线

**变调只改音高，改不了发声方式。** 实测教训：哥布林死亡声先做了两版"受击声变调 + 拉长"，
音高一路加到真八度 ×8，负责人听感仍是"同一只小怪物被掐"，要的是**「啊~~」嘶哑尖锐的临死嘶吼**
——这是**发声类型**问题，只能重做音源。

判据（拿来判断该不该换路线）：

| 需求里的词 | 变调/拉伸能解决吗 |
|---|---|
| 更高/更低、更长/更短、更响 | ✅ 能（3.5 节的手法） |
| **嘶哑 / 尖锐 / 破音 / 嚎叫 / 叹气 / 像人声** | ❌ 不能，必须换**音源**：路线 B 找真实录音，或路线 A 合成 |

**路线 A 合成人声的最小配方**（已固化为 `tools/bake_goblin_death_scream.py`）：

1. **激励**：锯齿/脉冲串 + 周期抖动（jitter）+ **次谐波**（比基频低八度的分音）
   —— 抖动与次谐波是"嘶哑"的来源，正弦做不出来
2. **元音**：「啊」用四个共振峰 F1~F4 做频域加权；小体型生物整体上移
   （本项目用 900 / 1520 / 2760 / 3800 Hz）。**没有共振峰就只是蜂鸣，不像人**
3. **尖锐**：叠一层"提亮过"的宽带噪声（一阶差分后的白噪声），并让它也过同一组共振峰
4. **破音**：幅度抖动 + `tanh` 过载；纯加法合成永远"太干净"
5. **形态**：快起音（~35ms）+ 长持续 + 自然衰减 + 基频下滑（660→395 Hz），
   下滑才是「啊~~」的叹气感

客观对照（受击 → 合成嘶吼）：**质心 1073→2134 Hz**（更尖锐）、
**20 ms 包络抖动 0.29→0.44**（更哑）。这两个量可以作为"有没有做到"的代理指标，
但**像不像人声只能人耳判断**。

### 3.7 技能配音要分两层：出招 与 命中

**踩过的坑**：出招声早就按技能分了（`rage` / `draw_strike` / `rage_strike` / `thrust`），
但**命中声是通用的** —— `battle_fx._impact_sound()` 只对普攻三分支特化，
其余全部落到 `light` / `heavy` / `launch` / `metal_hit`。结果是四个技能打在同一只
怪身上听感完全一样，"每个技能有自己的声音"只做了一半。

分工约定：

| 层 | 归属 | 配置位置 |
|---|---|---|
| **出招人声**（windup） | 短促的"用力"，先于招式音 | `battle_fx.VOICE_EFFORT`，由 `player` 在 windup 调用 |
| 出招（active） | 每个技能各自的挥砍/施法音 | `battle_fx.gd` 的 `match move_id` 分支 |
| 命中 | 每个技能各自的撞击音 | `battle_fx.gd` 的 `SKILL_IMPACT` 映射 |
| 怪物受到伤害 | 生物叫声（与上面几层叠放，不得替换） | `on_hit()` 里的 `goblin_hurt` |

**起手人声**：招式起手先出一声短促的"用力"（`battle_fx.VOICE_EFFORT` 四档，
由 `player` 在 windup 调用）。**必须是真实录音** —— 先做过一版共振峰合成的人声，
负责人实机反馈"不像人"，最终改用 CC0 素材《Male Grunt/Yelling sounds》
（HaelDB，62 段男声切片）加工，见 3.8 节与 `audio/effort_voice/`。

**落点要注意**：V6 招式（三段普攻、拔刀斩）在 `attack_event()` 里
`if seq6: return` 之前就返回了，所以**任何"起手层"都不能**挂在 `battle_fx` 的
`phase == "start"` 分支里，否则 V6 招式永远没声音。要么挂 `player` 的
windup 触发点，要么像挥砍声那样走 `seq_swing_sound()`。

**音色要靠质心排开**（否则四个技能还是一个味）：本项目实测排布是
怒斩 **1780 Hz**（最沉，低频占比 0.37）< 连突刺 **2864** < 上挑 **4247** < 拔刀斩 **5350**（最锐）。
先量现有命中声的质心（`light` 1220 / `heavy` 2736 / `thrust` 3639）当基准，
新做的一旦跑到 10 kHz 以上就会变成"嘶声"而不是"打中"——这时要**降高频增益**
并把低通**级联三次**（一阶只有 6 dB/oct，单次压不住）。

打金属目标时在技能命中声之上再叠一记 `metal_hit`，保留材质信息；血肉目标不叠，
免得糊掉技能的身份。
