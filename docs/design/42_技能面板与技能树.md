## 一、面板身份

技能树来源为原版 `SkillShopWindow` 归档；用户要求运行时呈现大弹窗，并露出下方真实快捷栏：

- 原 UI 控件 10 引用 800×600 `Skillshop.img` frame 14；运行时仅裁取原像素布纹，配合既有原版窗框构成位于 `(14,12)` 的 772×490 弹窗，不使用无已证实窗口引用的 frame 140。
- 源 `SkillShopSpPage` 为 580×400；弹窗视口适配为 540×342，源节点坐标不重排，只加 `(24,8)` 内边距防裁切。
- 源说明板为 199×438；弹窗内适配为 199×402，用 `WindowCommon.img` frames 213–221 九宫格，顶边保持 13 像素、底边 12 像素。
- 标题、图框、分隔条与正文起点使用 `SkillShopExplain` 明确引用；原正文 179×260、起点 `(9,176)`，弹窗正文高 214 并可滚动。
- 节点图标与详情图标都保留 SKL `[icon]` 的 28×28 原像素；只读节点用运行时暗色区分，不覆盖未证实用途的锁定图。

当前角色对应一个 SP 树分支。鬼剑士基础分支显示 17 个节点；转职后切换为剑魂、鬼泣、狂战士或阿修罗的完整源布局。

## 二、源数据

原版树 `clientonly/skilltree/swordman_sp.co` SHA256 为：

```text
1a9a1e320e2c9b1d6cc6933495a66a872bdc744737b72bf44366fc0a2e0b098e
```

每个 `[skill info]` 读取：

| 字段 | 用途 |
|---|---|
| `[index]` | SKL ID |
| `[icon pos]` | 原始 x/y 坐标 |
| `[next skill]` | 原版树显式后继 |
| SKL `[pre required skill]` | 前置 ID 与等级 |

实测坐标网格为：

```text
x: 0, 47, 94, 141, 188, 235, 282, 329, 376, 423, 470
y: 0, 67, 134, 201, 268, 335, 402, 469, 536, 603, 670
```

`skill_catalog.json` schema 3 保存 `trees.sp` 与 `trees.tp`。SP 分支节点数：

| 源分支 | 职业 | 节点 | 去重后前后置边 |
|---|---|---:|---:|
| `none` | 鬼剑士 | 17 | 0 |
| `weaponmaster` | 剑魂 | 34 | 4 |
| `soulbringer` | 鬼泣 | 33 | 9 |
| `berserker` | 狂战士 | 29 | 4 |
| `asura` | 阿修罗 | 33 | 8 |

边由 `[next skill]` 与 SKL 前置合并去重。例：

- 剑魂：格挡→自动格挡、三段斩/破军升龙击→流心：狂、拔刀斩→幻影剑舞。
- 狂战士：血之狂暴→血气爆发、血气爆发→嗜魂封魔斩/怒气爆发、怒气爆发→血魔弑天。
- 鬼泣：刀魂之卡赞→侵蚀之普戾蒙→冰霜之萨亚/鬼影步，瘟疫之罗刹→冥炎之卡洛→第7鬼神。
- 阿修罗：波动刻印→挫折意志→不动明王阵，杀意波动→无双波/邪光波动阵/暗天波动眼。

`swordman_tp.co` 当前源文件只有空的 `[swordman] none` 分支，因此 TP 数据保存为空结构，不用 SP 节点伪造 TP 树。

## 三、技能名称与学习

`tools/build_dnf_skill_panel.py` 从 `skill/swordmanskill.lst` 枚举 175 个 SKL，名称和说明优先经 `n_string.lst` 解析到 `skill/skill.kor.str`，保留表名、键、行号或直接文本来源。

学习事务为 `numbers.skill`，校验顺序：

1. 技能存在、未满级且有运行定义。
2. 当前职业列上限允许。
3. 角色等级满足 `required_level + 当前等级 × required_level_range`。
4. SKL 前置技能等级满足。
5. SP 足够。

18 级简化转职入口保留在技能页底部；正式转职任务、剧情和技能点重置任务尚未接入。调试 `force` 只绕过等级、职业和前置，不绕过技能上限与 SP。

## 四、运行定义

`tools/build_dnf_skill_runtime.py` 从 `skill_catalog.json` 与编译后的原版内容包生成
`game_dnf/data/skill_runtime.json`。该目录覆盖 175 条剑士 SKL：74 条主动、101 条被动；
五棵 SP 树合计 78 个唯一节点全部有 `local_id`、学习定义和效果入口。

树内主动节点共 52 个，均生成招式阶段或有明确 Buff / 持续效果；树内被动节点共 26 个，
分别生成属性修改、技能等级加成、派生解锁或战斗事件规则。EX 主动技能复用其基础技能
阶段，通用技能标记为工具或持续效果，不再作为只读占位。

| 类别 | 节点 |
|---|---|
| 鬼剑士主动 | 上挑、鬼斩、三段斩、十字斩、月光斩、格挡 |
| 剑魂主动 | 拔刀斩、破军升龙击 |
| 狂战士主动 | 血之狂暴 |
| 被动 | 光剑精通、光剑掌握、短剑精通、太刀精通、巨剑精通、钝器精通、武器奥义、血气旺盛、甲精通、动态低血/出血/暴击被动 |

运行定义保留来源档案中的 SKL `level_info`、MP、冷却、前置与职业列；招式阶段引用
原版 ANI/ATK/OBJ/PTL 或由技能目录明确标记的适配规则。纯视觉特效与状态效果分开存放，
不会再把特效 IMAGE/ANI 误写入临时效果表。

## 五、技能栏与交互

- 下排 A/S/D/F/G/H 保留存档下标 0–5，上排 Q/W/E/R/T/Y 为下标 6–11；旧六格存档追加六个空槽，不搬动原绑定。统一入口为 `game_dnf/stats/api/skill_slots.gd`。
- 树节点点击切换右侧说明；已学习且可入槽的主动技能直接拖入下方真实 HUD，弹窗中没有另一套快捷键设置区。
- 两排槽支持空槽移动、占用互换、跨排移动、去重及存档；未学习或无入槽码的节点不得绑定。
- 鼠标滚轮与右侧滚动条共同移动树视口；内容高度仍按最大 y=670 加节点底边计算。
- 任务窗快捷键改为 J；Q 只承担上排技能键。E 的门口辅助确认迁到 Enter，避免技能施放触发换房；R 在战斗中施放技能，重开与结算统一由正式流程处理。
- 选中节点使用原版蓝色 38×38 框，前置边高亮；不可用节点仍可查看说明。
- 退点和重置只处理真实购买记录，不删除任务赠送等级。
- 技能窗顶部只保留标题与关闭按钮，不显示属性/技能/装备页签。加退点使用原Skillshop帧59～64（18×18）；旧22/23实为重置箭头。Explain4000/4001为变更/锁定，当前加退点位置明确属于适配。
- 统一字体按2倍画布密度采样并缓存，保留原字号与原素材像素；实际渲染与原档案校对见[本轮记录](../reports/ws2/2026-11/2026-11-06_技能窗原版校对与文字清晰度.md)。
