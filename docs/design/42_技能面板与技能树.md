# 技能面板与技能树

> 面板数据来自原版 SKL，素材来自原版 `Interface2/UI/SkillShop/Skillshop.img` 与各技能自带图标。
> 代码：`game_dnf/ui/flow/skill_panel.gd`；数据：`game_dnf/data/skill_catalog.json`；素材：`tools/build_dnf_skill_panel.py`。

## 一、范围

- 列出**原版全部 175 条剑士技能**（主动 / 被动 / 通用 / 强化 四类页签）；未接入战斗的标灰只读。
- 已接入战斗并可加点的 7 个：上挑、拔刀斩、三段斩、十字斩、暴走、格挡、力量精通。
- 加点、退点、重置走 `numbers.skill` / `numbers.skill_reset` 事务；技能栏 6 槽支持从面板拖入（仅 `draw/triple/rage_slash/buff/guard`，且必须已学会）。
- 简化转职：18 级二选一（剑魂 / 狂战士），只切 `growtype` 与技能可用性，不含任务与剧情。

`tools/build_dnf_skill_panel.py` 生成 `assets_local/skill_panel/`（图标 + 零件 + manifest）与 `data/skill_catalog.json`。资源已随仓库入库（2026-10-28 起），同步后直接可用；只有需要重建时才跑该工具。

## 三、名称与要求

- **名称**：原版 `name_ref` 只解到 `name_17730` 这类占位键，本地化文本不在备份库内；中文名按 SKL 文件名语义整理（E-ADAPT），`*ex/*exp` 规则化为“本体·强化”，未识别的显示“未开放技能 &lt;编号&gt;”，待使用者校对（`tools/build_dnf_skill_panel.py` 的 `NAMES`）。
- **要求**：等级 `required_level + rank × required_level_range`、职业 `growtype_max_level`（0 表示该职业不可学）、前置 `pre_required_skill`，均按原版记录校验，开关为 `progression.enforce_skill_requirements`。
- 当前角色为未转职鬼剑士：拔刀斩（35 级 / 剑魂）、暴走（17 级 / 狂战士）在正式规则下不可加点；面板“调试·无视限制”开关可带 `force` 绕过，仍受技能上限与 SP 约束。

## 四、界面布局（800×600）

暗化层铺满 → 780 宽窗口 → 标题条“技能” → 四类页签 → 左侧 9 行技能列表（图标 / 名称 / 等级 / 锁定原因 / SP + 快捷加号）→ 右侧说明（图标、类型、原版编号、等级、SP、MP/CD/伤害%、等级与职业要求、前置、状态）→ 底部加点 / 退点 / 重置 / 调试开关 / 转职按钮。
