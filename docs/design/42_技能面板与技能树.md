# 技能面板与技能树

> 面板零件来自原版 `Interface2/UI/SkillShop/Skillshop.img`，技能名、说明、要求和等级行来自剑士 SKL。
> 代码：`game_dnf/ui/flow/skill_panel.gd`、`game_dnf/stats/skill_book.gd`、`game_dnf/scripts/main.gd`
> 数据：`game_dnf/data/skill_catalog.json`、`game_dnf/data/numbers.json`
> 构建：`tools/build_dnf_skill_panel.py`；过程证据见[本轮交付](../reports/ws1/2026-11/2026-11-02_技能系统源数据与职业树.md)。

## 一、范围

- 列出原版全部 175 条剑士 SKL，按主动、被动、通用、强化分类。
- 名称和说明来自同一份 SKL 本地化引用，不再用手写语义名作为显示名。
- 已接入运行时的节点可学习、退点、重置和进入技能栏；未接入节点标灰只读。
- 当前职业树：鬼剑士 60 个可见节点，剑魂 90 个，狂战士 81 个；“显示全职业”只用于查看，不绕过学习校验。
- 转职仍是 18 级简化入口：鬼剑士二选一剑魂或狂战士；原版任务与剧情未接。

## 二、源数据与名称

`tools/build_dnf_skill_panel.py` 从 `skill/swordmanskill.lst` 枚举 175 个 SKL，并读取：

| SKL 字段 | 运行时用途 |
|---|---|
| `[name]`、`[basic explain]`、`[explain]` | 面板名称、Hover 简介、详细说明 |
| `[type]`、`[skill class]` | 主动/被动分类 |
| `[max level]` | 存档等级上限 |
| `[required level]`、`[required level range]` | 每级角色等级要求 |
| `[growtype max level]` | 本源、剑魂、狂战士等职业列上限 |
| `[pre required skill]` | 前置技能与等级 |
| `[purchase cost]` | SP 成本 |
| `[icon]` | 未选中/选中图标 |
| `[dungeon] level info/static data` | 伤害、MP、CD、施放和被动行值 |

名称解析优先走 `n_string.lst` 中 `type 9 → table id`、`type 10 → string key` 的引用，再读取对应 `.kor.str` 条目；少数 SKL 直接保存显示文字。目录保留表名、键名、行号或直接文本标记，采用简体转换，但不把韩文或原始占位文本写入游戏数据。

## 三、职业与学习

| 职业 | `growtype` | 源列 | 说明 |
|---|---|---:|---|
| 鬼剑士 | `swordman` | 0 | 本源技能 |
| 剑魂 | `weaponmaster` | 1 | 拔刀斩、破军升龙击、武器精通路线 |
| 狂战士 | `berserker` | 3 | 血之狂暴、血气旺盛路线 |

学习事务为 `numbers.skill`，退点与重置分别只处理实际购买记录。添加新技能时，存档迁移只补缺失键，不覆盖已有等级。

校验顺序：

1. 技能存在且操作合法。
2. 未满技能与职业列上限；武器奥义可提高三类武器精通的上限。
3. 角色等级满足 `required_level + 当前等级 × required_level_range`。
4. 前置技能满足原版 ID/等级；未接入的运行前置不会静默放行。
5. SP 足够。

调试 `force` 只跳过等级、职业和前置，不跳过技能上限与 SP。

## 四、运行时节点

| 类别 | 节点 | 效果边界 |
|---|---|---|
| 本源主动 | 上挑、鬼斩、三段斩、十字斩、月光斩、格挡 | 原版 ANI/ATK；格挡为持续防御 |
| 剑魂主动 | 拔刀斩、破军升龙击 | 拔刀剑气对象；破军冲刺+上挑两段 |
| 狂战士主动 | 血之狂暴 | 持续修正；目前数值为 E-ADAPT |
| 被动 | 短剑/太刀/巨剑精通、武器奥义 | 武器条件、等级行和职业上限 |
| 被动 | 血气旺盛 | 十字斩 HP 替代 MP、提高出血触发率 |
| 被动 | 物理暴击、生命之源 | SKL 等级行驱动暴击率/HP |

鬼斩的运动没有自带攻击盒，使用原版 `HardAttackBlade1` 不透明范围和显式窗口生成判定。月光斩和破军升龙击使用身体 ANI 自带盒；缺盒范围继续沿用统一的派生盒规范，不把资源重叠当成原版证明。

## 五、技能栏

- 六个技能槽固定对应 A/S/D/F/G/H；Z/X/C 保留基础技能与动作。
- 槽内保存技能稳定 ID，不保存键码。
- 拖入条件：已学习、运行时主动技能、六槽之一、同技能不重复。
- 空槽移动、占位交换、旧档默认布局和读档都由 `items/slot_layout.gd` 处理。
- 出征时槽顺序进入 `CombatSession`；战斗侧按槽位接收输入，因此同一技能可拖到任意键。
- 技能图标优先使用原版 SKL 图标；流程美术包缺少新节点时回退到已入库的 `assets_local/skill_panel/icons/`。

## 六、界面

暗化层 → 780 宽窗口 → 标题条 → 四类页签 → 9 行分页列表 → 右侧来源说明与要求 → 底部加点/退点/重置/官方规则开关 → 职业过滤与转职按钮。

技能说明 Hover 与 K 面板使用同一份生成说明；展开说明框限制宽度并自动换行，避免长句越过原版边框。
