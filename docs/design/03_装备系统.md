# 03 装备系统

状态：已确认（核心决策） / 部分待决策

## 范围（按 60/70 版本拆分）

- 部位：武器 + 防具 5 件（头肩/上衣/下装/腰带/鞋）+ 首饰 3 件 + 称号
- 品级：白 → 蓝 → 紫 → 粉 → 橙（史诗），决定基础属性与词条数量
- 强化：+1~+10 稳升；**+10 以上失败只降级、装备保留**（单机友好）
- 耐久与修理：消耗耐久、NPC 修理（商店模块实现）
- 附魔：装备打属性卡片（后置评估）
- 时装/皮肤：纯外观（后置）

## 已确认决策（2026-10-13）

- 强化失败 = 降级不掉装（已确认，替代经典碎装）
- 品级 + 强化必做，为怀旧循环核心心流
- 装备词条：每品级 1~3 条随机属性，掉落时随机生成
