## 范围（按 60/70 版本拆分）

- 区域与副本：若干区域，每区域 3~6 个副本，线性解锁
- 副本结构：房间式（小怪房 → 精英房 → BOSS 房），房间内清理开门
- 难度：普通/冒险/勇士/王者，影响血量、伤害、掉落
- 疲劳值：每日上限，进副本消耗（控制节奏）
- 通关评价：SSS~F（受击数、被击、连击、时间）
- 翻牌：通关翻牌奖励（装备/材料/金币），可金币翻第二次
- 掉落表：按副本/难度/怪物配置

## 建议

- 全部必做，这是核心循环。首发 1 个区域 3 个副本 + 1 个 BOSS 房即可跑通。
- 疲劳值保留（怀旧节奏感），数值可放宽。
