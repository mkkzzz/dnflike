# 05 地下城系统

状态：已确认（核心决策）

## 范围（按 60/70 版本拆分）

- 区域与副本：若干区域，每区域 3~6 个副本，线性解锁
- 副本结构：**副本 → 布局（1~N 套）→ 房间模块（可复用）**；同一副本可有多种关卡布局、由房间模块自由拼装，硬约束是入口房开头、**最后一间必为 BOSS**；房间内清理开门（细则见 [23 副本设计工作流](23_副本设计工作流.md)）
- 难度：普通/冒险/勇士/王者，影响血量、伤害、掉落
- 疲劳值：**不保留**（单机自由刷，已确认）
- 通关评价：SSS~F（受击数、被击、连击、时间）
- 翻牌：通关翻牌奖励（装备/材料/金币），可金币翻第二次
- 掉落表：按副本/难度/怪物配置
- 死亡：回城或原地复活（消耗复活币，见决策清单 F015）

## 已确认决策（2026-10-13）

- 疲劳值不做，副本不限次数自由刷
- 死亡无惩罚（可选回城或花复活币原地复活）
- 其余细节见 `决策清单.md`（C011、C013~C014、F018~F021）
