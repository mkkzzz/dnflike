## 一、M1 目标

在 Godot 工程里做出**可游玩的战斗手感原型**：

- 鬼剑士基础职业：完整基础动作集 + 3 段普攻连段 + 上挑浮空
- 1 种怪物（哥布林）：完整受击反应（硬直/浮空/倒地/受身）+ 简单 AI
- 手感指标落地：命中停顿、震屏、击退、跳字
- 注意：转职技能（狂战士/剑魂）在 M1 只做**2 个代表性技能**验证框架，其余 M2/M3 补齐

## 二、基础操作（已确认：无搓招，纯快捷键）

| 按键 | 动作 |
|---|---|
| A/D 或 ←/→ | 左右移动（双击方向=奔跑） |
| C / 空格 | 跳跃 |
| X | 普攻（连按出 3 段连招） |
| Z | 通用技能（鬼剑士：上挑） |
| A~H | 技能快捷栏（转职技能） |
| 1 / 2 | 消耗品 |

## 三、基础动作清单（鬼剑士通用，转职前）

| 动作 | 说明 | 帧数（60fps 基准） | 备注 |
|---|---|---|---|
| idle 待机 | 呼吸浮动 | 循环 | 美术帧 4~6 张 |
| walk 行走 | 慢速移动 | 循环 12f | 速度 200px/s |
| run 奔跑 | 快速移动 | 循环 10f | 速度 420px/s |
| jump 跳跃 | 起跳/空中/落地 | 起跳 8f / 空中循环 / 落地 6f | 跳跃高度 140px |
| back_dash 后跳 | 向后小跳（回避） | 18f | 位移 -120px，前 6f 无敌 |
| attack1 普攻一段 | 横斩 | 前摇 6f / 判定 4f / 收招 10f | 连段窗口：收招后 12f 内接二段 |
| attack2 普攻二段 | 反手回斩 | 前摇 5f / 判定 4f / 收招 12f | 连段窗口同上 |
| attack3 普攻三段 | 下劈 | 前摇 8f / 判定 5f / 收招 18f | 击倒效果，可取消接技能 |
| upper 上挑 | 挑空敌人 | 前摇 5f / 判定 3f / 收招 12f | 浮空起手，命中后跳起追击 |
| guard 格挡 | 防御姿态 | 持续按住 | 减伤 80%，受击不硬直 |
| hit 受击 | 轻受击硬直 | 硬直 14f | 可被浮空技打断 |
| air_hit 浮空受击 | 空中被击 | 重力下落 | 落地弹起 1 次 |
| down 倒地 | 倒地躺 | 36f | 后 18f 可受身 |
| getup 受身起身 | 受身 | 12f | 无敌 12f |

**命中反馈规范（全局）**：命中停帧 4~6f（重击 8f）、屏幕震动 2~6px、伤害跳字（暴击放大变色）、受击白闪 2f。

## 四、转职技能（原创命名，机制对标经典）

### 狂战士（血性·近身·以血换伤）

| 技能 | 快捷键 | 效果 | 异常/机制 |
|---|---|---|---|
| 血怒 | A | 狂化状态 8s：攻速+30%、移速+20%、防御-30% | 自带霸体（已确认机制） |
| 怒斩 | S | 大范围横斩 2 段 | 出血（已确认 5 异常之一） |
| 嗜血打击 | D | 前抓取，命中吸血 15% | 抓取判定，无敌帧 |
| 血腥风暴 | F | 旋转大剑 1.2s，多段伤害 | 霸体，可移动 |
| 崩山 | G | 跃起砸地，冲击波击飞 | 落地范围伤害，无敌帧 |
| 血十字 | H | 强化十字斩，前方 X 形剑气 | 出血 |

### 剑魂（剑术·连击·快速）

| 技能 | 快捷键 | 效果 | 异常/机制 |
|---|---|---|---|
| 拔刀斩 | A | 收刀蓄力 0.3s 后瞬斩，范围大 | 出刀帧无敌 |
| 连突刺 | S | 快速前突刺 3 连 | 可取消普攻收招 |
| 升龙 | D | 上挑强化：自身腾空连击 | 浮空追击衔接 |
| 剑影 | F | 向前放出分身斩击 | 脱手技能 |
| 疾风连斩 | G | 高速多段斩 6 段 | 攻速属性加成（已确认机制） |
| 剑幕 | H | 周围剑光护体 1.5s，反弹飞行道具 | 霸体 |

> M1 实现范围：狂战士做「血怒 + 怒斩」，剑魂做「拔刀斩 + 连突刺」，验证霸体/无敌帧/异常/攻速四大机制。其余技能 M2/M3 按美术排期补齐。

## 五、攻速与帧数缩放（已确认：只影响普攻和部分技能）

- 攻速系数 1.0 = 帧表标准速度；有效区间 0.7 ~ 1.6
- 受影响：普攻三段、连突刺、疾风连斩（标注"攻速加成"的技能）
- 不受影响：跳跃、上挑、大技能（帧数固定）

## 七、配置表结构（数据驱动）

所有帧数、速度、伤害、异常全部走 JSON 配置表（`game/data/`），不在代码里写死：

- `moves.json`：动作帧表（前摇/判定/收招/位移/无敌帧/停帧）
- `skills.json`：技能表（伤害/冷却/异常/霸体/无敌/耗蓝）
- `monsters.json`：怪物属性与 AI 参数
- `player.json`：玩家基础属性与成长
