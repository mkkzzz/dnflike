# 任务指引面板与城镇持武器

> 2026-10-25 负责人需求："做一个任务指引系统，UI 大概放在右中偏上，看看资源库有没有相关资源，字体用对话框类似的就好"，
> 随后细化为"永远显示""大小做成原来的 2/3""整个框靠着屏幕最右侧"，并提出"城镇里面也拿着武器"。

## 一、任务指引面板

### 位置与尺寸（800×600 UI 基准）

| 项 | 值 |
|---|---|
| 画布 | `flow/loop_root.gd` 的 `ui` 固定 800×600，整体按 1.8 倍放进 1920×1080 |
| 位置 | `(641, 132)` —— **贴右边缘**（641 + 159 = 800），纵向在中间偏上 |
| 尺寸 | `159×98` = 原生底板 `239×147` 的 **2/3** |
| 顶栏避让 | 顶部提示条出现时下移 30px |
| 常驻条件 | 角色已建立、无全屏面板、未开 GM 面板，城镇与战斗都显示 |

### 资源（全部取原版 UI，未自绘）

| 用途 | 来源 |
|---|---|
| 底板 | `ui.quest` 帧 14（`quest.img` 原生 239×147 暗底面板） |
| 图标 | `ui.quest` 帧 0（39×39 金环任务图标） |
| 分隔线 | `ui.quest` 帧 1（236×3） |

三张原生帧都按 `2/3` 缩放（`skin.image(..., shrink)`），保持像素对齐。
**不要用帧 7/8**：那是原版窗口的分页签，里面已经烤进了"奖励"等中文字。

### 文字

沿用对话框同源方案（`ui/flow/native_skin.gd` 的 `label()` + `UIFont`）：

| 行 | 字号 | 颜色 |
|---|---|---|
| 任务名 / 可接任务 | 10 | `#f0d18a`（对话框人名金） |
| 目标行（未完成） | 9 | `#c9bda3`（羊皮纸） |
| 目标行（已完成） | 9 | `#8fc46a`（绿，前缀 `✓`） |
| 交付提示 | 9 | `#f0d18a` |

### 内容规则

- **有追踪任务**：任务名 + 最多 3 条目标（`· 拜访林纳斯 0 / 1`），完成后变绿打勾；全部完成时改为"目标已完成 + 回城向 X 交付"。
- **无追踪任务**（负责人要求"永远显示"）：标题"任务指引"，正文"暂未追踪任务"，若存在可接任务则补"可接：<任务名> / 找 <NPC>"。
- 每帧由 `loop_root` 调用 `refresh_tracker()`，用内容签名比对，**只有变化时才重建文字标签**。

## 二、城镇持武器

原实现把城镇武器隐藏（`player_locomotion.town.weapon_visible=false`，注释写明是"表现适配"）。
现在改为：城镇角色直接使用**运行时清单的带武器合成动作包**。

| 项 | 旧 | 新 |
|---|---|---|
| 图集 | `motion_town.png`（无武器分层合成） | `player_<武器>.png`（runtime `players.<weapon>`） |
| 动作 | `player_locomotion.town` 的 stay/move/dash | runtime `clips` 的 `player/stay`（90~95）、`player/move`（180~187）、`player/dash`（105~112） |
| 武器类型 | 隐藏 | `numbers.json` → `equipment.<id>.weapon`（当前 4 件装备均为 `katana`） |
| 回退 | — | 清单缺键时仍回退到原无武器分层包 |

刷新时机：进入角色（`enter_character`）与每次换装（`refresh_item_views`）后调用 `town.set_weapon()`；同种武器为空操作。
