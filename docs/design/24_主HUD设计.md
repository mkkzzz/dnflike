## 一、结论

- **现行 HUD 的问题**（`game/scripts/hud.gd` 程序绘制版）：信息挤在左上角、技能栏单排且无道具格、无左右下角球体、无经验/评价/增益图标、字体层级弱、整条底栏只有一层半透明渐变，跟参考的"金属底板 + 分区锚定"不是一个结构。按使用者判断"几乎都不对"，**重做而不是修补**。
- **已确认（2026-10-18）**：
  1. **队伍栏暂不实装**，只在左上留出空位，以后有组队需求再补；
  2. **技能栏复刻参考的双排 12 格**，键位取 Q W E R T Y / A S D F G H；这套键位**只用于技能**，与移动、普攻、跳跃等基础动作键（← → ↑ ↓、X、C、Z 等）互不相干；
  3. **视觉完全参考原图**（暗蓝金属 + 古金浮雕），能做出来的资源就按原图做。
- **新方案**：13 个分区，全部按四角 / 中轴锚定，逻辑坐标写死、美术按 2K 原生出图；底部主栏（球、经验、道具、技能）作为一组整体让位，保留现行"角色走到路面前沿底栏淡出"的行为。
- **本期顺序**：P0 骨架 + 程序占位并接真数据 → P1 换底板/球/槽九宫格 → P2 补技能/道具/增益/评分图标 → P3 双分辨率验收。
- **水印**：参考截图只用于测量分区与比例，不进入仓库、不切像素、不派生任何资产；布局图是重新绘制的线框。此后本项目的 HUD 样张、实机截图、评审板一律不得出现第三方水印或上传者昵称。

## 四、组件规格

- **A 队伍（预留）**：只画虚线占位框，不画头像/血条；实装时不占渲染成本。
- **B 首领条**：类型图标 34×34；条分三段——红（当前 HP）、暗红（掉血残影）、紫（霸体/护盾，只覆盖剩余部分）；`×N` 18px。无目标时整组淡出 0.3s，不占位。
- **C 副本信息**：三行右对齐；进房时名称淡入 0.4s；房间号随门切换刷新；FPS/计时只在调试开关打开时显示。
- **D 评价**：四行固定顺序；数值变化时数字滚动 0.2s；评分字母变色（S 金、A 银、B 铜）。
- **E/F 球**：圆环外圈固定，胶囊内液面高度 = 比例，带 2px 高光与轻微波动；低于 30% 时球体呼吸红闪（HP 球）。
- **G 经验条**：无经验系统时保持 0% 并显示 `Lv.30`，不伪造进度。
- **H 技能栏（2 排 12 格）**：格内左上技能等级（`Lv.` 小字）、右下键位；状态：就绪 / 冷却（径向遮罩 + 秒数）/ 蓝量不足（蓝框）/ 禁用（灰度）；未学或未配置的格子保持空槽（与参考一致），不显示假图标。技能槽内容由 `skills.json` 的 `slot` 字段驱动，当前每职业只占 2 格（血怒、怒斩 / 拔刀斩、连突刺），其余空置。
- **I 槽位**：底框 + 图标 + 右下数量；药水显示剩余次数与冷却。
- **J 增益**：图标 18×18 + 底部 2px 剩余时间条；到期淡出。
- **K 连击**：数字从 1.15 倍回落到 1.0 的弹跳；连击 ≥ 10 变金、≥ 30 变橙红。
- **L 提示**：单行居中，深色底 60% 透明；与播报队列共用，避免叠字。

## 五、视觉规格

- **方向（已确认）**：完全参考原图的暗蓝金属 + 古金浮雕。底板为深藏蓝珐琅，边为黄铜/古金浮雕，槽位内凹，球体带齿轮环与玻璃胶囊。
- **材质要点**：外框 2~3px 亮金高光 + 1px 暗金描边；底板四角做卷草纹/铆钉；球环做 12 齿齿轮；槽位内阴影（上暗下亮）；整体加极轻噪点避免纯色塑料感。

## 七、实装方案

- **节点结构**（新建 game/scenes/hud.tscn，待建）：`CanvasLayer` → `Control HudRoot` → 分区子节点（`PartyReserved` / `BossBar` / `DungeonInfo` / `RankPanel` / `BottomBar`（内含 `OrbHp`、`OrbMp`、`ExpBar`、`BuffRow`、`SkillGrid`、`ItemRow`）/ `Combo` / `Toast`）。底部整组挂同一父节点，继续整体 `modulate` 让位。
- **静态/动态分层**：静态层用 `NinePatchRect` / `TextureRect`；液面、冷却径向遮罩、条填充、文字用 `_draw` 或轻量子节点，每帧只重绘变化项。
- **数据接口**：保留现有 `set_player_info / set_vitals / set_combo / set_target / set_cooldowns / set_dungeon_room / set_elapsed / set_front_occlusion / set_feedback / set_training`，新增 `set_exp(level, cur, max)`、`set_rank(ops, tech, hits, rank)`、`set_buffs(list)`、`set_party(list)`、`set_items(list)`、`set_skill_slots(list)`。旧调用点不得改动语义。
- **键位**：技能格只绑定技能键（Q W E R T Y / A S D F G H），基础动作（移动、X 普攻、C 跳跃、Z 上挑、V 格挡、↓+C 后跳）不进技能格；`player.gd` 的输入表另立映射，不与 HUD 槽位混用。
- **刷新策略**：数值变化时刷（`set_*` 内 `queue_redraw`），液面/冷却每帧刷；连击/播报用 `_process` 计时。
- **回归**：`tools/run_demo.ps1 -Test` 的 369 项不得减少；HUD 只读数据，不改战斗逻辑。截图验收按 [22 四节]：1920×1080 与 2560×1440 各一张，检查字重、糊边、球体液面。
- **旧资产**：`game/art/hud/*`（V4 烘焙）在 P1 后标记退役，不删除历史；`hud_manifest.json` 保留作对照。
