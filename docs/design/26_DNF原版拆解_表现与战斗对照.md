# DNF 原版拆解：表现与战斗对照

> 上级入口：[还原路线](26_DNF原版拆解与还原路线.md)。优先处理用户指出的场景、美术、UI、动作和战斗五类问题。
> 下面规定测什么、怎样验，不凭空规定原版应该是什么数值。

## 一、共同对照条件

每组证据必须记录原版来源锁、角色/职业/等级/技能等级/装备/衣装/Buff、地图/难度/怪物、输入序列、分辨率与录制时间基准。
显示为同一比较尺寸；保留原始画面，另生成明确标注的裁切/缩放对照。
必须区分逻辑像素、窗口像素、屏幕缩放、相机位置和HUD占用区。
截图不足以证明动作节奏，连播不足以证明碰撞；分别保留静图、视频与事件记录。

容差需根据源数据精度、采样帧率和量测误差制定。没有量测依据，不先承诺“误差1帧以内”或“完全一致”。
用户认为“不像”的问题先登记具体画面/操作，不用自动化检查通过否定反馈。

## 二、场景与美术

| ID | 拆解项 | 原版依据/量测 | Godot交付与验收 |
|---|---|---|---|
| VIS-01 | 视口、HUD占位、相机、人物与场景比例 | 全屏原图、人物高度/脚底位置、镜头边界 | 同条件整屏对照；不只比较局部精灵 |
| VIS-02 | 地图尺寸、走区与阻挡 | MAP/TIL、四边和关键实体通行实验 | 世界坐标与镜头分离；逐段走边/绕物录像 |
| VIS-03 | 远/中/近层、滚动比例和前景 | 原MAP字段与水平移动录像 | 同一路径取多个镜头位置；前后层移动关系正确 |
| VIS-04 | 物件摆位与遮挡 | 原装配坐标、层标记、角色绕行 | 脚底排序与固定层分别处理；树前/后、边缘和跨层对照 |
| VIS-05 | 门、光效与进出场 | 原对象ID、四向图像/动作、门位置 | 上下左右分别还原，不能共用上门或旋转侧门替代 |
| VIS-06 | 图像像素、色彩、Alpha、滤镜和混合 | 原IMG及原客户端同背景显示 | 原尺寸解码、透明边缘、暗/亮背景比较；未知混合显式报错 |
| VIS-07 | 角色衣装/武器前后层、翻面、身体一致性 | 同角色/衣装/武器的逐帧组合 | 同包各层统一根坐标；左右、空中、受击和出招逐帧核对 |
| VIS-08 | 物件破坏/掉落/残留、粒子与环境 | OBJ/ACT/ANI及实机事件 | 破坏前后、切房返回、重开/死亡路径均检查 |

先恢复一间真实原房间的全部关系，再扩房间数量。
地板平铺与原图直贴若不符合原地图装配，应修装配规则；不得靠增加随意物件掩盖布局差异。
原版像素资源适用[22的新版例外](22_资产画面规格.md#六dnf-原生像素新版例外)，本轮不生成新素材。

## 三、UI与排版

| ID | 拆解项 | 需记录 | 验收场景 |
|---|---|---|---|
| UI-01 | 整体布局 | 基准视口、面板边界、固定/伸缩/平铺区、与世界画面的关系 | 两种显示尺寸整屏比较；不能以裁掉HUD中段代替布局 |
| UI-02 | 字体/字形/数字 | 字体来源、字号、基线、描边/阴影、字距、对齐、截断 | 中文/英文/数字、长名、负数/大数、不同状态 |
| UI-03 | 血蓝/经验/疲劳 | 图层、遮罩/填充方向、数值格式、闪动/恢复 | 空/满/中间、受击/回蓝、死亡、暂停、切房 |
| UI-04 | 快捷栏与图标 | 原技能ID→图标路径/帧、按键字形、CD遮罩、缺蓝/材料状态 | 可用/不可用/冷却/悬停/拖换；每项绑定真实状态 |
| UI-05 | 怪物与领主信息 | 出现条件、位置、名字/等级/属性图标、血条段数/变化 | 首次接敌、切目标、多人目标候选、死亡/离场 |
| UI-06 | 小地图 | 探索状态、连接关系、当前/领主/特殊房间、提示闪烁 | 未访问、访问未清、已清、来回、领主房 |
| UI-07 | 窗口交互 | 控件状态、焦点/叠放、快捷键、鼠标命中区、穿透 | 打开/关闭/拖动、Esc优先级、游戏输入隔离 |
| UI-08 | 提示/评价/结算 | 字形/动画、出现时点、条件、奖励事务 | 胜负、退出/重试、背包满、奖励不能重复发放 |

当前系统字体、文字技能格、程序画的条/框属于适配，直到原版对照证明其符合目标。
完整屏幕清单见[全系统目录](26_DNF原版拆解_全系统目录.md)，不得只还原常驻HUD就宣布UI完成。

## 四、动作与输入

| ID | 拆解项 | 必须确认的规则 | 对照方式 |
|---|---|---|---|
| ACT-01 | 时钟 | 原帧时长、循环/等待、攻速作用段、停帧影响对象 | 同输入事件轴；分别记录实际时间与动作时间 |
| ACT-02 | 基础动作 | 待机、行走/跑动起停、方向变化、跳起/滞空/落地 | 裸动作连播、脚底轨迹、人物位置、状态切换 |
| ACT-03 | 普攻 | 三连接续、按住/重复按、缓冲期限、末段收招、武器差异 | 同武器完整连续三刀；空挥和命中分别对照 |
| ACT-04 | 防御与受击 | 正背面、减伤、击退、硬直、无敌、霸体、倒地/起身 | 正背攻击、连续打击、空中/地面与致死 |
| ACT-05 | 取消与技能 | 可用状态、取消资格、输入优先级、失败是否吃输入/扣费 | 有/无取消条件、有效段前后、多输入同帧 |
| ACT-06 | 武器/衣装依赖 | 动作类型、攻击/受击盒来源、前后层、武器修正 | 三武器同条件及左右对照，不能只换图 |

首两刀身体ANI没有攻击盒，只能说明这些文件没提供攻击盒；需继续查武器/角色/引擎依赖。
长等待帧可能与状态退出相关；语义未确认前保存原字段，不批量截短或删除。

## 五、战斗规则

| ID | 拆解项 | 需要的设计记录 | 关键反例 |
|---|---|---|---|
| CBT-01 | 空间命中 | 攻击/受击盒、轴方向、朝向镜像、根坐标、边界与相交 | 擦边、背后、纵深错开、不同高度、倒地 |
| CBT-02 | 多段与去重 | 实例ID、命中组、段间间隔、目标过滤、重复命中规则 | 同目标停留、多目标、离开再进入、低/高攻速 |
| CBT-03 | 伤害链 | 基础攻击、武器/技能倍率、等级、属性/防御、暴击、取整 | 换武器/等级/怪物只改一项，固定随机条件 |
| CBT-04 | 受击运动 | ATK字段、硬直、击退、浮空、重力、落地/弹地、保护 | 空地状态、重复浮空、墙边、死亡同时发生 |
| CBT-05 | 消耗/CD | 施放条件、扣费/CD时点、等级曲线、指令优惠、失败处理 | 缺蓝、材料不足、打断、切房、暂停 |
| CBT-06 | Buff/异常 | 叠层、持续时钟、刷新、抗性、结算顺序、清理 | 重复施加、免疫/霸体、致死、切房/重开 |
| CBT-07 | AI与领主 | 目标选择、感知、冷却、选招、移动、阶段转换 | 脱离范围、遮挡、目标死亡、阶段临界点 |
| CBT-08 | 音画反馈 | 命中停帧、闪白、震屏、特效层、声音/跳字 | 空挥/命中、轻/重、多目标、连击与中断 |

固定伤害、统一硬直/重力、全局停帧等现版适配必须逐条核实，不直接提高参数来代替还原。
声音事件需追CHR/ATK/ANI/audio.xml等链路；换武器、空挥/命中的声音不假定相同。
本轮不制作或替换音效；若另开新制音效需求仍适用19/20流程。

| 场景 | 覆盖项 |

| S01 原房间空场走动 | 静止整屏、左右走跑起停、镜头滚动、纵深走边、物件遮挡、四向门 |
| S02 裸动作 | 同衣装/武器待机、跳跃/落地、后跳、格挡、三连；左右均展示 |

| S04 代表技能 | 上挑、拔刀斩与一项多段技能；MP/CD、攻速、打断和取消条件 |
| S05 完整HUD与生命周期 | 不同血蓝/CD、怪物/领主条、小地图、清房/返回、胜负/重开、暂停 |

每组都交原版、Godot、差异注释和事件表；不能用另一套离线素材替代实装资源录像。
