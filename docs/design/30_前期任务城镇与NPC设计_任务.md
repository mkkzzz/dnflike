# 前期设计：任务与成长路线

入口：[前期总览](30_前期任务城镇与NPC设计.md)。任务名称下表以简体中文说明，来源快照保留原繁体及原键；中文译名不是稳定ID。

## 一、原包任务不是一条按文件名排序的列表

原任务定义在n_quest下。quest.lst提供数字ID到文件的索引；epicquest.lst提供章节展示顺序；QST的前置、等级、职业、成长类型和目标字段决定进一步条件。这三者应分别保存。

本轮发现共通任务散布在地区目录与common目录。只导出Handonmyre会漏掉1901/501/502等职业桥接节点；按文件名的epic_2或epic_8推等级也会出错，实际应读[level]。

| 字段 | 已读取内容 | 不能直接假定 |
|---|---|---|
| grade / difficulty | epic、common unique等类别；O/W/X等原值 | difficulty就是副本难度；它也可能参与任务收益等级 |
| level / job / grow type | 等级范围、all/swordman、成长类型门槛 | 文件名等级生效；所有职业看到相同任务 |
| npc index / complete npc index | 接取/完成相关NPC数值 | -1永远代表同一NPC；缺省与-1可随意互换 |
| pre required quest | 前置ID列表和原始顺序 | 多项必定全AND；章节先后就是硬前置 |
| type / sub type / int data | 目标类型与位置敏感参数 | 所有目标都可统一拆成ID和数量；负数都是0 |
| reward type / int data / selection | 物品、职业变化等奖励与条件化条目 | 全部是无条件物品对；0的含义或金币/经验公式已确认 |
| name / condition message等 | 直接字串或9/10类型的表ID和键引用 | 原文和数值一定一致；乱码可以删掉再凭记忆补文本 |

档案中的.kor.str后缀不代表文本内容一定是韩文。本次所用NPC、城镇、任务STR实际可严格CP950解码并原字节往返；通过n_string.lst和键解析出中文。保留原表/键/行号，输出到游戏时统一简体中文与术语。

任务112最低等级为12，虽然文件名仍含epic_8。文件名、原文和实际字段矛盾时，保留差异并进入验证，不偷偷改到记忆里的等级。

本轮确认的任务目标中文包括“杀5只猫妖”“击败凯诺”“获取毒猫王的毒药袋”。掉落几率、任务物品是否必掉、组队共享和接受前进度均未实测。

## 八、任务组织与节奏建议（E-ADAPT）

1. 首次只突出一个可执行主目标；支线允许共接，跟踪面板只显示玩家选择的少量条目。具体可接/跟踪数量本轮不设成原版数值。
2. NPC对话按可交付任务、可领取任务、剧情交谈、服务分类展示；多条同地任务要可区分，不能一个按钮一次领走所有奖励。
3. 任务文本至少回答“去哪、做什么、数量/条件、找谁交”；地图名与出征卡一致，目标NPC可导航定位。
4. 普通击杀任务在接受后按稳定击杀事件计数；是否追认先前通关/现有材料按目标策略单独定义。
5. 条件达成变为可交付，交付成功才发奖/消费材料/解锁后继；自动结算任务作为单独类型。
6. 同一怪物可推进多条适用任务，但同一事件重发只对各目标计数一次；章节共享任务ID不产生第二份任务实例。
7. 返回城镇、切角色、重载、任务物品转移后重新计算可交付性；不能在失去材料后仍允许领奖。
8. 卡等级时优先检查任务依赖、地图开放和奖励曲线；没有原版证据前不靠增加无意义刷图次数填时长。

## 九、不可把筛选结果直接导入运行

商人等级系列21002～21004在洛兰深处目录，但中文条件涉及启动资金与手续费；它们不是“新人教学”的同义词。
低等级宠物进化、活动、修练场和时间之门同样不因等级低而进入60复古前期白名单。

白名单必须携带源ID、源路径与SHA、职业/成长类型、目标处理器、奖励解析、资源闭合和版本确认状态；无法解释的节点保持锁定并给开发诊断，不能默认无条件成功。
