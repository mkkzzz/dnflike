# 23 副本设计工作流

状态：草案（2026-10-16 提交评审）。首个适用对象：初始副本（明亮白天森林）。
关联：[05 地下城系统](05_地下城系统.md) · [14 美术资源全流程](14_美术资源全流程.md) · [15 统一风格与题材规范](15_统一风格与题材规范.md) · [16 美术资源总清单](16_美术资源总清单.md) · [17 美术资源任务模板](17_美术资源任务模板.md) · [19 音效生产工作流](19_音效生产工作流.md) · [20 音效任务模板](20_音效任务模板.md) · [21 美术目录与资产归档](21_美术目录与资产归档.md) · [22 资产画面规格](22_资产画面规格.md)。

## 一、总则

- 结构：地区 → 副本 → **布局（关卡布局，1~N 套）** → 房间模块（可复用）。同一副本可有多种布局、由房间模块自由拼装；硬约束：入口房开头、**最后一间必为 BOSS**；房间内清理开门。
- 编号：副本 5 位（如 10001）；布局 = 副本号-大写字母（如 10001-A）；房间模块 = 副本号-R + 两位序号（如 10001-R01）。布局是配置层，新增/调整布局不产出新美术，除非引入新房间模块。
- 资源边界：**背景图不含任何可碰撞物**；怪物、非生物实体、关卡门、掉落物全部是独立资源，由关卡配置摆放。
- 规格：新资产按 [22](22_资产画面规格.md)（2K 原生）；目录按 [21](21_美术目录与资产归档.md)；风格从所属地区出发（[15](15_统一风格与题材规范.md)），不同地区/副本风格可以完全不同；音效按 [19](19_音效生产工作流.md)。
- 复用优先：能复用已批准资源就不重复设计；复用必须登记来源与批准范围。
- 通用制作规范（任务模板、审批链、发布规则）沿用 [14](14_美术资源全流程.md) 与 [17](17_美术资源任务模板.md)；本文只做副本层特化。

## 二、流程（每步有产物与通过门）

| 步骤 | 做什么 | 产物 | 通过门 |
|---|---|---|---|
| 1 定位与需求 | 地区/副本在内容线的位置、解锁、难度、房间数量与类型构成、BOSS、时长 | 副本需求单 | 用户确认范围 |
| 2 风格方向 | 从地区基调出发：色光气氛板、时段、材质、参考图 | 气氛板 | 用户认可风格方向 |
| 3 内容清单与复用判定 | 逐类判定 新增 / 复用 / 变体：怪物、非生物实体、场景、门、音乐音效、UI | 资源台账 + 复用登记 | 清单确认 |
| 4 关卡结构 | 该副本的布局套数与每套布局的房间序列、每间角色（入口/小怪/精英/BOSS）、横竖长短、门位、节奏 | 布局清单（关卡配置表） | 用户确认结构 |
| 5 美术产出 | 先基准房样张 → 认可后按房间批量；实体与门按清单出图 | 源图、导出、门两状态与动效、破坏物三状态 | 样张认可 → 组合预览验收 |
| 6 音频产出 | BGM / 环境 / 战斗 / 交互音效清单与事件绑定 | 音效包 | 用户试听认可 |
| 7 组合验收 | 背景 + 实体 + 门 + 怪物按配置摆好组合；2K/1080p 抽查 | 组合预览 + 检查记录 | 用户认可组合 |
| 8 交接与实装 | 任务包发布；实装区接入关卡配置、碰撞与事件 | 发布记录 | 接收区实机验收 |

## 三、各内容要求

### 布局与拼装

- 一个副本先定基础布局（如 10001-A），变体布局（短版、长版、随机化等）按需要另排；同一模块可在布局内重复出现，怪物数量与实体/门摆放按“位置实例”分别配置。
- 拼装规则：所有房间横向串联（左入右出，竖幅房行走面也是横向一条）；首间入口房、末间 BOSS 房；连接由关卡配置生成，门按布局接下一间。
- 布局是配置层：新增/调整布局不产出新美术；只有引入新房间模块才追加美术任务。跨副本复用同地区房间模块时按复用登记来源与批准范围。

### 场景

- 分层：远景 / 中景 / 可行走路面 / 前景遮挡；**路面必须醒目可读**（踩实的路带、边界清晰），避免角色踏空感。
- 尺寸：长/短/横/竖按房间定义；横竖两个方向都超过一屏，数值按 [22](22_资产画面规格.md)。
- 门与画面端部对齐；房间两端留出入画面。
- 竖幅房间默认：行走面仍是横向一条地面线（不做高低差），门开在横向一端；纵向多出的空间用于高耸景物展示与镜头余量。若后续加入纵向玩法，另行设计。

### 怪物

- 清单注明：新增或复用、战斗角色（普通/精英/BOSS）、投放房间与数量。
- 新怪走 [14](14_美术资源全流程.md) E 路线：轮廓比例 → 标准原画 → 动作 → 受击/死亡；复用怪登记来源任务与版本。
- BOSS 单独登记每个招式的起手提示、危险区与结束相位。

### 非生物实体（按关卡配置、全部带碰撞）

| 实体 | 状态 | 说明 |
|---|---|---|
| 木桩 | 单态 | 纯碰撞装饰 |
| 火把 | 火焰循环动画 | 细碰撞；后续可接动态光源 |
| 果树 | 有果 / 无果 | 可打击掉果，果子为拾取物 |
| 木栅栏 | 完好 / 半破坏 / 破坏残骸 | 可打击；打击配合特效 |
| 骨堆 | 完好 / 半破坏 / 破坏残骸 | 可打击；打击配合特效 |
| 灌木、石块 | 单态 | 小装饰与小碰撞 |

- 每个实体登记：脚底锚点、碰撞框、破坏阈值与状态切换时机（由关卡/战斗配置定义）；图片只负责交付各状态。

### 关卡门

- 每间房一个出口门；未开启 / 开启两状态；开启态需要动效（门框灯闪烁等）。
- 默认样式：木质栅栏 + 藤蔓门框 + 门框灯（森林部落风）；其他地区可做款式变体。
- 门的连接由关卡配置决定（顺序自由，BOSS 收尾）。

### 音乐与音效

- 清单：地区/副本 BGM、战斗切换、环境音、交互音效（门、破坏、拾取、跳跃等）。
- 流程与交付检查按 [19](19_音效生产工作流.md)，需求按 [20](20_音效任务模板.md) 填表。

### UI（副本内）

- 门状态提示、破坏物提示等如需要，按 [22](22_资产画面规格.md) 规格登记。

## 四、复用与新增判定

| 类别 | 可直接复用 | 需要变体 | 必须新增 |
|---|---|---|---|
| 场景 | 房间完全一致 | 换色 / 换时段 / 加装饰 | 新构图房间 |
| 怪物 | 已批准原画+动作 | 同族换装 / 换武器 | 新物种 |
| 实体 | 已批准且状态齐全 | 换材质 / 调整尺寸 | 新类型或新状态 |
| 门 | 同款式 | 尺寸 / 地区配色变体 | 新款式 |
| 音乐音效 | 同地区 | 编曲 / 乐器变体 | 新地区或战斗曲 |

- 复用登记：来源任务、版本、批准范围；复用资源在组合预览中仍要复查（比例、风格、光照）。

## 五、验收清单

- [ ] 房间尺寸/横竖/余量符合 22；路面清晰；门与端部对齐。
- [ ] 实体状态齐全（含破坏中间态）；碰撞数据与图一致。
- [ ] 门两状态 + 开启动效；连接顺序与配置一致。
- [ ] 2K/1080p 抽查通过；组合预览经用户认可。
- [ ] 复用资源无比例/风格冲突，已登记版本与来源。
- [ ] 音效事件齐全并有试听记录。
- [ ] 任务包、文档索引、版本注册表已更新。
