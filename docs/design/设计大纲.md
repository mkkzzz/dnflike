# 设计大纲

> 本文档是全部设计方案的**入口与索引**。每个功能模块对应一份独立设计文档，细化后回写对应文件。
> 状态标记：待决策 → 已确认 → 设计中 → 已实现。

## 一、项目目标

怀旧横版动作 RPG（单机）。体验目标对齐经典 60/70 级版本的核心循环：

**刷图 → 掉落 → 成长（升级/装备/强化）→ 挑战更高难度 → 再刷图**

原创世界观、角色、美术、音频；系统结构与手感还原经典。

## 二、设计原则

1. **先系统后细节**：所有功能先定"做不做、做到什么程度"，动作/战斗细节放到 M1 对齐设计时展开。
2. **单机闭环优先**：先完整跑通单人游戏循环，联机相关一律后置。
3. **内容可增量**：模块独立设计、独立实现、独立验收。

## 四、第一版范围（2026-10-13 确认）

> 决策已全量对齐（见 [决策清单.md](决策清单.md) D001~D024），第一版交付以下基础功能闭环：

1. **进入游戏**：标题 → 创建角色（固定基础造型 + 自定义名字）→ 进入城镇
2. **存档**：本地多档位，自动存档
3. **剧情与任务**：主线 + 支线（轻量剧情先行，框架可扩展），无演出
4. **局内战斗流程**：房间式副本、通关评价、翻牌、掉落（对应 M1/M2）
5. **局外城镇**：主城（商店/仓库/铁匠/任务 NPC），装备/强化/制作/商店闭环（对应 M3）

**第一版范围内剩余待审核产出物**（非决策，为方案审核）：
- 世界观方案（原创，结构对标 60 版区域主题）
- M1 动作设计（鬼剑士动作清单 + 双转职技能 + 手感指标）
- 转职造型：狂战士/剑魂两套差异化角色标杆图（新增美术需求）
