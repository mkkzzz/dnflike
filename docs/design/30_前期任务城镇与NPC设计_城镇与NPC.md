# 前期设计：城镇空间与NPC

入口：[前期总览](30_前期任务城镇与NPC设计.md)。本页的功能定位分为原字段事实与设计解释，NPC名字采用本地简体术语，源繁体/别名保留在证据快照。

## 一、三处城镇承担不同成长职责

| 地区 | 场景/叙事定位（E-INFER） | 可核对的原结构 | 内容接入顺序 |
|---|---|---|---|
| 艾尔文防线 | 林地边缘的安全据点；人物少、目标清楚、容易反复返回 | TWN含主街、gate、洛兰地下城口；主街MAP含林纳斯1、土罐8 | 先补赛丽亚入口与两个洛兰副本，保留林纳斯的近距离整备角色 |
| 赫顿玛尔 | 服务和职业成长枢纽；居民之间互相引荐 | TWN列主街、城市区、auction、后街、酒馆、格兰入口及其它出口 | 先接主线必经路径与风振/辛达/G.S.D；再接酒馆/诺顿等分支 |
| 西海岸 | 商贸与魔法主题的新区域；把森林问题导向天空之城 | TWN含街区、魔法区、gate、天空之城及额外地区入口 | 莎兰/罗莉安/卡坤与对应任务先接，其它世界入口按范围锁定 |

三个TWN的[limit level]原值分别是1、3、4。它不等于剧情推荐到访等级，也不证明服务端没有其它准入条件；西海岸任务从16级展开，不能据TWN的4就强制4级搬城。

本地实现应保留“可走的城市与区域出口”，而不是仅做三个传送菜单。玩家要通过视觉地标、NPC招牌、路口和副本口理解空间。

## 二、地图装配与摆位证据

| 原记录 | 本轮可确认 | 不应扩大的结论 |
|---|---|---|
| Elvengard主街 | [NPC]记录出现土罐/林纳斯的原朝向与锚点，重复标签保留 | 不能把重复记录不加判定地生成两套NPC；原Y坐标不等于已认证的屏幕脚点 |
| Hendon_City | 含诺顿13、歌兰蒂斯45、博肯18、阿尔伯特27等 | 名字叫City不代表该区一定是目标版唯一主街 |
| Hendon_Auction | 含G.S.D7、辛达4，也夹杂其它NPC | 不按记忆把二人搬到“经典位置”后声称使用了原摆位 |
| Hendon_Pub / Hendon_Ura | 分别存在索西雅5、夏洛克9的MAP记录 | 酒馆室内/外景连接与进门触发仍要核对 |
| (r)/(f)Hendon | 风振/凯丽等位置和邻居不同 | 文件前缀的语义、生效选择及覆盖顺序未知，不能自动选最后一个 |
| (r)/(f)Gate_Hendon、Gate_West | 同一记录可见赛丽亚2、邮箱32、仓库22 | 可以作为赛丽亚房间入口调查线索，不能据此声称开场一定从该图出生 |
| (r)/(f)WestCoast_Magic | 有莎兰12等NPC | 不把现代/额外NPC一起接入前期白名单 |

TWN中的gate、Hendon、WestCoast等若干通用MAP路径在本库缺少同名文件，存在带前缀的候选变体。正式装配必须显式记录“源引用→所选MAP及哈希→选择依据”，未确认时标候选，禁止导出器默默挑一张相似图。

MAP中的位置字段与可走地面、遮挡、相机和交互范围分别记录。城镇角色的休闲站姿/走路是表现规则；走区不能只剩中间一条路，也不能简单放开穿过建筑和树干。

NPC可同时是剧情角色、任务交付者和服务提供者。服务菜单应依据NPC能力、角色职业、等级和任务状态生成；没有能力处理器的服务显示锁定或暂不展示，不能留一个点击后无效果的按钮。

人物不是职业专属的“不可交流对象”。风振会介绍鬼剑士给辛达，诺顿会参与天空之城研究；限制的是技能/服务资格，普通剧情交谈仍可用。

## 四、NPC对白如何建立人物

本轮额外读取每位NPC前两条[dialog]作为样本，保留它们的条件参数与中文来源；不是完整对白，也没有把前两条认定为新角色一定听到的两句。

| 人物 | 源对白的内容特征 | 后续表现要求（E-INFER/E-ADAPT） |
|---|---|---|
| 林纳斯 | 主动认出初来者，提供帮助，讲移动与X/C/Z基本操作 | 像熟悉环境的长辈，具体而直接；教学文本按本项目当前键位映射生成，不能照抄已改变的按键说明 |
| 赛丽亚 | 先自我介绍并承诺帮助，接着解释居民委托和头顶卷轴标记 | 温和的安全返回点；在同一人物身上组织任务教学，标记样式继续查原UI，不能默认替换成现代通用叹号 |
| G.S.D | 关心左臂鬼神的遭遇，隐约展示高手身份与旧识关系 | 职业导师兼角色命运的解释者；无需一上来用技能商店盖住剧情 |
| 夏洛克 | 自夸货源与天才身份，又解释被哥布林族群排挤的经历 | 利益驱动但有人物理由；他的委托可以带出族群关系，不把哥布林一律当无故事的怪物 |
| 索西雅 | 欢迎喝酒、谈冒险疲惫、看客人决斗，同时强调损坏赔偿 | 酒馆是有生活秩序的空间；幽默与交易意识可以共存，不能只剩一段商店操作说明 |
| 诺顿 | 强调科学与魔法的分歧，具体解释装备分解用途 | 用人物立场讲系统；分解说明里的品质/产物是文字证据，实际产物表和概率仍需核对 |
| 莎兰 | 以魔法公会身份欢迎来者，讲述魔法知识的来源 | 面向更大世界的解释者；承接魔法阵与天空之城问题，不与林纳斯重复同一套新人台词 |

同一人物的日常闲谈、章节对白、任务条件说明和服务说明分开存储。通过任务让玩家认识人物关系：赛丽亚→林纳斯→风振→辛达→G.S.D；索西雅、诺顿、莎兰等在后续问题中被再次找到。
这是一张由具体任务构成的关系网，不是先让玩家把所有NPC挨个点一遍的签到清单。

## 五、场景美术与资源组成

| 组成 | 原数据入口 | 后续实装约束 |
|---|---|---|
| 地区结构 | TWN的area、类型、MAP引用、小地图矩形、gate关联 | 区域ID独立于中文名；出口目标/回程落点/解锁条件齐全 |
| 场景层次 | MAP/TIL、背景/中景/前景、装饰ANI、物件 | 保留原层次与地面锚点，不用重复一张背景当所有街区 |
| NPC世界形象 | NPC的field animation、对应ANI/IMG及朝向 | 原尺寸与时钟，脚点落地，前后遮挡正确；角色不可穿过实体占用区 |
| 人物肖像 | small face / big face / popup face及对话家族 | 按用途选择原图；大对话立绘不能用地图小精灵放大替代 |
| 服务窗口 | 对应原商店/技能/分解等组件 | 共用基础按钮/格子，但保留窗口家族和原布局区别 |
| 任务提示 | 原任务气泡/标记与中文文本 | 先查源UI/帧再选；本轮未认证图标颜色和状态映射，不凭记忆批量重画 |
| 音频 | field wav / popup wav及原音乐映射 | 场景进入/退出有生命周期；本轮未新增音效需求，不启动音效制作 |

用户明确要求原美术、中文与表现细节。源包里的韩文、乱码、现代活动招牌、节日装扮和定制NPC需在消费层逐项筛选。保留原档案不等于允许原样上屏。

现有循环小包只覆盖已选用的城镇/UI/动作，不能据此宣称上表全部肖像和街区都已交付到运行工程。完整原库可通过既有共享入口取得；每批新增运行依赖需另发不可变小包与锁。

## 六、城镇交互与界面规则（E-ADAPT）

1. 按NPC实际地面距离与朝向/可交互范围判定，提示随人物位置；有多个目标时给明确候选，不用画面坐标最近代替世界距离。
2. 交互后先看到人物身份和任务/服务入口；对话窗口沿已认可的底部版式，大肖像、姓名和正文有独立层级。
3. 任务接取/进行中/可交付/已完成对话分开，不在接取后继续显示“尚未见面”的初始台词。
4. 任务与服务可以从同一NPC进入；退出商店/技能页后回到合理上一级，对话关闭后恢复城镇输入。
5. 已交付任务的NPC标记即时更新；同一人物还有别的任务时，不因一条完成就全隐藏。
6. 角色切换后重新计算任务和服务可用性；不能残留上一个角色的商品资格、职业技能和头顶标记。
7. 地区切换保留背包/任务/角色位置策略，副本返回到对应入口附近；不能每次都重置到林纳斯身边。

## 七、城镇验收先看什么

- 原比例全景、NPC近景、地标/门口、街区衔接、酒馆与赛丽亚候选房间分别留实机截图。
- 在视觉可走地面上下移动，测试建筑/树干/摊位遮挡与边界；不穿帮、不被不可见横线卡住。
- 长名字、长中文、多任务和无任务状态都能读清；NPC小精灵、肖像、字号、按钮不能被缩放策略挤变形。
- 同一NPC连做“接取→出征→返回→交付→服务→关闭”，再切角色与重载，验证画面与状态一致。
- 每张地图选用的变体、被排除的事件/活动内容和原版运行对照缺口记入该批任务包。
