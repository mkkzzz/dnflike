# 02 角色体系

状态：已确认（核心决策） / 部分待决策

## 范围（按 60/70 版本拆分）

- 职业体系：首发仅**鬼剑士** 1 个基础职业
- 转职：**狂战士、剑魂** 两个转职（首发即做，玩家选择路线）
- 等级：1~70 级经验曲线，升级自动成长属性
- 属性：力量/智力/体力/精神（主属性）+ 物攻/魔攻/物防/魔防/命中/回避/暴击/攻速/移速/施速
- 觉醒：50 级觉醒（后置到 M5 评估）
- 技能学习：升级得 SP 点，技能树投入
