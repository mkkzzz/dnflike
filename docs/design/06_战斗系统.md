## 当前实机操作与设置

> 从 README 迁入：README 只保留基础须知，操作与设置细节归本文件维护。

| 按键 | 动作 |
|---|---|
| ← / → | 行走；双击同方向奔跑 |
| ↑ / ↓ | 调整地面纵深（同样播放行走步态，移动更快），攻击需要对齐敌人所在纵深 |
| X | 地面三连；跑动时冲斩接后两段；空中下劈，每次起跳一次 |
| Z | 上挑，冷却 2 秒；命中后按 C 起跳，空中 X 追击 |
| C / 空格 | 跳跃；轻点小跳，按住完整跳跃；空中可自由加速、转向并保留惯性 |
| ↓ + C | 后跳，起手有短暂无敌，冷却 0.35 秒；普攻 / 技能收招可更早衔接 |
| V | 正面格挡减伤 80%；起手 3 帧精准格挡减伤 95% |
| A / S | 狂战士：血怒 / 怒斩；剑魂：拔刀斩 / 连突刺 |
| 1 / 2 | 生命 / 魔力药水，共享 5 秒冷却 |
| Esc / F1 | 暂停 / 操作说明 |
| R / T | 重玩 / 切换职业试玩 |
| Tab / F2 | 训练重置 / 切换无限补给与实战蓝耗冷却 |
| F3 / 右上角显示设置 | 帧率上限与垂直同步，立即生效并在本机保存 |

**设置帧率**：按 F3 → 选择 30 / 60 / 90 / 120 / 144 / 165 / 240 FPS 或不限 → 按需切换垂直同步。右上角显示当前 FPS；垂直同步可能让实际帧率受显示器刷新率限制。战斗中打开菜单会暂停，关闭后继续。

**玩法入口**：选择职业后点**连段训练**，可在两个保留浮空、倒地与受身反应的训练目标上练习，默认无限魔力与职业技能补给。HUD 显示最近 5 秒 DPS、本段 / 累计伤害和最长连击，流血计入伤害。点三波挑战进入完整遭遇战。

**手感要点**：奔跑只用同向双击（Shift 已移除）；攻击期间可提前双击并按住方向，在允许移动的收招阶段直接跑出。普通攻速 100%，血怒加成 12%，属性独立于帧率。完整跳跃约 173 px，轻点小跳。↑/↓ 纵深移动播放行走步态且速度提升；每跳默认一次空斩（机制支持技能加成增加次数）。

**当前范围**：M1 双转职各提供两个代表技能，D/F/G/H 尚未开放；最后一波含哥布林队长。
