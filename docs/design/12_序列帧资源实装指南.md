## 二、招式帧数据（与资源对齐的数值）

来自 `tools/art_v5/moves.py`，同时写进 `manifest.json` 的 `motion_hint`：

| 招式 | 总长 | 前冲窗口 | 前冲距离 | 命中窗口 | 停帧 | 类型 | 刀光窗口（出+消散） |
|---|---:|---|---:|---|---:|---|---|
| attack1 一段右横斩 | 30 | 5–14 | 12 px | 8–14 | 3 | light | 8–15 +11 |
| attack2 二段反手横斩 | 32 | 6–15 | 10 px | 9–15 | 3 | light | 9–16 +11 |
| attack3 三段竖劈 | 41 | 9–19 | 18 px | 12–19 | 6 | heavy | 12–20 +14 |
| quick_draw 拔刀斩 | 36 | 16–19 | 104 px | 16–21 | 9 | iai | 16–21 +16 |

- **命中帧**：`hit_window` 内第一个满足接触判定的 tick。资源侧 `hit/*` 序列的 f000 对应命中 tick，播完即收。
- **停帧**：命中后全局冻结 `hitstop` 个 tick；冻结期间身体帧、刀光帧重复，`hit/*` 特效**继续播放**（与预览一致，DNF 同款处理）。
- **前冲**：身体序列不含位移；`motion_hint.travel_start/end/dx` 说明该窗口内 root 应前进多少（smoothstep）。slash 序列的锚是"出招第 0 tick 的 root"，所以 slash sprite 不要跟随前冲移动，固定在世界坐标即可。

## 三、Godot 实装要点（另一工作区）

```gdscript
# 1. manifest -> SpriteFrames（建议离线转一次，或运行时构建）
# 2. 身体层
var body := AnimatedSprite2D.new()          # sprite_frames = body/attack1
body.centered = false
body.offset = Vector2(-240, -230)            # 锚=root：root 对齐角色脚底
body.play("attack1")                          # 60 fps
# 3. 刀光层（世界坐标，不随前冲）
var slash := AnimatedSprite2D.new()          # sprite_frames = slash/attack1
var mat := CanvasItemMaterial.new()
mat.blend_mode = CanvasItemMaterial.BLEND_MODE_ADD
slash.material = mat
slash.centered = false
slash.offset = Vector2(-280, -280)
slash.global_position = root_at_move_start    # 出招瞬间记录的 root
# 4. 受击特效（挂打击点）
var hit := AnimatedSprite2D.new()            # hit/heavy，材质同上
hit.offset = Vector2(-210, -210)
hit.global_position = contact_point           # 命中帧记录的接触点
# 5. 地裂（两层同锚）
#    ground/heavy 用普通混合；ground/heavy_glow 用加法混合，同 global_position
```

- **打击点**：沿用 V4 的命中检测思路——刀身采样线与目标 sprite alpha 的首个交点；本工作区 `tools/art_v5/scene.py` 的 `_detect`（每 tick 4 次子采样、24 个刀身采样点）是参考实现，`hit_alignment_debug.png` 可做对齐验收图。
- **iai 全屏压暗**：拔刀斩停帧时世界亮度 ×0.52、轻微偏蓝，用 `CanvasModulate` 过渡即可（预览里是 `dim` 参数，未烘进序列帧）。
- **受击目标反应**（闪白/红调/轮廓光/抖动/击退）属于目标侧逻辑，不在本资源包内；数值参考 `tools/art_v5/scene.py` 的 `Target.on_hit / look`。
- **加法素材说明**：PNG 的 alpha = max(R,G,B)，Godot 的 `BLEND_MODE_ADD` 下效果与预览一致；若使用自定义 shader，直接 `dst + tex.rgb * tex.a`。
- **泛光**：预览的 bloom 是渲染器后期，未烘进素材。实装侧 WorldEnvironment 可开轻度 glow，或不加（素材自带辉光细节）。

## 五、再生成方式（本工作区）

```powershell
python tools/bake_seq_v5.py        # 重烘全部序列帧 + manifest（依赖 Pillow/NumPy/SciPy）
python tools/bake_body_v5.py       # 重切绿幕身体帧（art/sheets/v5/body_slash*.png）
python tools/preview_v5.py         # 全部预览 GIF -> temp/v5_preview/
python tools/preview_v5.py --publish   # 同步评审媒体到 docs/previews/v5_art/
```

身体帧来源：`image_gen` 生成的 6 格绿幕 sheet（`temp/v5_gen/slash1_sheet.png`、`slash2_sheet.png`），标定数据在 `tools/bake_body_v5.py` 的 `CALIBRATION`（root/握点/建议刀向/遮挡层）。重新生成姿势后需重新目测标定。
