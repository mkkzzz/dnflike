## 状态取值

| 状态 | 含义 | 由谁填 |
|---|---|---|
| 已发布 | 产出方已提交并推送 | 产出方 |
| 已接收 | 接收方已同步并校验 | 接收方 |
| 已实装 | 已接入游戏工程 | 接收方 |
| 已验收 | 实机验证通过 | 接收方 / 用户 |
| 已搁置 | 主动暂停，保留记录 | 产出方 |

## 规则

- 状态升级**由接收方填写**，产出方不得代填"已接收/已实装/已验收"
- 交接产生的等待项，同步写进 [待办](02_待办.md)
- 里程碑达成时追加一行，并在 `main` 打 tag（可选）
- 一次交接一行；过程细节写进 `docs/reports/<工作区>/<YYYY-MM>/` 的对应文档，本文只留索引
