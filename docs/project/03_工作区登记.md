## 三、负责范围

当前**不设固定模块分工**，按任务认领。认领方式：在 [进度看板](01_进度看板.md) 的"在制品"表填一行。

与分工无关的硬约束：

- 产出方只写自己的源目录与文档；不直接改接收方目录
- 接收方（实装）同步后校验并记录实机结果，不由产出方代填
- 同一文件避免双改；必须双改时先走第二节的占位登记
- 公共文档（`README.md`、`AGENTS.md`、`docs/project/**`）改动后必须在 [交接日志](04_交接日志.md) 追加一行
