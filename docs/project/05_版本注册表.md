## 登记规则

- **新增版本**：先在本文加行，再建 `art/sheets/v<N>/` 等目录
- **编号规则**：`v<N>` 单调递增，禁止复用已退役编号
- **状态回填**：由实装 / 验收的工作区填写，产出方只能填到"预览认可"
- 与 [美术资源总清单](../design/16_美术资源总清单.md) 的关系：本文登记"版本级"状态，总清单登记"单项资产级"状态；两者冲突时以实机证据为准并回填
