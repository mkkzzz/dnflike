# 协作总纲

> 协作规则的**唯一维护位置**。`AGENTS.md` 与各 AI 工具入口文件只做指引，不复述本文。
> 项目内容入口见 [文档索引](07_文档索引.md)。

## 一、基本概念

| 概念 | 含义 |
|---|---|
| 工作区 | 一份独立 clone + 使用者 + 其 AI Agent，ID 为 `ws<N>`，见 [工作区登记](03_工作区登记.md) |
| 人员 | 负责人（ws3）、rainmk（ws1、ws2），"等谁"一律填人员或工作区 ID |
| 本地标识 | 仓库根目录 `.workspace`（不入库），记录本区 ID 与上次同步位置 |

## 二、开工与收工（口令）

使用者说 **"开工"**（或 **"开工：<任务>"**）时依次执行：

1. `python tools/sync_status.py`（本 clone 首次先 `--init ws<N>`）；把"等待本区的事项"告诉使用者
2. 读 `AGENTS.md` → 本文 → [进度看板](01_进度看板.md) → [待办](02_待办.md)
3. 落后远程就 `git pull --rebase`
4. 有任务就在本区 [状态文件](status/) 写"正在做"

使用者说 **"收工"** 时依次执行：

1. 改过文档就跑 `python tools/check_docs.py`
2. 更新本区状态文件（转为空闲，"最近完成"补一条）；有交接就向 [交接日志](04_交接日志.md) 末尾追加一行；待办有变化就更新 [待办](02_待办.md)
3. `git fetch` 后提交（`[ws<N>] <类型>：<描述>`）并推送，核对远程 SHA
4. `git status` 应为空；跑过引擎后仍有残留，按第六节排查

**两个词就够，不需要更长的提示词。**

**新工作区首次接入**：clone → `tools/setup_godot.ps1`（只做文档 / 美术可跳过）→ `python tools/sync_status.py --init ws<N>` → 读本文 → 在 [工作区登记](03_工作区登记.md) 填本机路径。

## 三、Git 红线（单分支 main）

- 所有人直接提交到 `main`，不建功能分支
- 禁止 `push --force`、`--amend`、跳过 hooks；不自动修改 Git 配置、不自动安装 hooks
- 冲突时保留双方成果；判断不了就停下沟通，不丢弃他人改动
- **二进制文件**（png / gif / jpg / wav / mp4）无法合并：冲突时不擅自选边，联系产出方决定；同一资产出新版本时建新目录，不覆盖旧文件
- 预计会和他人改同一文件时，先在 [工作区登记](03_工作区登记.md) 占位

## 四、提交

用户持续授权：**有产出就自动提交并推送**，所有工作区同样执行。只完成本地 commit 不算同步。

格式：`[ws<N>] <类型>：<描述>`，例如 `[ws1] 文档：拆分进度看板`。标记让开工脚本能区分是哪个区的提交。

| 类型 | 用于 |
|---|---|
| 设计 | 设计文档、方案 |
| 实装 | 接入游戏工程的改动 |
| 修复 | 缺陷修复 |
| 资源 | 美术 / 音频资源 |
| 文档 | 纯文档改动 |
| 工具 | 脚本与工具 |

- 只 stage 本轮相关文件并检查 staged diff；禁止裸 `git add -A` 带入无关实验、缓存或他人改动
- 推送被拒时重新 `fetch` 并协调，不循环重推
- 不得提交凭证、私钥、未授权素材、`temp/` 产物与引擎噪音文件；`.codebuddy/` 是项目数据，不得当缓存删除

## 五、状态与交接

- 本区正在做什么：只写本区的 [status/ws<N>.md](status/)，只由本区修改，不会和他人冲突
- 交接：只在 [交接日志](04_交接日志.md) 末尾追加，不改旧行（该文件按行合并）
- 等待项：写进 [待办](02_待办.md)，关闭由等待方确认
- 状态词只用 [状态词总表](05_版本注册表.md#状态词总表)；产出方最多填到"已发布"，"已接收 / 已实装 / 已验收"由接收方填
- 预览认可不等于实机验收，提交不等于美术认可
- 以仓库当前状态为准，不把会话记忆或旧版文档当作现行契约

## 六、环境一致性

- 引擎固定 **Godot 4.7.2**，用 `tools/setup_godot.ps1` 安装；`tools/run_demo.ps1` 会拒绝其它版本，因为版本不同会改写数百个 `.import`
- 跑引擎后 `git status` 出现大量改动、但 `git diff` 为空：这是行尾假脏。为该文件类型在 `.gitattributes` 补 `text eol=lf` 规则后提交，不要把这批文件提交上去
- 生成产物只进 `temp/`（不入库）

| 卡住了什么、等谁 | [02_待办](02_待办.md) |
| 最近的交接 | [04_交接日志](04_交接日志.md) |
| 资源版本与状态词 | [05_版本注册表](05_版本注册表.md) |
